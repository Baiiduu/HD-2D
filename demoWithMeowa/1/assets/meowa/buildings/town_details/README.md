# 城镇细节物件

八种非房屋生活道具，使用独立砌石、细孔整石、旧木纹、陶土、铸铁与黄铜。砌石和整石位于 `../materials/`，花盆与花车内土使用同目录的独立栽培土；不复用道路、广场或地板贴图。全部是独立 3D 场景，花车与花盆使用既有原生透明 2D 花草；水平旋转镜头后仍能从不同角度观察构件和碰撞。

| 物件 | 场景（`res://scenes/buildings/town_details/`） | 摆放与碰撞 |
| --- | --- | --- |
| 独立长椅 | `park_bench.tscn` | 休整区和通路侧边；坐板、靠背、扶手、支腿分别碰撞，板缝和下方空间保留 |
| 手推花车 | `flower_cart.tscn` | 花园路口、店铺边缘；木槽、支架、推把与轮辐独立碰撞，两只轮圈按真实空心网格碰撞 |
| 告示牌 | `notice_board.tscn` | 小广场入口；木面板提供宽平面，两支腿之间留空，纸张为装饰，尚无交互 |
| 陶制花盆 | `flower_pot.tscn` | 角落点缀；上宽下窄的盆体与空心盆沿，花草可关闭 |
| 石质水钵 | `water_basin.tscn` | 公共休憩节点；阶梯底座、细柱、浅钵和中央装饰，水面轻微波动，盆沿保留实际空心结构 |
| 街边垃圾桶 | `litter_bin.tscn` | 长椅、路灯旁；铁条、空心口沿与实心底座分别碰撞，铁条空隙可穿过细射线 |
| 货运托盘 | `cargo_pallet.tscn` | 店铺后侧和补给角；木托板、箱体与布袋组成低矮杂物组 |
| 麻袋堆 | `sack_pile.tscn` | 库存与庭院角落；三只不同大小、平底收口的布袋，分别提供鼓腹轮廓碰撞 |

通过 Godot「地图切换 → 城镇细节物件预览」查看，或打开 `res://scenes/previews/town_details_preview.tscn` 按 F6。预览沿用当前正式世界实际镜头和光影，Q/E 旋转、R 切换光影天气；三组样板位于 `CurrentWorld/TownDetailSamples`，沿广场向东、向南可走到下一组。

将任一场景拖入 `world.tscn`，选根节点整体移动、旋转、复制。「贴合地面」查找所在世界的 `Homestead` 或 `Ground`，也可手动指定 `terrain`。`dimensions` 调构件宽、高、深；花盆和花车的 `flowers_enabled` 控制花草，木纹、陶土、布袋颗粒底图可独立替换。移动不重建道具，调尺寸只重建当前实例，不写地表或人物存档。

`terracotta.png` 是 Meowa 生成的原生 64×64 RGBA 不透明材质，未重采样或再次像素化。布袋复用这张颗粒底图与 `town_burlap.gdshader` 的低对比织纹，未另造或修改图片；织纹是着色器表现。表面采样约 40 像素／米。花草保留既有原生透明像素，采用固定柔和簇影和当前天气风摆。

物件沿用第 1 层碰撞、`ricochet_obstacles` 根节点分组及 `ricochet_surfaces` 碰撞体分组，可供弹射攻击查找反射表面。关闭 `collision_enabled` 可只做视觉点缀。静态物件不执行逐帧脚本；只有带花草的实例同步天气，关花草后停止同步。水面波动在着色器中完成。素材当前用于场景地编，未附加坐下、读公告、搬运等交互。
