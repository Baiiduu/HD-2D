# 像素材质样板

草地、卵石、墙面和屋瓦由 Meowa 原生 64×64 纹理流程制作，源图原样接入。`path.png` 是以卵石为前景生成的 256×256 透明四角过渡图集，每格 64×64，采用 `TerrainPaintBrush.MEOWA_TILES` 的 16 格顺序。

正式地图 `VisualSample` 默认启用这组素材，检查器的材质开关只切材质，Style 可恢复整体原始预设。没有覆盖历史图片或修改原画笔资源。新建筑纹理每块覆盖 1.6 米，凹凸邻域为 1 原图像素；详情与截图见 [像素美术统一样板](../../../../../docs/pixel-art-sample.md)。
