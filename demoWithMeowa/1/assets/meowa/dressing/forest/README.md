# 浓绿林缘植物

来源：Meowa 原生像素「精致像素简约植物」，用户已确认。8 张独立透明 PNG 原样复制到 `plant_01.png`～`plant_08.png`，用于正式小院样板。

实际画布 **32×32**，模板目录的 64×64 标注与此次返回不一致；没有重采样。RGBA、透明留边、像素裁剪、最近邻采样、无损导入、无 mipmap。可见像素范围、各株底部锚点、像素尺度、绿色叶片色阶行、簇内层次和原图 SHA256 位于 `assets.json`。

`normals/` 中的 8 张同尺寸文件为单独的受光数据，复用 `tools/build_surface_normals.py` 的叶片法线算法，从颜色和透明轮廓估计浅高度；与原图透明度一致，不是 Meowa 提供的法线，也不代表真实三维体积。颜色 PNG 保持原样。

资源按原草层路径接入天气、光影和根部遮蔽；显示尺度再乘草层和区域倍率。旧小院样板的布局文档与截图已清理，植物源图及组件保留。当前地图的使用范围以实际场景为准，调节入口见[参数总览与 Style](../../../../../../docs/technical/parameters-and-styles.md)。
