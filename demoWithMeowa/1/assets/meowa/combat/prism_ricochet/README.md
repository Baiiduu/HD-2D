# 棱光弹射素材

`shard.png` 是 Meowa 根据已确认的粗像素方向重新制作的棱晶，原生 48×32 RGBA。晶面使用大色块、暖金细边和少量亮芯，透明边缘由 Meowa 像素去背景生成；保留原生像素与 alpha，没有本地重采样、再次像素化或去背景。技能图标通过 AtlasTexture 选取主体，矩形为 `(14, 5, 31, 22)`。

晶体使用独立的透明混合材质，保留蓝色晶面和金边，少量自发光突出亮芯。按用户要求缩小显示尺度：显示宽度为 0.75 米（包含透明留白和尾部小碎片），一级主体约 0.45 米；每个原生像素对应 0.015625 米，贴近人物的像素尺度。高阶仍由齐射与弹道强化体现成长。资源路径与导入 UID 保留。

运行时短光丝和八帧碰撞星芒保留 `../light_pierce/` 中的早期素材，碰撞反馈使用独立的 `scenes/combat/prism_contact_effect.tscn`，不读取 A02 新的 `pixel/` 素材。`PrismRicochetEffect` 按实际物理折线移动；网格、材质、碰撞反馈节点和弹丸特效均复用，闲置停止更新。命中和反射音源复用公共 Meowa 战斗音源，通过 `MapEffects/GameAudio` 的预算播放。
