# A02 青金贯穿美术

Meowa 按用户认可的场景参考制作了透明素材页及八帧命中动画。枪锋为白金亮芯与青蓝晶体外壳，拖尾为交织光丝，命中为星芒、弧纹和向外消退的晶片。

| 文件 | 原生尺寸 | 用途 |
| --- | --- | --- |
| `head.png` | 512×304 | 水平向右的枪锋 |
| `trail.png` | 1024×256 | 细长光丝拖尾 |
| `impact.png` | 512×384 | 命中动画的起始素材 |
| `impact_atlas.png` | 2560×1008 | 八帧命中动画，4×2 排列 |
| `impact_frames.tres` | 每帧 640×504 | Godot 非循环 `impact` 动画 |

全部 PNG 保留真实 alpha。三个静态素材从 Meowa 的 1024×1024 素材页按原像素裁切；动画由原始 WebP 帧按原尺寸打包，没有重采样或本地去背景。它们是适配 HD-2D 场景的特效美术，通用生成不保证统一的小像素网格。

`source/` 保留 Meowa 原素材页、原动画 WebP/GIF 和原始动画图集；原动画为八帧、0.8 秒。运行时按 `Impact Duration` 重定时，当前视觉预览为 0.4 秒。该目录使用 `.gdignore`，运行时读取 PNG 和 SpriteFrames。

查看方法、可调参数与实际游戏镜头录制见 [雷光贯穿视觉预览](../../../../../../docs/light-pierce.md)。
