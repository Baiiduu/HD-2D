# 正式地图（战斗区）

Y 可切换「镜头跟随人物」，「设置 → 镜头」与主菜单中的同名页显示当前状态；跟随状态只在本次运行生效，不再单独存档，旧存档中的跟随开关也不会覆盖当前状态。关闭时保留取景，鼠标移向屏幕边缘平移镜头，越靠边越快，斜向不额外加速，Q/E 后按新的画面方向移动。焦点限制在地图边缘留白内，人物行动与地图边界刷新不自动重锁；重新开启后平滑回到人物。管理界面、鼠标移出窗口、窗口失焦和清波特写时停止边缘滚动；输入文字、组合键、按键重复、管理和入场演出不触发 Y。

镜头页可调「跟随速度上限」与「最大跟随落后」，World 默认 10 米／秒与 3 米。上限控制常态跟随平移；接近允许落后距离时逐渐放宽限速，必要时优先保住人物可见性，推近后按实际视野收紧允许距离。远处重新跟随时先平滑归位，保留原推近、短促震动与结算演出。速度上限设为 0 可沿用不限速，其他场景默认不启用限速。数值偏好自动保存在 `user://camera_settings.cfg`，参数总览「视觉」也可调整。`tests/test_camera_edge_pan.gd` 与 `tests/test_camera_follow_limit.gd` 检查输入、设置和追赶逻辑，实际手感由人工试玩确认。

`BuildingOcclusion` 只在医院或便利店实际挡住玩家时平滑淡化该栋建筑，离开后短暂保持再恢复；怪物不参与遮挡检测，人物与波次怪物关闭穿墙轮廓。检测复用现有分段盒碰撞与模型，不改变碰撞、灯光或阴影；菜单与入场期间保留完整建筑。参数总览「视觉」可调遮挡不透明度、检测间隔、淡出与恢复时间。未来同类房屋可通过根节点的 `occlusion_buildings` 分组接入，碰撞体须使用对应墙身的 BoxShape3D。

在 Godot 的「地图切换」中选择「正式连续地图」并运行。入口为 `world.tscn`，独立于视觉测试场景。

正式启动先显示 `WorldMainMenu` 内嵌菜单，World 已在背后完成初始化、导航构建与入场效果预热；准备好才启用开始，点击沿用同一实例进入游戏。若需直接预览地图或入场，可在编辑器关闭 `WorldMainMenu.show_on_world_start`，再使用 `WorldEntry.preview_on_direct_run`。

现有主菜单背景保持，点击「开始游戏」后才显示建筑间穿雾入场。`WorldEntry` 当前总长约 8.2 秒：先用约 5.5 秒从北街贴近建筑高度穿过商店与医院之间，沿雕塑旁绕行并逐渐抬升，结合横移和左右侧倾，保持画面正向；转回原有游戏机位后停稳约 0.4 秒，再用约 2.3 秒翻卷散雾显露人物。运镜阶段保持完整雾量，近处墙体、树冠和灯光在雾中留下不同深浅的轮廓。

路线在 `WorldEntry/BuildingFlightPath`，使用独立的 `data/visual/world_entry_route.tres` 曲线，可在 Godot 的 Path3D 编辑工具中修改。运镜先沿街观察建筑，再连续转回人物取景方向；最后一段适配实际跟随机位和 Q/E 朝向。入场期间暂时关闭人物穿墙描边，结束／跳过后恢复原值。未绑定路线的其它场景仍可使用远空环绕参数；正式地图沿已布置的建筑通路前进，不移动建筑或改写基础镜头配置。

当前高空转弯控制点已匹配 30 米基础镜距。默认朝向的低空段保持在地图内，高空段保留在地图边缘 4.5 米范围内；修改基础镜距后需复核运行时适配后的曲线。`test_world_entry.gd` 同时检查边界、真实碰撞避让、转向连续性与 Q/E 回放衔接，失败时输出越界距离和位置；画面观感仍由人工试玩确认。

空间云层自动读取 `Homestead` 的真实边界，并包住整条镜头路线及转向、侧倾时完整的 96 米前向视野；连续的底层云密度遮住固定城市远景，路线及地图周围的体积云团、近中远多层 Meowa 厚云素材提供主体轮廓、翻卷、掠过和视差。沿途云片面向该段实际镜头朝向，按 FOV 与窗口比例扩大，固定在世界中供相机穿行。散雾时云团保持自身密度，实际向外围位移并翻转，密度场按向外输运的卷流回溯采样；广域云层的开口也扩展到可见深处，近景云片退向两侧，上卷、扭动并逐渐让出人物和地图，仅最后清理视野外残余。暖色聚光保持到显露阶段，临时中性散射避免夜景把整片云染成蓝幕。`assets/meowa/effects/world_entry/cloud_bank_density.png` 保留 Meowa 原生 1024×1024 灰度密度图，直接在材质中转为柔和透明度；旧雾絮保留，不做二值抠图、重新像素化或全屏灰色遮罩。

入场等待首轮画面呈现后再计时，演出时钟单独限制加载长帧带来的跳步，人物物理与世界时间保持原规则。临近收尾逐渐恢复场景原有空气参数，再归还相机环境引用，避免突然变色；不改地图资源或本机画质存档。

菜单接口为 `WorldEntryRequest.request()` 后切入本场景，切场失败调用 `clear()`；请求只消费一次。直接 F5/F6 是否播放由 `WorldEntry → preview_on_direct_run` 决定，Esc 可跳过。总时长、运镜时段占比、绕转角度、左右侧倾、远空距离／高度、雾浓度和聚光亮度在 `data/visual/world_entry.tres` 或参数总览「视觉」调整。收尾销毁临时光雾、恢复 HUD 和输入并停止更新，保持准备状态，不自动开战或打开选卡；基础镜头、Style、雨风声和 BGM 保持各自配置。逻辑回归为 `tests/test_world_entry.gd`，光雾与运镜观感由人工试玩验收。

主场景只保留现有 32×32 米战斗核心，外围非战斗绕行带与旧入口地块已移除。地形按原 1.6 米格子覆盖核心，实际为 21×21 格、33.6×33.6 米，人物与战斗范围均限制在核心内。出生、开战交互和撤退返回位置位于核心内的空地（X/Z 为 0／48），保留原 F 键开局流程。核心内的手绘地表、建筑摆放与光影参数保持。旧小院、住宅、训练小屋、东侧广场等原型资源继续保留。

`WorldDetails/BattleCourts` 集中布置城镇细节、树池、中心雕塑与弹射障碍，复用花车、长椅、告示牌、花盆、水钵、垃圾桶、托盘、麻袋、石墙、柱、围栏、箱桶与路灯。道具按各实例的缩放布置，树池底座与树冠可独立调节，保留原生像素素材。场内横穿与绕障通路保留，物件具有实际碰撞。

树池建筑样板可从「地图切换 → 树池建筑预览」查看。将 `scenes/buildings/tree_planter.tscn` 拖入世界，选择根节点整体移动、旋转、复制；Inspector「贴合地面」对齐高度，尺寸与花草／长椅／路灯独立可调。具体素材与放置方式见[树池说明](../../assets/meowa/buildings/tree_planter/README.md)。

参考图的双头路灯与中心环球雕塑见「地图切换 → 广场路灯与环球雕塑预览」。独立场景为 `scenes/buildings/plaza_streetlamp.tscn` 和 `scenes/buildings/armillary_monument.tscn`，可同样拖入世界整体放置；具体参数见[广场道具说明](../../assets/meowa/buildings/plaza_landmarks/README.md)。

六种非房屋弹射障碍物位于 `scenes/buildings/ricochet/`，从「地图切换 → 六种弹射障碍物预览」查看。包含矮石墙、铁艺围栏、木箱堆、木桶组、方形石柱与 L 形挡墙，均可整体放置，提供实际平面／圆柱／转角碰撞；用法见[障碍物说明](../../assets/meowa/buildings/ricochet/README.md)。

同风格新增十二件变种位于 `scenes/buildings/ricochet/variants/`，从「地图切换 → 弹射建筑变种预览」查看。短墙、斜墙、通行开口围栏、折栏、单箱／箱排、单桶／桶排、圆柱／八角柱、U 形／钝角墙可用于组合不同的反射路线，尺寸、开口和角度在各根节点调整。

八种城镇细节物件位于 `scenes/buildings/town_details/`，从「地图切换 → 城镇细节物件预览」查看。包含独立长椅、手推花车、告示牌、陶制花盆、石质水钵、街边垃圾桶、货运托盘和麻袋堆，可拖入正式地图，沿用现有弹射碰撞与整体放置方式；见[细节物件说明](../../assets/meowa/buildings/town_details/README.md)。

战区挑战使用[无尽波次](../../../../docs/gameplay/endless-waves.md)：开场 18／28／40 只，后续持续递增；清波休整后按 F 继续，失败或 ESC 撤退结束，T 重试回到第一波。参数位于 `WavePrototype → 无尽波次`。

`WavePresentation → settings` 调节辅助标题与最后一击特写；开战保持当前取景，不拉镜。最后一击特写默认 3 秒，快速推近、世界慢放并强调原生剪影，平滑恢复正常镜头后再衔接清波选卡和休整；UI、音乐与风雨声继续，返回主菜单和管理界面会完整释放演出状态。正式视觉参数见 `data/visual/wave_presentation.tres`，运行使用当前相机配置。

战区地形使用 `data/world/world_terrain.tres`，当前战斗面为零层平地，取消原东西两侧的高台地与坡道；裁切后保留格子的原道路覆盖层、区域类型、高度与画笔编号。`data/world/world_surface.res` 保留手绘地表与分隔带数据，仅上传落在战区内的绘制块。原 `data/world/spawn_terrain.tres` 保留为小院原型基准。`VisualSample` 使用场景当前保存的光影，三种 Lumina 与原始增强仍可按 R 比较；原始增强参数见[参数总览与 Style](../../../../docs/technical/parameters-and-styles.md)。

`SpawnPoint` 是实际出生位置，运行时将人物放到此标记。默认 WASD / 方向键移动，Q/E 连续旋转，Y 切镜头跟随，R 切四种光影 Style，G 切晴雨，结算后 T 重试，P 打开／关闭设置。正式地图暂时关闭空格跳跃，保留按键配置与人物开关。主菜单与游戏内「设置 → 按键」可统一改键并恢复默认，保存本机偏好；Esc 保留返回与取消。晴雨快捷键与「画质 → 天气与装饰 → 下雨」共用按地图保存的状态，R 保留晴雨、雨量和雨丝数量。Godot「参数总览」统一定位参数，见 [参数与 Style](../../../../docs/technical/parameters-and-styles.md)。

正式地图关闭 `Player → 台阶通行 → auto_step_enabled`，并将原生 `Floor → Max Angle` 设为 1°，防止胶囊底部沿矮边爬升。人物走路被栅栏底座、花坛和建筑台阶阻挡，可沿边滑行；`Player → 跳跃与下落 → jump_enabled` 暂时关闭，后续可重新启用。其它地图与预览保留各自配置，建筑自身的体积与碰撞不变。

地表分布可在编辑器中手绘：选中 `Homestead`，打开右侧「地表画笔」并启用，选择草地或卵石道路后左键拖动。Shift+左键擦除道路，Ctrl+Z / Ctrl+Shift+Z 撤销或重做；使用「保存地表」或 Ctrl+S 保存。详见 [地表画笔](../../addons/terrain_painter/README.md)。

镜头恢复人物在画面中央附近的原有构图：FOV 28°、距离 25 米、俯角 30.627°、默认朝向 135°、焦点高度 0.75 米、垂直偏移 0 米，景深关闭；保留 Q/E 连续旋转、跟随与弹射反馈。`VisualSample` 不覆盖镜头，共享效果和四境视觉测试场景保留各自对照配置与旋转能力。

远景为 `assets/meowa/environment/distant_city/city_matte.png` 的原生 2048×1152 单幅雾城图，经天空材质按屏幕坐标等比裁切，只出现在地形、建筑后方。人物移动时图片位置不变，窗口比例变化时顶部对齐，不拉伸；画面背景与照明立方体分开，保持现有场景照明。旧环绕贴图与隐藏的 `CityBackdrop` 原型保留。

`WorldDetails/BattlePerimeter` 沿战区四周草地边沿放置 36 段现有铁艺栅栏，栏高 1 米，保留独立石座、金属栏杆及真实弹射碰撞。各实例可在编辑器单独调整，不改手绘铺装及场内原有建筑。

| 调节节点 | 参数与用途 |
| --- | --- |
| `WorldDetails/BattleCourts` | 小型道具的整体位置、朝向、缩放与真实碰撞 |
| `GroundDressing → excluded_areas` | 建筑与入口的花草留空区域，采用地形本地 X/Z 坐标 |
| `BattleArea` | 主战斗面、开战交互与花草密度；正式场景 `loop_width = 0`、`entry_inset = 19.2`、`terrace_levels = 0`，重建保留手绘地表，不恢复外围区域 |
| `Homestead → data` | `cell_size` 为格子尺寸（当前 1.6 米），`layer_height` 为每档高差（当前 0.8 米）；地块轮廓与层级在独立数据中保存 |
| `Homestead → top_material` | 草地、道路与手绘石板铺装；各 `surface` 的 X/Y/Z 分别控制干燥粗糙度、金属度、受湿程度 |
| `Homestead → wall_material` | 独立的 `materials/world/spawn_cliff.tres`；`wall_texture` 为侧壁纹理，`tint/saturation` 为色调，`texel` 为单像素对应的米数，`lip_pixels/lip_shadow_pixels` 为边沿宽度与阴影宽度 |
| `Homestead → grass_transition / surface_edge_transition` | 草沿与铺装侧边衔接，当前均开启；控制台地边缘如何折到侧壁 |
| `WorldMap` | 调整标记位置后可按「对齐建筑与出生点」重新对齐台地高度；`spawn_lift` 是出生时脚底离地余量 |
| `MapEffects/ArtDirection` | 曝光、环境光、主光颜色/方向/阴影、雾与色调 |
| `MapEffects/Camera3D` / `VisualSample` | Camera3D 独立调镜头；VisualSample 切光影、像素材质和色阶，World 独立保留晴雨，不再重复控制镜头或布局 |

顶面沿用预览材质做法：按世界坐标铺设 64px 材质，道路/泥土使用 4×4 双网格过渡图集，`terrain_surface.gdshaderinc` 同时供顶面和侧壁取样；`cliff.gdshader` 处理草沿、铺装侧边及崖脚衔接。单格 1.6 米，像素密度保持一致。材质参数在正式地图中独立保存，不影响视觉测试地图。

天气与地面湿润参数由通用 `MapEffects` 同步到地形材质；调节雨量或湿润效果时使用既有天气与视觉调节节点。

地表与碰撞在编辑器和运行时生成，生成节点不保存。运行回归检查可使用 `tests/test_battle_only_world.gd`，覆盖裁切范围、通路、障碍碰撞、Style 保持和真实波次启动。
