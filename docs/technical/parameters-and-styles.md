# 参数总览与游戏内 Style 切换

更新：2026-10-17。项目 `demoWithMeowa/1`，正式地图 `scenes/world/world.tscn`。

## 参数入口

Godot 右侧新增「参数总览」，初次默认放在检查器下方，选择参数后可继续浏览总览。可拖动停靠面板调整位置；已有布局可能保留此前的页签位置。打开地图或组件场景后自动索引，外部修改后可点「刷新」。已有编辑器若未显示，在「项目 → 项目设置 → 插件」启用「参数总览」。

- 默认「只看常用」，先显示镜头、风格、人物、扇击数值、怪物数值、波次、经验、HUD 和音量。
- 关闭常用筛选，按用途、组件路径和原分组浏览全部自定义导出参数、嵌套规则资源与高级着色器参数。
- 搜索中文用途、英文变量名、节点路径、分组或原代码说明。搜索覆盖全部参数，不受常用开关限制。
- 选择结果定位原检查器，继续使用 Godot 的撤销、场景保存和资源保存。总览不保存第二份数值。
- 悬停和选中时显示原代码说明。共享资源只登记一次；要独立调节先设为唯一。

| 分类 | 实际控制对象 | 常用调节 |
| --- | --- | --- |
| 视觉 | VisualSample、ArtDirection、Camera3D、Weather | Style、像素材质、色板、曝光、主光、雾、镜头、景深、雨量、风摆、闪身扰动 |
| 人物 | Player、Player/Sprite、人物弹射／基础剑术与动作资源 | 速度、跳跃、闪身、蓄力／反弹／拨怪、普攻与飞行剑术的伤害／间隔／范围／斜切摆位、五类动作槽、生命魔力、受光 |
| 战斗与成长 | WavePrototype、FanAutoAttack、RunGrowth、波次／怪物／经验资源 | 扇击伤害／范围／间隔、怪物数值、刷新、保护、经验与吸取 |
| 地图与地编 | Homestead、BattleArea、GroundDressing、区域、建筑及画笔 | 地形、战区、铺装、花草、建筑尺寸和材质 |
| UI | LoadoutUI、TrainingUI、属性条、技能栏、物品栏、成长卡片 | 缩放、字号、边距、槽尺寸、辉光、透明度、动效 |
| 声音 | BGM、Weather 音频组、动作音效、UIAudio 及声音资源 | 开关、音源、分贝、淡化、循环和增益 |
| 物品与规则 | 物品／装备／技能目录、训练规则 | 内容、基础属性、训练消耗及已有配置；不代表后续流派已定稿 |

生成的网格、碰撞、花草批次和 UI 控件不作为重复调节入口。布局仍在场景，地形仍在 TerrainData，机制数值仍在组件和规则资源中。

## 游戏内设置与计分

「镜头」页与主菜单共用数值偏好。默认 Y 临时切换跟随，跟随状态不写入也不读取旧存档；边缘滚动速度、跟随速度上限及最大落后距离自动保存于 `user://camera_settings.cfg`。World 默认跟随舒适速度 10 米／秒、最大落后 3 米，0 上限为不限速；落后增大时允许渐进加速追赶，按当前实际视野收紧安全距离，地图边界优先。原有推近、短促反馈和结算演出保留。输入文字、组合键、重复按键、管理或入场时不触发跟随切换，远处重锁先平滑归位；参见正式地图说明与 `test_camera_follow_limit.gd`。

正式地图右上「设置」统一打开声音、环绕调试、画质与显示、镜头、按键、排行榜和人物属性页，默认 P 或 Esc 打开／关闭。声音页保留分组音量与本机保存；切换离开声音页或关闭设置会停止试听。环绕页保留真实路线与轮廓、攻击范围、锁定和清空记录；关闭设置后仍可观察已开启的场景诊断线，关闭调试后停止采集。打开设置及人物属性页会暂停场景树，人物、怪物、攻击与战斗音效停止推进，BGM、UI 音效及排行榜通信继续。切换页签不解除暂停，关闭、返回菜单或移除设置时恢复打开前的暂停状态，不解除其它战斗冻结；恢复前吸收移动键并清除积压战斗输入。Esc 优先取消改键，再关闭设置，不新增 F 类快捷键。窗口顶部可开关黑字实时 FPS，关闭设置后继续显示。

「画质与显示」支持以下现有能力，第一次打开沿用当前场景值，仅保存用户明确修改的项：

| 分组 | 游戏内选项 |
| --- | --- |
| 显示 | 窗口／全屏、场景渲染分辨率、垂直同步、帧率上限 |
| 抗锯齿与阴影 | MSAA、FXAA、TAA、局部阴影贴图尺寸、方向光阴影、路灯全向补光阴影、聚光阴影 |
| 环境与后处理 | SSAO、SSIL、SSR、泛光与强度、距离雾、体积雾、景深、暗角 |
| 水面与地面 | 湿地面倒影、水面镜像及反射分辨率比例 |
| 天气与装饰 | 下雨开关、降雨强度、雨丝数量、地面雨纹、镜头水滴、花草风摆、极光、萤火光点、路灯颗粒 |

全屏始终覆盖整个屏幕，分辨率选择改变真实 3D 渲染缓冲，不切换显示器视频模式、不缩放 UI。
选项按当前窗口宽高比例计算；例如 1920×1080 输出下选择 720p，场景为 1280×720，
输出改为 2560×1440 后仍维持 1280×720。水面镜像缓冲也乘同一场景分辨率比例，避免主视口
降低后镜像仍保留原像素成本；独立极光天幕保持原规格。低分辨率会降低清晰度，阴影提交与
CPU 逻辑的开销仍需独立处理。Godot 的 [3D 缩放接口](https://docs.godotengine.org/en/stable/classes/class_viewport.html#class-viewport-property-scaling-3d-scale)
与 [全屏模式](https://docs.godotengine.org/en/stable/classes/class_window.html#enum-window-mode)参见官方说明。

编辑器内嵌运行（`--wid`）可调整渲染分辨率；全屏开关显示为不可用，并提示改用独立运行窗口。
本机选项保存在 `user://graphics_settings.cfg`：显示／抗锯齿设置共用，场景光影按地图路径独立保存，
不回写场景或美术资源。Style 变化会重新应用用户选择；「恢复本页场景默认设置」移除当前页
覆盖并恢复场景配置。运行时参数由 `graphics_settings_page.gd` 管理，ArtDirection 完成应用后
重新落实显式环境开关；闲置无逐帧轮询。无界面测试不读取／写入个人画质文件；性能对照工具
也明确关闭个人画质加载。全屏切换、实际分辨率显示、画面清晰度与手感仍需人工试玩验收。

右上得分由 `WavePrototype/RunScore` 和 `WavePrototype/ScoreHUD` 负责；击杀、清波和小额弹射表现分采用独立规则资源 `data/score/default_score.tres`，HUD 的合并时长、计数过渡、变化位上弹与颜色可在该节点 Inspector 调整。[计分与接口说明](leaderboard-api.md#godot-局内计分与-hud)。

## 画质参数的含义

| 参数 | 作用与代价 |
| --- | --- |
| 全屏／场景渲染分辨率 | 全屏铺满屏幕，场景可用更少像素绘制后放大，UI 保持清晰。1280×720 是 1920×1080 像素数的约 44%，但 FPS 不会按该比例提升，提交与逻辑成本仍在 |
| 垂直同步（VSync） | 配合显示器刷新提交画面，减少横向撕裂，可能增加等待。常见 60 Hz 显示器开启后通常受约 60 FPS 上限约束；测最高性能时关闭，日常试玩再按观感开启 |
| 帧率上限 | 限制绘制频率以减少发热与功耗；设置 100 只是上限，不是保底。检查性能余量时选“不限”并关闭 VSync |
| MSAA 2×／4×／8× | 平滑建筑等几何边缘，倍数越高越耗 GPU 和显存；不能完整解决贴图内部和透明裁切的锯齿，也不是整幅画面提高这么多倍分辨率 |
| FXAA | 用较低成本平滑本帧边缘，但可能抹软像素人物和细线 |
| TAA | 结合历史帧减少闪烁，但可能模糊或拖影，尤其要观察高速弹射、雨丝和残影 |
| 局部阴影贴图尺寸 | 全向灯／聚光灯共用的阴影图集边长，不是每盏灯各有一张同样尺寸的贴图；不控制方向光图集。2048→4096 时整张图集像素增为四倍，阴影更细，成本也更高 |
| 方向光／补光／聚光阴影 | 三类投影分别控制；关闭阴影保留照明。补光阴影是本项目已定位的高开销项，关闭后需观察墙后漏光。减小图集不会消除重复投影提交 |
| SSAO／SSIL／SSR | 分别补充接缝暗部、间接补光和屏幕空间反射，都增加 GPU 计算。SSR 对屏幕外物体的反射有限 |
| 泛光／强度 | 高亮位置向外扩散光晕。强度调低不等于关闭，关闭泛光不关闭真实灯光 |
| 距离雾／体积雾 | 前者让远处融入雾色，后者让空气和雾中光束受光；体积雾通常更重 |
| 景深／暗角 | 分别控制虚化和四角变暗；暗角主要改变观感，不是已定位的性能大头 |
| 湿地面／水面镜像 | 湿膜与灯光倒影使用现有地表表现；镜像是额外视角绘制，只在活动水面存在时产生该视口成本 |
| 水面反射分辨率比例 | 宽高的缩放比例，50% 对应约四分之一像素；还会共同乘主场景的分辨率比例 |
| 雨量／雨丝／雨纹／水滴 | 调整天气密度和表现；雨量会联动原有雨声与湿润反馈，雨丝数量影响粒子与透明叠加 |
| 风摆／极光／光点／颗粒 | 独立装饰表现，开关不移除地图或碰撞。极光额外视口此前实测较小，不能假定关闭任意特效都会明显提速 |

本项目的对照起点可用 MSAA 2×、FXAA／TAA 关闭、阴影图集 2048；保留方向光与聚光阴影，
单独比较全向补光阴影的开关，再比较 900p／720p。它们不会自动改写默认画质。
引擎允许叠加抗锯齿，但叠加会增加成本，不建议为了“全开”同时开启。
各控件悬停也可查看用途与取舍。CPU 定位可固定为最低画质并保留 128 怪；GPU 定位可改为空场或少怪并保留待测画面。同一组内固定镜头、窗口、数量和动作，一次只改一项，最后恢复完整负载验收。详见 [CPU 与 GPU 性能优化](../gameplay/attack-performance.md)。

原理与限制参见 [Godot 抗锯齿](https://docs.godotengine.org/en/stable/tutorials/3d/3d_antialiasing.html)、
[局部阴影图集](https://docs.godotengine.org/en/stable/tutorials/3d/lights_and_shadows.html#shadow-atlas)、
[VSync 模式](https://docs.godotengine.org/en/stable/classes/class_displayserver.html#enum-displayserver-vsyncmode)
与 [环境和后处理](https://docs.godotengine.org/en/stable/tutorials/3d/environment_and_post_processing.html)。

## 按键与快捷键

主菜单与游戏内「设置 → 按键」共用一套键位。点击对应键位后按下键盘单键；普攻、蓄力弹射、闪身和跳跃也支持鼠标左／右／中／侧键。移动保留主键、备选键两个槽位，继续分别检测新按下，保持“发射前已按住的移动键不取消弹射，松开后重新按下才取消”的规则。

| 操作 | 默认按键 |
| --- | --- |
| 移动 | WASD／方向键 |
| 普攻／蓄力弹射 | 鼠标左键／右键；右键短按仍沿原规则切线脱离 |
| 闪身／跳跃 | Shift／空格 |
| 镜头旋转／跟随开关 | Q、E／Y |
| 交互与续波／人物背包 | F／Tab |
| 光影 Style／晴雨 | R／G |
| 结算重试／设置开关 | T／P |

重复占用会显示冲突操作并保留原键位；Esc 取消当前改键，未改键时返回界面。Esc、数字选择及 F1–F12 等保留键不用于重新绑定。输入文字、管理／升级占用输入、长按产生的重复事件不会切换天气。晴雨快捷键复用画质页的实际天气与保存入口，不改光影配置。

键位即时生效，保存到 `user://controls.cfg`，重启后恢复；恢复默认按键同时还原实际输入及界面显示，不改写项目默认键位。初始主键可沿用场景的交互／背包／Style 默认配置，用户已保存的改键优先；测试使用独立临时文件，不读写本机按键存档。核对逻辑由 `test_control_bindings.gd` 与 `test_controls_settings.gd` 覆盖，界面排布和手感由人工试玩确认。

## R 切换

初始光影以地图 `VisualSample.style` 为准。**R 单次按下：原始光影 → 黄金时段 → 细雨 → 夜晚 → 原始光影**。World 的这四项只切光影，晴雨由游戏「设置 → 画质 → 天气与装饰 → 下雨」独立控制。结算重试改为 **T**；F 开始／继续，ESC 返回或撤退。

| Style | 当前光影 |
| --- | --- |
| 原始光影 | 沿用原暖主光；默认开启提亮和明暗交界增强，关闭增强恢复旧版 |
| 黄金时段 | 暖主光、冷环境填光、轻窗光和较干地面 |
| 细雨 | 冷柔主光、较湿地面和更明显的暖窗；名称不决定是否下雨 |
| 夜晚 | 深冷环境、低主光和较强暖窗 |

World 的 Style 仅切光影与表面受光，保留晴雨、雨量与雨丝数量，以及当前镜头、Q/E 朝向、跟随、景深、人物位置、地图与建筑布局、尺寸、碰撞、花草密度及分布、种植、库存、战斗与存档。建筑窗光和 Lumina 受光只更新材质，不重建网格或碰撞。

像素材质、色阶、屋瓦对比、卵石暗点及草地深浅变化在四种 Style 中独立保留。「原始光影」用于同场景光照对比，不再还原历史镜头、旧布局与旧素材。声音音量／开关、闪身扰动参数也独立保留，天气声音继续采用原淡化。

原始光影实际主光在 `spawn_original_render.tres` 中单独保留，历史 `spawn_original.tres` 不覆盖；三种 Lumina 主光按预设正确生效。

`VisualSample → 原始光影增强` 提供独立开关与 `spawn_original_refined.tres` 配置，默认开启，仅对 Style 0 生效。关闭恢复旧版，三种 Lumina 不变；主光与局部暖光的方向保持统一。

World 的 `VisualSample.independent_weather` 明确开启，初始晴雨与雨量读取地图 `MapEffects/Weather`；本机选择保存到 `user://graphics_settings.cfg` 的当前地图区段。关闭下雨保留雨量、雨丝数量和基础风摆，雨声淡出，地面按原有速度退湿；恢复本页默认设置会还原地图初始值。雨丝、地面／水面雨纹、镜头水滴与雨声仍共用原天气状态。其它地图默认保持原 Style 与晴雨联动，启用该模式后才提供独立晴雨开关。

`VisualSample → 画面风格 → 游戏内切换` 提供 `Runtime Switch Enabled` 和 `Style Key`。自动重复、组合键、文字输入、背包／训练面板与升级选择期间不接管 R；结果状态允许切换。F7/F8 不绑定视觉功能。

## 参数由谁控制

| 调节项 | 持久修改位置 | 切换 Style 时 |
| --- | --- | --- |
| 镜头、跟随、旋转与景深 | `MapEffects/Camera3D`，FOV 在内置属性中 | 保留；移除 VisualSample 重复的四项镜头控制 |
| 地图、建筑、花草分布 | 原场景节点、TerrainData、地编区域 | 保留 |
| 像素材质、尺度、屋瓦对比、色板与卵石暗点 | VisualSample 与色板资源 | 保留 |
| 草地深浅开关、强度与斑块大小 | `VisualSample → 草地深浅变化` | 所有 Style 保留，包括原始光影 |
| 明暗层次样板及原版对照 | `VisualSample → 明暗层次样板` 与 `spawn_value_sample.tres` | 保留开关和独立色板；三种 Lumina Style 应用各自半球补光，原始光影恢复均匀环境色 |
| 原始光影提亮与交界 | `VisualSample → 原始光影增强` 与 `spawn_original_refined.tres` | 保留开关，仅叠加到 Style 0；关闭恢复之前实际光影 |
| 雾、泛光与暗部后处理 | `VisualSample → 雾与后处理样板` 与四个 `spawn_atmosphere_*.tres` | 保留开关，各 Style 应用自身配置；关闭恢复本轮前效果，主光和镜头保持 |
| 主光、填光、雾、受光和预设雨量 | `data/visual/spawn_*.tres` | 应用该预设；直接调控制节点用于临时试看，切换后会重设 |
| 声音、闪身、人物与战斗数值 | 原组件或规则资源 | 保留 |
| 湿地面与灯光倒影 | `MapEffects/ArtDirection → 湿地面与灯光反射` | 保留独立开关、湿润下限、覆盖、粗糙度和波纹参数，见[湿地面调节](../visuals/water-lighting.md#当前战区湿地面与灯光反射2026-10-14) |

总览列出四个「风格预设」资源：`node_values` 是节点视觉值，`shader_values` 是材质视觉值，`palette_values` 是地表受光。历史快照内的相机、位置、尺寸、花草分布、声音和闪身项保留参考，现切换逻辑明确忽略；画笔编号与图集规则不从 Style 写回。

## 草地深浅变化

选择 `VisualSample → 草地深浅变化`，也可在「参数总览」搜索「草地深浅」或「斑块大小」。

可以直接在 **Godot 编辑器 3D 视窗**中预览，不必运行游戏或按 R。拖动强度／大小会立即更新地面材质；已打开场景在工具脚本更新后自动补齐预览初始化。若想手动重刷，同组提供「刷新草地斑块预览」按钮，只更新这三项，不套用 Style，也不重建地形或花草，因此保留当前自定义灯光。

| 参数 | 默认 | 意义 |
| --- | --- | --- |
| `Grass Variation Enabled` | 开 | 叠加固定的程序化色块，与 Style、Lumina 凹凸、草地受光及像素材质开关独立 |
| `Grass Variation Strength` | 0.16 | 越大深浅差异越明显；0 不叠加这层变化，贴图自身的明暗仍保留 |
| `Grass Variation Size` | 约 2.63 米 | 噪声格的世界尺度，越大斑块越大；不修改地形格、贴图密度或花草分布 |

算法在地面着色器中运行：世界 X/Z 位置除以斑块大小，取固定位置偏移下的平滑值噪声，再用 `smoothstep` 形成颜色倍率。在开启五色色阶时，先变化底色再选档。强度 0.16 沿用此前约 0.84～1.04 的倍率；算法不使用时间或相机位置，保持固定分布。只作用于实际草地层，道路和耕地保持原行为。

2026-10-13 的相邻色档试作已按用户反馈撤回，当前恢复原颜色倍率与选色规则；原始光影中的大块斑块仍可能不明显。已否决的对照仅作历史记录，不作为当前表现或下一步实现要求。

原来这层变化使用写死的频率／幅度，并附在 Lumina 开关上，所以原始光影没有斑块；现在三项参数独立，在原始光影中也生效。只调强度或大小更新材质，不重建地形、碰撞或花草。

首次进入必须直接得到正确草色。已修复启动阶段画笔延迟刷新将 Style 色调覆盖成白色的问题：画笔应用后重新保留当前草地／道路受光，不重复套用整个场景预设。草根遮蔽、草地凹凸等继续由 GroundDressing 统一控制，历史 Shader 快照不再覆盖这些数值。
