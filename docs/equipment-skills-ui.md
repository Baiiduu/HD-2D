# 人物背包与技能界面

2026-10-12 玩法方向更新：技能获得与 Tab 技能页的新职责见 [慢节奏波次生存玩法草案](rpg-game-design.md)。建议用清波成长选择与长期解锁链路取代目录内直接学习；本页继续记录当前已实现的界面，相关代码尚未按新方案修改。

同日灰盒范围更新：正式地图已连接 [波次循环灰盒](wave-graybox.md)，技能页暂为说明占位、技能槽为空，战斗中限制打开管理界面。下方原学习与装配操作继续适用于未连接灰盒的界面测试；具体技能与成长随后讨论。

正式地图已接入 Meowa 手帐风格的人物、背包与技能管理界面。三个页面沿用已有的大书页底图、外框和页签位置，窗口四周呈现当前游戏世界，只轻微压暗背景。人物页显示立绘、三类装备槽与装备比较；背包页独立管理装备、工具、材料、种植物品和消耗品；技能页提供学习、装配与装备加成预览。通用背包和底部物品快捷栏的操作、素材及参数见 [背包与物品栏](inventory-ui.md)。当前物品与数值用于检验界面和管理逻辑，正式平衡及各系统的使用动作随后继续开发。

## 运行与操作

在 Godot 打开 `demoWithMeowa/1/scenes/world/world.tscn`，按 F6 运行正式地图。项目 F5 默认入口仍是视觉测试地图。

| 操作 | 效果 |
| --- | --- |
| Tab | 打开或关闭界面，首次默认进入背包页 |
| ESC 或右上角关闭按钮 | 返回地图 |
| 人物／背包／技能页签 | 分别打开人物装备、通用物品与技能配置；书本外框保持一致，背包页签聚焦搜索框 |
| 单击装备或技能 | 查看详情 |
| 双击装备 | 穿戴到对应类别的槽位 |
| 拖动装备 | 放进武器、防具或饰品槽；类别不匹配时拒绝 |
| 双击尚未学习的技能 | 学习技能 |
| 拖动已学习技能 | 装配到技能槽；移动到已占用槽位时交换位置 |
| 详情区操作按钮 | 穿戴、卸下、学习、指定装配位置或移出技能槽 |
| 搜索与分类筛选 | 筛选装备或技能；无匹配项时显示提示 |

打开界面时世界照常运行，天气、环境动画、人物物理和声音持续更新。面板占用人物移动、跳跃、镜头旋转及未处理的游戏按键，搜索装备时不会误操作角色；关闭后恢复控制。左下角技能槽可打开对应技能详情，目前用于配置入口，尚未触发战斗技能。用户已确认小尺寸空槽、半透明暗底和暖色辉光，技能图标定稿前默认不显示；参数和实景见 [技能栏说明](skill-hud.md)。

人物页的装备列表中，金色菱形表示已装备，蓝色高亮表示当前选中。右侧比较显示更换该槽位后实际发生的属性变化，长说明可以在详情区滚动。16 个格子是人物页装备列表的每页展示数量；通用背包另使用 30 格分页，均不代表容量上限。技能装配区在槽位较多时支持滚动，移动或选择技能后保留滚动位置。

## 界面参数

在正式地图选中 `LoadoutUI` 节点，可从检查器调整这些参数。

| 参数 | 当前值 | 含义 |
| --- | --- | --- |
| `ui_scale` | 0.8 | 书本整体缩放，范围 0.6～1.5；默认外部画布约占视口宽度的 77%，书本实际宽度约为 74%。调小可显示更多地图，调大时自动限制在屏幕内；运行时调节立即生效 |
| `font_size` | 24 | 中文基础字号，范围 16～28；标题和说明按此分级，字体随书本一起缩放。修改后重新运行生效 |
| `world_dim_amount` | 0.18 | 游戏世界压暗程度，范围 0～0.65；0 保留原始地图亮度，越大背景越暗。运行时调节立即生效 |
| `portrait_texture` | `assets/meowa/ui/journal/portrait.png` | 书页内的独立人物立绘，可替换为后续正式角色资源；不改变地图中的角色贴图 |
| `portrait_scale` | 1.0 | 人物立绘相对书页的大小，范围 0.75～1.15；运行时调节立即生效 |
| `skill_slot_count` | 4 | 可装配技能的槽位数量，范围 1～8；缩减会移除超出槽位的装配，已学习技能保留 |
| `toggle_key` | Tab | 打开与关闭界面的物理按键；ESC 同时保留关闭功能 |
| `catalog` | `data/loadout_catalog.tres` | 装备和技能目录，决定名称、图标、类别、属性与展示数值 |
| `training_rules` | `data/training_rules.tres` | 共用的角色基础属性和训练规则；人物页显示基础、训练与装备的合计 |
| `starting_equipment` | 6 件演示装备 | 首次创建状态时拥有的装备 ID；每类默认穿戴目录中第一件拥有的装备 |
| `starting_skills` | `fire`、`heal` | 首次创建状态时已学习的技能 ID |
| `starting_assignments` | `fire`、`heal` | 首次按顺序填入技能槽的技能 ID |
| `save_enabled` | true | 自动保存穿戴、学习与装配状态；独立验证时可关闭 |
| `save_path` | `user://equipment_skills.json` | 状态存档路径；已有有效存档优先于初始内容 |

损坏或不兼容的存档会保留原文件，并停止自动保存以避免覆盖。右侧书页上方的便笺文字、右下角的操作说明与保存文字已移除；内部保存反馈仍供训练窗口读取。调整初始内容不会覆盖已有存档；验证新配置可临时指定独立的 `save_path`。

## 手帐动效

开合、悬停与按压、切页和穿戴反馈使用现有美术，由程序控制。打开时书本浮起并放大，背景逐渐压暗；关闭时反向收起。悬停放大图标并提亮按钮，按压只移动绘制画面，点击区域保持稳定。页签轻微抬起，内容横移并淡入；书本边框保持固定。

穿戴时图标沿轻微弧线飞向人物页的装备槽，到达后槽位闪过暖金色边光，属性数字平滑过渡。背包页使用右侧装备预览作为到达位置。装备数据与存档立即更新，动效不延迟穿戴结果。连续更换会取消旧飞行，切页和关闭时清理临时图标。人物、背包和技能页签均有切换过渡，世界、天气和声音持续运行。

在 `LoadoutUI` 的“手帐动效”分组调节参数。时长单位为秒，位移使用书本 2048×1152 设计坐标中的像素，最终屏幕位移随 `ui_scale` 缩放。参数调整用于后续交互；总开关关闭时立即恢复静态界面。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `motion_enabled` | true | 动效总开关，可用于减少动态或对比；管理逻辑保持可用 |
| `open_duration`／`close_duration` | 0.24／0.16 | 打开、关闭时长；0 立即完成 |
| `open_start_scale` | 0.96 | 打开时相对于最终书本尺寸的比例；1 只保留淡入与位移 |
| `open_lift` | 12 | 打开时向上浮起的距离；0 关闭位移 |
| `hover_duration` | 0.10 | 悬停和按压反馈的过渡时长 |
| `hover_scale` | 1.04 | 悬停图标的放大倍率；1 保持原尺寸 |
| `hover_brightness` | 0.08 | 悬停按钮的提亮幅度；0 保持原亮度 |
| `button_press_distance` | 2 | 按压时按钮画面下沉距离 |
| `page_duration`／`page_slide_distance` | 0.18／12 | 内容淡入时长与横向位移 |
| `equip_duration` | 0.28 | 装备图标飞行时长；0 使用即时槽位反馈 |
| `attribute_duration` | 0.30 | 属性数字过渡时长；0 显示即时数值 |
| `equip_glow_color` | `#e5c578` | 装备槽到达反馈的暖金色 |

实景演示：[手帐程序动效](equipment-skills-preview/motion.webp)。动画控制位于 `scripts/ui/journal_effects.gd`，按钮绘制反馈位于 `shaders/journal_button.gdshader`。

## 装备与技能配置

打开 `data/loadout_catalog.tres`，展开 `equipment` 或 `skills` 条目即可编辑资源。

| 配置 | 字段 | 含义 |
| --- | --- | --- |
| 装备 | `id` | 稳定且唯一的标识；拥有状态和存档通过该 ID 引用 |
| 装备 | `slot` | 武器、防具或饰品 |
| 装备 | `attribute_bonuses` | 属性名到加成值，例如 `attack: 8` 表示攻击增加 8 |
| 装备 | `skill_bonuses` | 技能 ID 到百分比，例如 `fire: 18` 表示火焰效果强度增加 18% |
| 技能 | `id` | 稳定且唯一的技能标识 |
| 技能 | `values` | 当前展示 `power` 效果强度与 `cooldown` 冷却秒数 |
| 两者 | `display_name`、`description`、`icon` | 界面名称、说明和可替换图标 |

不同装备对同一技能的百分比相加，再乘以基础 `power`。例如法杖火焰加成 18%、护符加成 10%，合计 28%；基础效果强度 20 显示为 25.6。冷却时间暂不受该加成影响。

目前每个装备 ID 对应一种拥有状态，重复获得不会叠加为多个物品实例。特殊词条保留为后续候选；当前没有随机词条、技能施放、伤害结算或穿戴后角色换装。

## 代码入口

- `scripts/rpg/loadout_state.gd`：拥有、穿戴、学习、装配、交换槽位、属性汇总和存档。
- `scripts/rpg/equipment_definition.gd` 与 `skill_definition.gd`：可在检查器编辑的内容资源。
- `scripts/ui/loadout_ui.gd`：手帐书页、页签、筛选与分页、详情比较、面板输入占用与状态反馈。
- `scripts/ui/loadout_tile.gd`：拖放数据与槽位校验。
- `scenes/ui/loadout_ui.tscn`：正式地图复用的界面入口。

掉落或奖励系统可调用 `LoadoutUI.state.acquire_equipment(id)`，学习系统可调用 `learn_skill(id)`；状态变化会自动刷新界面和存档。角色通过现有 `Player.get_attributes()` 读取合计属性。

## 美术与验证

美术来自已确认的 Meowa 手帐参考方案：透明书本底图、人物立绘、提取的页签与按钮、属性符号、六枚装备图标以及同风格的火焰／冰晶／雷光／治疗图标。运行资源位于 `assets/meowa/ui/journal/`，采用线性过滤以支持平滑缩放。书本之外的参考图背景与道具已移除，真实地图直接显示在窗口后方；书页内保留原有插画。

名称、说明、属性、选中状态与按钮均由 Godot 实时绘制。历史参考图及组件包位于 `docs/equipment-skills-reference/`；实际运行使用项目中的透明底图和技能图标。

底图中多余的分类占位框和详情区半透明条已通过 Meowa 修除，右侧插画收在上方图标区，名称与说明使用空白纸面。搜索框和分类按钮统一排列并保留边距；搜索框获得焦点时继续使用浅色底，便于阅读。装备槽的图标、类别与名称分开排布，字号变大时自动压缩图标区域，避免文字碰到边框；过长名称在格子和详情标题中省略显示，完整名称可在物品提示中查看。

当前是部分拆分的界面。人物立绘、装备／技能图标、属性符号、页签及主要按钮皮肤均为独立资源，文字和交互区域为独立控件。书皮、左右纸页、背景插画、花纹、固定空格框、便笺和关闭按钮的装饰图形仍合并在 `foundation.png` 中；交互区域可以单独修改，但若要大幅移动格子或更换整体版式，需要先拆分并修补底图。整个界面由脚本在运行时组装，尚未将每个区域制作成独立可复用场景。

实际运行验证覆盖缩小窗口、背景压暗调节、页签与搜索聚焦、18 件装备分页、4／8 技能槽与滚动位置保留、Tab 和 ESC、鼠标选择、穿戴与卸下、双击、真实拖放和槽位交换、搜索筛选、UI 保存后重载、损坏存档保留，以及共用界面工具的训练窗口兼容性。模型测试还验证未拥有装备、未学习技能、重复装配和过期存档条目的处理。验证截图沿用项目当前开发相机和景深设置。

本轮修正另核对了 `font_size` 为 24 和 28 时的搜索区、装备槽文字边距、详情标题以及 4／8 技能槽布局，并复查穿戴、双击、真实拖放、搜索和存档重载。

动效验证覆盖开合中途反向、连续穿戴、快速切页、关闭时清理临时图标、输入占用持续到书本隐藏、关闭动效、零时长以及外部暂停状态的保留。实景鼠标检查确认悬停与按压不移动点击矩形，穿戴数值和存档重载正确。版本校验同时兼容 JSON 读回的整数数值。
