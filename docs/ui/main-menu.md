# 动态主菜单

F5 运行正式 `World` 时，先显示内嵌动态主菜单；地图准备就绪后，点击开始原地进入同一个 World。也可打开 `demoWithMeowa/1/scenes/ui/main_menu.tscn` 按 F6，或从「地图切换 → 回弹 · 动态主菜单」进入，这些入口会提前准备 World 并转入内嵌菜单。

当前标题暂用「回弹」，居中保留开始、设置和退出。鼠标、上下键、Enter 与 Esc 可操作；设置期间环境演出继续。

进入地图后，在右上角「设置」底部点击「返回主菜单」，结束当前一局；再点「开始游戏」即可重新查看入场镜头。返回时先呈现菜单，再通过波次公共清理流程移除怪物、待生成队列、攻击、成长和得分，恢复人物状态与出生位置。地图几何、导航和共用资源继续复用，不销毁或重建 World，也不重复播放隐藏入场预热；连续点击只受理一次，不保留本局进度。

## 表现与接入

Meowa 从确认的统一怪潮参考中整理干净夜景与六种透明角色；原生裁切素材保存在 `assets/meowa/ui/main_menu/`，未重采样。背景、人物和怪物独立运动。循环包含蓄力聚点、借墙反弹、贴地火带、怪物错峰翻飞、近景史莱姆放大掠过和重新集结；叠加细雨、雨纹、暖色浮尘、灯光湿地闪动与鼠标视差。菜单独立于演出位移，具有红色选中标记、暖金线条扫光和按压收缩。

火带与实机共用 `shaders/combat/ground_fire_surface.gdshaderinc` 的噪声轮廓、像素切边、亮火／燃烧／余烬规律，读取正式人物 `data/combat/scenes/world/player/action_visuals.tres` 的宽度、三阶段时长、能量与像素密度。主菜单将同一地面模型投影到二维背景；人物与火带共用演出路径和逐段经过时间，尚未经过的位置不提前点燃，余烬固定在地面消散。只预建三个路段网格和材质并循环复用，减弱动态时固定演出时刻。二维画面单独压缩自发光亮度，未增加火舌、额外灯光或真实战斗。

`WorldMainMenu` 接在正式 World 内，菜单显示期间地图保持真实实例，完成出生、导航构建与战斗反馈对象储备。隐藏预热只抽取入场的四个代表状态，每个等待两次真实绘制，不按整段 8.2 秒的演出时长等待，也不接管菜单输入或播放穿雾声音。随后正常相机再绘制两帧才启用开始。点击开始仅播放反馈、移除菜单并调用该 World 的完整正式入场，不再加载地图或替换实例。菜单暂时隐藏玩法 HUD、阻挡游戏输入，并与 World 共用混音；预热不自动开战。

独立菜单及没有内嵌菜单的其他地图入口，在开始之前准备正式 World，准备中禁用开始，设置和退出仍可使用；准备失败可点击开始重试。正式 World 内的返回按钮直接重用本实例，只在本局重置完成前短暂禁用开始。脚本资源在主线程初始化，正式 F5 启动由 World 本身完成资源加载。点击开始后的确认动画与资源加载分离；完整启动及首次绘制耗时仍需要在目标机器上人工验收。

设置复用项目声音混音与画质设置。动感强度和减弱动态独立保存到 `user://main_menu.cfg`；声音仍使用 `user://audio_mix.cfg`，画质沿用 `user://graphics_settings.cfg`。

菜单音乐与进入后的准备阶段共用探索曲的单曲增益，内嵌菜单同时读取 `MapEffects/BGM.music_volume_db`，不再单独压低菜单 BGM。两处设置中的「音乐」共用 Music 总线与本机存档。探索音源约 −11.4 LUFS、单曲增益 −19.5 dB，战斗音源约 −16 LUFS、单曲增益 −15 dB，稳态输出响度均约 −31 LUFS（叠加统一增益与本机调节前）；保留原曲动态、开始淡出与游戏淡入。

## 调整入口

| 节点 | 参数 |
| --- | --- |
| MainMenu | 标题、进入场景、开始反馈时长、演出音量 |
| World → MapEffects/BGM | 菜单与游戏统一音乐增益；各曲音量在曲目资源调整 |
| World → WorldMainMenu | 启动时显示菜单、预热入场效果 |
| Stage | 循环时长、动感强度、鼠标视差、反弹轻震、减弱动态 |
| Stage → 环境 | 雨丝数量、火带强度、灯光与环境动效强度 |

中文统一使用 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) 12px 简体版，许可证及上游署名随字体保存在 `assets/fonts/fusion_pixel/`。`project.godot` 的 `gui/theme/custom_font` 将同一字体作为游戏默认值，主菜单、背包、选卡、设置、HUD、弹窗、工具提示及预览 UI 共用，局部主题保留各自皮肤、字号与颜色，取消楷体、微软雅黑等系统字体覆盖。字体导入关闭抗锯齿与子像素定位，主菜单直接复用同一资源；得分、伤害数字和专用按键字母仍使用独立的 Press Start 2P。

## 验收

`tests/test_world_main_menu.gd` 验证提前准备、隐藏预热、输入占用、就绪门槛和开始复用同一 World。`tests/test_main_menu.gd` 检查事件顺序、长帧边界、设置隔离、重复开始及旧加载接口，`tests/test_main_menu_fire.gd` 与 `tests/test_player_fire_trail.gd` 检查共用火带。以上为无界面逻辑检查。

`tests/test_return_to_menu.gd` 验证准备、战斗、休整与结算四种状态返回主菜单；检查往返始终只有一个 World、导航复用、不再预热入场，以及本局怪物、成长、得分和输入占用清理。每次重新开始仍触发正式入场并恢复控制。

人工在 F6 检查两轮演出、近景史莱姆和火带观感、按钮反馈、设置及 Esc、不同窗口比例，以及开始后的入场衔接。动画表现与声音主观强弱尚待人工验收。
