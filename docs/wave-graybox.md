# 波次循环灰盒

2026年10月12日。按用户最新范围，先验证基础战斗与波次休整，技能实际效果和成长随后讨论。

当前循环：**接近圆台并开始 → 基础战斗 → 清波直接休整 → 主动开始下一波 → 胜利／失败／撤退 → 重试或返回小院。**

## 试玩

在 Godot 的地图切换工具运行“正式连续地图”，或打开 `demoWithMeowa/1/scenes/world/world.tscn` 后按 F6。F5 的默认入口仍是视觉测试地图。

从小院前方的坡道向南走，靠近灰色小圆台 `(0, 0, 12.8)` 后按 **F** 开始。人物保持原有 WASD 移动、空格跳跃、Shift 瞬移和 QE 旋转。

- 基础攻击自动选择范围内、无遮挡的最近灰盒敌人。敌人命中时短暂变亮、头顶数字显示剩余生命。
- 胶囊敌人分批出现，短暂预告后追击，接触造成真实血量损失；多个敌人共享受击保护间隔。
- 清空本波后直接进入休整，停止刷怪；不倒计时、不自动回血，也不提供技能或成长奖励。按 **F** 或“开始下一波”继续。
- 休整可按 **Tab** 查看背包。技能页保留说明占位，左下技能槽为空；战斗期间不打开会占用移动的管理页。
- 最后一波清空后结算。生命耗尽或离开南侧战斗范围也会结束本轮；结果页可以重试，或返回小院。休整时也可主动撤退。

这版没有新美术、具体人物技能、范围伤害、减速、连锁、强化选择或永久解锁。原来的蓝色史莱姆继续保留外观与巡逻展示；波次敌人使用独立灰盒胶囊。现有装备、训练、种植和学习存档不因挑战而改写，挑战本身不保存成长进度。

## 可调参数

选择正式地图的 **WavePrototype**。以下均为测试基线，数值不是最终玩法方案。

| 参数 | 默认 | 用途 |
| --- | --- | --- |
| `total_waves` | 3 | 每轮总波数 |
| `first_wave_enemies` / `enemies_per_wave` | 5 / 2 | 首波数量与每波增加的数量 |
| `spawn_interval` / `spawn_warning` | 1.3 / 0.8 秒 | 分批生成的间隔与出现前预告时间 |
| `enemy_health` / `enemy_speed` | 20 / 1.35 | 敌人的生命和移动速度，各波保持相同 |
| `contact_damage` / `hurt_interval` | 8 / 0.7 秒 | 接触伤害与共享受击保护时间 |
| `attack_damage` / `attack_interval` / `attack_range` | 10 / 0.8 秒 / 6.4 米 | 通用基础攻击，用于检验清波速度 |
| `battle_area` | `Rect2(-12, 9.6, 24, 12.8)` | 战斗的世界 XZ 范围；改变后重启以重建可通行生成点 |
| `interaction_radius` / `interact_key` | 2.5 米 / F | 开始挑战的距离与交互键 |
| `random_seed` | 12102026 | 生成位置的随机种子，重启生效 |

每轮开始与返回小院时恢复生命，波间保留当前血量。生命上限继续来自角色真实属性；基础攻击使用上表参数，尚未接入装备攻击、防御、蓝量消耗或掉落经济。

## 实现与验证

可复用组件：`scenes/shared/wave_prototype.tscn`。控制器、占位敌人与临时界面位于 `scripts/combat/`。技能与成长的早期尝试已经从当前代码撤下。

`tests/test_wave_prototype.gd` 检查 F 开始、最近目标的基础攻击、墙体遮挡、QE 不改变目标逻辑、真实血量与受击间隔、失败重试、三波清波／休整／胜利、无限时安全休整、技能页占位、空技能栏、原存档状态保持、越界结束和主动撤退。

实际 D3D12 / Forward+ 检查了基础自动攻击、清波休整、Tab 占位页、失败、重试与返回按钮，沿用当前相机和景深基准。实机检查使用单个敌人隔离交互，不改变正式场景默认波次数量。
