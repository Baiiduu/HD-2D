# UI 操作音效

主菜单、游戏内设置与成长选卡共用 UI 音效架构，复用 Meowa 生成的 10 个短音效。声音沿用纸页、皮革、木质和金属扣质感；角色背包、装备、技能配置、物品快捷栏及训练原型的旧接法保留。World 当前关闭人物／背包管理页的玩家入口、展开快捷栏按钮与物品数字快捷键，主菜单和游戏内按键页隐藏对应改键项；底层角色数据、保存、局内成长与升级选卡继续正常使用。City 与独立原型保持自身配置。

## 公共接入

三个层次分别负责分配、播放和绑定：

- `UISoundBank.actions` 将操作名称映射到声音槽；`UIAudio.sounds` 可为某个界面指定独立资源，默认共用 `data/audio/ui_sounds.tres`。
- `UIAudio.play_action(action)` 接受操作名称，复用原有 6 路声音池、UI 总线、本机音量与素材静音配置。旧界面的 `play(cue)` 与战斗提示的 `play_clip` 保持兼容。
- `UIAudio.bind_controls(page)` 一次绑定页面，新增子控件通过节点事件加入；重复绑定不叠加，没有每帧扫描。释放声音节点后自动断开连接，控件可由新的声音节点重新绑定。

| 语义操作 | 默认声音 | 使用位置 |
| --- | --- | --- |
| `open`／`close` | `journal_open`／`cancel` | 实际打开／返回界面，包括 Esc |
| `button`／`confirm` | `confirm` | 普通按钮、成功确认 |
| `toggle`／`choice` | `select` | 开关激活、下拉选择、鼠标及键盘明确选择成长卡 |
| `tab` | `page_turn` | 页签；游戏内重复点当前页保持静音 |
| `adjust` | `select` | 滑条拖动结束、键盘或滚轮调值、数字步进及文本确认 |
| `error` | `error` | 无效改键等明确失败结果 |
| `navigate` | `select` | 主菜单选中移动；成长卡与可用确认／重抽按钮的鼠标悬停 |

默认操作可在 Godot 检查器的 `actions` 字典改配，空声音名称表示静音。单个控件通过字符串／StringName 元数据 `ui_audio_action` 覆盖默认操作，例如设为 `close`；设为空字符串时跳过自动声音，供界面自己的开合／成功／失败回调统一发声。新业务操作只需在资源增加映射；需要新增声音槽时再扩充 `UISoundBank`，控件不直接引用音频路径。

新页面示例：

```gdscript
@onready var feedback: UIAudio = $UIAudio

func _ready() -> void:
    $Panel/Back.set_meta(&"ui_audio_action", &"close")
    feedback.bind_controls($Panel)
```

窗口开合应在实际状态变更时调用 `play_action`，相应按钮设置空操作，避免一次点击叠加按钮声与开合声。程序初始化、读取存档、同步勾选与数值、搜索输入和隐藏／禁用控件不发声；连续调值按真实时间限频，不限制实际参数更新。滑条每次改变后松手只响一次。按键捕获的成功、冲突与 Esc 取消由业务报告，不让捕获 Esc 同时关闭设置。

游戏内设置与 World 独立人物属性面板打开时暂停游戏。两处界面和 `UIAudio` 保持 `PROCESS_MODE_ALWAYS`，按键捕获、音量调节与操作反馈仍可使用；人物页开合与切类复用 `open`／`close`／`tab`，不新增音源。BGM 沿原有独立音乐通路连续播放，不暂停、重启或换曲。战斗音效池沿既有场景树暂停检查保持原声道及声音时钟，关闭后继续；升级冻结仍独立生效。暂停与恢复的无界面状态回归见 `tests/test_settings_pause.gd`、`tests/test_character_panel.gd`，实际音乐连续性及操作听感由人工验收。

正式战区的成长选择另外使用核心音效包：一轮开牌播放一次揭晓声，成功重抽才播放换牌声，确认采用成长生效音而不叠加原确认声；普通手帐界面继续沿用下表。经验收取合并短间隔提示，升级按实际升级批次提示，连续待选保持原选择流程。开战、实际怪潮入场和完整清波使用独立短提示，小股怪物不触发怪潮声。相关配置在 `MapEffects/CoreFeedbackAudio`，升级冻结期间 UI 声音仍可正常播放。

`GrowthChoiceUI` 的打开、明确选卡、确认和 Esc 取消分别使用 `open`、`choice`、`confirm`、`close`，普通与史诗选卡及开局技能选择共用该组件。悬停通过控件的鼠标移动事件播放 `navigate`，每次进入仅提示一次；在卡内持续移动、程序换牌后出现在静止指针下、未全部揭晓、隐藏或禁用时不提示，也不会替玩家选中卡片。沿用公共声音限频、六路池、UI 总线及本机混音。重抽由原成功事件提供核心换牌／揭晓音，不额外播放打开界面或通用按钮确认；已经选中的卡片再次点击保持静音。

| 操作 | 声音资源 |
| --- | --- |
| 打开手帐或训练界面 | `journal_open`，轻柔开合 |
| 关闭界面 | `journal_close`，合上书页 |
| 切页或翻页 | `page_turn`，纸页翻动 |
| 选择物品、技能、分类或快捷槽 | `select`，轻木质点选 |
| 开始拖动物品／技能 | `drag_start`，拿起物品 |
| 成功放入物品栏／技能槽或交换位置 | `item_drop`，轻柔落槽 |
| 穿戴、替换或卸下装备 | `equip`，金属扣合 |
| 学习技能、训练成功、收藏或整理 | `confirm`，短成功提示 |
| 移除绑定或在空白处取消拖放 | `cancel`，柔和回落 |
| 无效操作或拖进不匹配的装备／技能槽 | `error`，低沉双点提示 |

搜索输入、悬停、自动刷新、初始化和读取存档保持安静。已打开的界面再次刷新、重复关闭请求不会重播开合声。点选声带短间隔限制，6 个播放通道保留短尾音并限制连续操作的叠加量。

## 调整声音

在 Godot 打开 `scenes/audio/ui_audio.tscn`，选中 `UIAudio`：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `enabled` | true | 只开关 UI 音效；关闭时停止正在播放的 UI 声音 |
| `volume_db` | -12 | UI 总音量，dB；越低越轻，不修改音乐或环境声 |
| `audio_bus` | UI | 共用 UI 总线，服从设置中的「界面音效」分组音量 |
| `repeat_interval` | 0.05 | 同类声音的最短间隔，秒 |
| `action_intervals` | `adjust: 0.12` | 连续操作独立限频，秒 |
| `sounds` | `data/audio/ui_sounds.tres` | 操作音效配置资源 |

打开 `data/audio/ui_sounds.tres` 可逐项替换声音，并通过 `gains_db` 调节某一种操作的相对音量。默认点选降低 4 dB、拖动开始降低 3 dB、无效操作降低 2 dB。资源为空时该操作静音。

「参数总览 → 声音」提供 GameSettingsUI 的 UI 音效配置及操作映射入口；也可直接编辑上述资源。主菜单与设置共用默认资源，调整一种音源无需逐个改按钮。`LoadoutUI.player_access_enabled` 是地图独立的背包入口开关，World 关闭；重新开放并重新运行后，相应改键项恢复，旧键位和存档不丢失。

运行 WAV 位于 `assets/meowa/audio/ui/`，Meowa 原始 MP3 保存在其 `source/` 目录。运行版本去除必要的起始空白、加短淡入淡出并控制峰值，长度约 0.41～0.48 秒，峰值不高于 -6 dBFS；播放时再叠加 UI 音量参数。

## 验证

`tests/test_ui_audio.gd` 回归原有手帐操作、训练、暂停兼容、静音和连续触发。`tests/test_ui_feedback.gd` 验证语义映射、重复／动态绑定、初始化静音、点击后隐藏或禁用、原生滑条与数字输入事件、设置页改键反馈、背包入口关闭与两处按键页隐藏。`tests/test_growth_choice_audio.gd` 验证普通／史诗卡及按钮悬停、鼠标与键盘选择、静止指针、揭晓资格、语义重映射、成功重抽、关闭与静音，并通过实际核心连接检查换牌／揭晓和单次成长生效音。以上为无界面逻辑与控件输入检查；音色、音量和点击手感仍由人工验收。
