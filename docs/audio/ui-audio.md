# UI 操作音效

已为背包、人物装备、技能配置、物品快捷栏及训练界面接入 Meowa 生成的 10 个短音效。声音沿用手帐的纸页、皮革、木质和金属扣质感；成功操作后才播放完成反馈。背景音乐、雨声和风声保留原有播放与音量。

| 操作 | 声音资源 |
| --- | --- |
| 打开手帐或训练界面 | `journal_open`，轻柔开合 |
| 关闭界面 | `journal_close`，合上书页 |
| 切页或翻页 | `page_turn`，纸页翻动 |
| 选择物品、技能、分类或快捷槽 | `select`，轻木质点选 |
| 开始拖动物品／技能 | `drag_start`，拿起物品 |
| 成功放入物品栏／技能槽或交换位置 | `item_drop`，轻柔落槽 |
| 穿戴、替换或卸下装备 | `equip`，金属扣合 |
| 学习技能、训练成功、收藏或整理 | `confirm`，短成功提示 |
| 移除绑定或在空白处取消拖放 | `cancel`，柔和回落 |
| 无效操作或拖进不匹配的装备／技能槽 | `error`，低沉双点提示 |

搜索输入、悬停、自动刷新、初始化和读取存档保持安静。已打开的界面再次刷新、重复关闭请求不会重播开合声。点选声带短间隔限制，6 个播放通道保留短尾音并限制连续操作的叠加量。

## 调整声音

在 Godot 打开 `scenes/audio/ui_audio.tscn`，选中 `UIAudio`：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `enabled` | true | 只开关 UI 音效；关闭时停止正在播放的 UI 声音 |
| `volume_db` | -12 | UI 总音量，dB；越低越轻，不修改音乐或环境声 |
| `audio_bus` | Master | 播放总线，可改为项目后续配置的专用 UI 总线 |
| `repeat_interval` | 0.05 | 同类声音的最短间隔，秒 |
| `sounds` | `data/audio/ui_sounds.tres` | 操作音效配置资源 |

打开 `data/audio/ui_sounds.tres` 可逐项替换声音，并通过 `gains_db` 调节某一种操作的相对音量。默认点选降低 4 dB、拖动开始降低 3 dB、无效操作降低 2 dB。资源为空时该操作静音。

运行 WAV 位于 `assets/meowa/audio/ui/`，Meowa 原始 MP3 保存在其 `source/` 目录。运行版本去除必要的起始空白、加短淡入淡出并控制峰值，长度约 0.41～0.48 秒，峰值不高于 -6 dBFS；播放时再叠加 UI 音量参数。

## 验证

音效测试覆盖初始化静音、成功／失败分流、操作回调、训练、暂停兼容、静音和连续触发。实机验证包含真实鼠标拖放、取消、不匹配槽位、数字键与搜索，并录制了 UI 播放总线，确认实际有声音输出。背包、手帐动效及世界持续运行的回归检查已通过，技能栏原脚本、场景和素材保持不变。
