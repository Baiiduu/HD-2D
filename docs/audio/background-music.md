# 背景音乐与曲池

正式地图通过 `MapEffects/BGM` 管理音乐。曲目、场合曲池和播放器分别配置，音乐独立走 `Music` 总线，不占战斗音效播放预算。

## 当前播放规则

| 游戏状态 | 曲池／音乐 | 衔接 |
| --- | --- | --- |
| 准备、开局技能选择 | `exploration`／现有探索曲 | 首次淡入 |
| 开始战斗、巨量怪潮模拟 | `combat`／《雨灯疾行》 | 与探索曲交叉淡化 |
| 波间休整、继续下一波 | 保持 `combat` | 沿用当前播放进度 |
| 升级选卡、管理界面、战斗冻结 | 保持当前曲池 | 音乐与循环继续运行 |
| 胜利、失败、主动撤退结算、返回准备 | `exploration` | 与战斗曲交叉淡化 |
| 快速重试 | 按真实波次状态回到 `combat` | 若战斗音轨尚在淡出，则反向淡化并沿用进度 |

开关音乐默认用 3 秒淡入淡出，场合之间默认用 2.5 秒交叉淡化。重复请求同一场合不会重播或重新选曲。首次播放从开始淡入时启动，避免场景同步载入时静默跳过前奏。

## 配置入口

代码与场景路径以下均相对于 `demoWithMeowa/1/`。

- 播放器：`scripts/audio/bgm.gd`，正式节点为 `world.tscn → MapEffects/BGM`。
- 单曲资源：`scripts/audio/bgm_track.gd`；现有配置在 `data/audio/music/exploration.tres` 和 `garden_battle.tres`。
- 场合曲池：`scripts/audio/bgm_playlist.gd`；现有配置在 `data/audio/music/exploration_playlist.tres` 和 `combat_playlist.tres`。
- 参数总览「声音」可查看节点、曲池和单曲参数。

| 参数所在处 | 参数 | 作用 |
| --- | --- | --- |
| BGM 节点 | `music_enabled` | 独立开关音乐，淡出后停止并释放两路播放实例 |
| BGM 节点 | `music_volume_db` | 整组音乐增益；正式地图为 0 dB，再叠加单曲增益 |
| BGM 节点 | `music_transition_time` | 不同场合间的交叉淡化时间 |
| BGM 节点 | `music_fade_time` | 开关音乐时的淡化时间 |
| BGM 节点 | `playlists` | 场合曲池列表 |
| BGM 节点 | `session`、`follow_battle_session` | 波次事件连接与自动选曲开关 |
| 曲池 | `context_id` | 场合标识，须在该节点内唯一 |
| 曲池 | `tracks` | 对应场合可以播放的曲目 |
| 曲池 | `play_order` | 顺序轮播，或随机且不连续重复；单曲时循环自身 |
| 单曲 | `track_id`、`track_title`、`stream` | 稳定标识、显示名称与音频资源 |
| 单曲 | `volume_db` | 单曲增益，探索曲 −18 dB、战斗曲 −15 dB |
| 单曲 | `loop_crossfade` | 曲尾衔接时间，探索曲 6 秒、战斗曲 3.87 秒；短曲自动缩短 |

最终音量由单曲增益、节点增益、淡化曲线及 `Music` 总线共同决定。原音源不修改，播放器复制播放资源并关闭引擎自带循环，统一控制接缝。

## 后续新增 BGM

1. 导入音乐文件，并新建 `BgmTrack` 资源，设置唯一 `track_id`、音源、音量和曲尾衔接时间。
2. 添加到对应曲池的 `tracks`。同一场合多首音乐会按配置顺序或随机轮播，每次曲尾自动衔接下一首。
3. 如需新场合，新建 `BgmPlaylist`、设置唯一 `context_id`，加入 BGM 节点的 `playlists`，由对应玩法调用 `play_context(&"场合标识")`。

未知场合、空曲池和无效候选不会打断正在播放的音乐。曲池中的空条目、无效音源及重复曲目标识会在选曲时跳过。相同曲目的 `track_id` 与音源应保持一致。

## 衔接与资源生命周期

播放器固定使用两个 `AudioStreamPlayer`，以等功率曲线衔接。切换中反向请求现有音轨时保留当前增益与播放进度；两路均占用且请求第三首时，先在至多 0.25 秒内收完当前衔接，再播放最新待播目标。过期请求不累积，不使用可叠加的延迟任务或 Tween。

只有进入曲尾窗口时才选择下一首。退出的音轨会停止并释放播放资源；音乐关闭且淡出结束后两路都释放，并停止节点处理；地图退出时停止音乐、断开波次信号。

共享地图效果和旧预览没有配置曲池时，继续使用原有 `music_stream`、节点音量和 `music_loop_crossfade`，沿用单曲循环方式。

## 验证

- `tests/test_bgm.gd`：曲池选择、状态路由、快速反向／第三曲／最新请求、开关恢复、旧单曲兼容与资源回收；可无窗口运行，真实播放进度需原生音频验证。
- `tests/test_bgm_audio.gd`：使用真实 MP3／OGG 音源和 Music 总线采集，覆盖两首曲尾、曲间切换、暂停、快速重试及正式地图开战／休整／冻结／结算。测试需原生音频设备，录音仅保存在 D 盘工作目录。
