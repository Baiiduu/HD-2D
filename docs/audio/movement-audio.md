# 人物脚步、起跳与落地

制作或修改音源前先读 [Meowa 音效制作与接入指南](meowa-sfx-production-guide.md)，其中整理了提示词审核、起声延迟、成套音色、变体、响度和试听接入的现行要求。

采用已确认的轻柔自然拟音。草地是短促的叶片摩擦，卵石路是温润的触地声；石板、泥土、木板、金属保留各自的质感。起跳以衣料摩擦和很轻的蹬地声为主，落地使用实际承重面的声音，并随下落速度调节力度。

正式战区另外接入 `MapEffects/CoreFeedbackAudio`：本体蓄力起手、稳定循环、满蓄提示、发射、石／木／金属反弹、拨怪眩晕及收势均由真实动作事件触发。循环随取消或发射结束，满蓄只提示一次，升级冻结暂停战斗声音；反弹直接读取已有碰撞，不为声音增加射线查询。连续反弹按命中材质选择对应声音，并保留有限音高变化。

World 开启击杀击飞时，普攻、弹射挥剑和奔雷造成的史莱姆／普通生物死亡声由 `death_impact_gain_db` 额外提高，默认 +4 dB，优先级 35；密集死亡仍由原合并窗口处理，不提升到危险／受伤预留通道。壶兽保留独立碎裂声，其他远程死亡沿用原优先级。声音页的死亡试听同步当前地图增益和本机单条混音；参数总览「声音」可调“近身与奔雷死亡声增益”。

World 设置 `charge_energy_audio_enabled=false`，停用旧起手 S01 与能量循环 S02，只保留现有聚力风 S54 和独立的 S03 满蓄确认。聚力风随真实进度渐强，满蓄保持稳定，取消／发射短淡出；World 优先级 75，高于普通命中，低于危险／受伤，被抢占后最多每 0.2 秒尝试恢复。满蓄只提示一次，刚满即松手仍确认，不将提示时刻烘焙进固定长度音源。S03 已选用聚气收束音源 `charge_ready_gathering.wav`，World 事件补偿调整为 -7 dB 以适配新音源。World 音源库继承共享库并单独排除发射原变体 1，只播放已认可的原变体 2；对照试听仍保留 S04／S05 编号，并标记 S04 停用。新生成音色须先审核提示词。旧音源和 City 配置保留兼容，重新开启旧起手／循环时仍使用原渐强参数。

World 的 `MapEffects/ChargePresentation → 蓄力声音退让` 随同一蓄力进度，临时压低音乐和风雨，满蓄默认分别 -2.5／-3 dB。直接叠加在 `GameAudio` 的 Music／Ambience 分组混音上，不改基础音量、本机保存值、试听音源、战斗声音预算或声音播放速度。取消与发射后平滑恢复，退出和阶段切换立即清理；可在参数总览「声音」将两项设为 0 关闭退让。

弹射飞行与自动环绕使用已选的 Meowa B「动能气流」。`flight_loop.wav` 为 48 kHz 单声道循环，保留原始 MP3，只在首尾交叠 20 毫秒消除循环接缝。声音直接读取 `PlayerRicochet.flight_speed`，按固定参考速度调节音量，超过参考速度后封顶；不按每次发射速度重新归一化，也不因转向或碰墙重新播放。复用 `GameAudio` 的一个跟随声道、声音预算和本机混音，升级冻结时暂停；更高优先级反馈可以抢占，仍在飞行时最多每 0.2 秒尝试恢复，已停止的尾音不重新创建。

在正式 `world` 的 `MapEffects/CoreFeedbackAudio → 弹射飞行动能气流`，或「参数总览 → 声音」中调整：

| 参数 | 默认值 | 含义 |
|---|---:|---|
| Flight Audio Enabled | 开启 | 只控制持续气流，关闭立即释放声音 |
| Flight Gain Db | -5 dB | 参考速度时相对于核心动作音量的增益；当前合计 -12 dB |
| Flight Low Speed Gain Db | -12 dB | 接近零速时额外减小的音量，速度上升后平滑回到 0 dB |
| Flight Reference Speed | 12 米／秒 | 达到最大气流音量的实际速度 |
| Flight Volume Smoothing | 0.10 秒 | 起声及速度变化的平滑时间常数，0 为立即跟随 |
| Flight Fade Out Seconds | 0.22 秒 | 停止／移动取消后的淡出时长，0 为立即结束 |

停止时从当前振幅淡出，完成后释放声道并停止逐帧更新；快速再发射沿用尚未淡完的同一循环。重试、失败、关闭音效与卸载场景清理旧循环。声音调试新增 `S41 弹射动能气流`，以参考速度音量试听，单条增益／静音同样作用于真实飞行；S01～S40 编号保留。

## 地表过渡与节奏

- 跑步音效跟随 8 帧动画的第 0、4 帧触地，动画速度取实际移动速度。停步、空中、顶墙不持续播放脚步。
- 地面查询先确定人物实际站立的碰撞面，再识别 Terrain 的底材和覆盖层。道路与泥土使用和着色器一致的 4×4 图集索引、透明阈值和覆盖顺序。
- 台地边缘的垂直射线若落空，使用身体真实的脚下碰撞点；不会因为脚下射线落空短暂插入默认石面声。
- 脚下中心与四周共五次采样，在可见的材质边缘混合两种声音；权重再按时间平滑。每一步采用等功率混合，保持过渡时的响度。
- 同类多条素材避免连续重复，并添加很小的音高和音量变化。两次脚步可以保留彼此的短尾音。
- 起跳、落地各触发一次。出生点下落安置不播放落地声；跳到另一种地面时，落地直接读取新的材质。
- Q/E 旋转镜头不会改变人物音效的音量和地表判断。

## Godot 参数

在地图中选中 `Player/MovementAudio` 即可调节。要修改所有地图的通用默认值，打开 `scenes/audio/player_movement_audio.tscn`。

| 参数 | 默认值 | 含义 |
|---|---:|---|
| Enabled | 开启 | 动作音效开关 |
| Volume Db | -8 dB | 人物动作音效总音量 |
| Step Volume Db | 0 dB | 脚步相对于总音量的增益 |
| Footprint Radius | 0.22 米 | 脚下混合采样半径；越大，材质过渡区域越宽 |
| Surface Blend Time | 0.18 秒 | 材质权重的平滑时间常数；约三倍时间接近新材质的 95%；0 立即跟随采样 |
| Contact Frames | 0、4 | 跑步触地帧；更换动画时可调整 |
| Minimum Step Interval | 0.12 秒 | 防止快速转向造成重复踏步；实际也按移动速度限制间隔 |
| Pitch Variation | 0.04 | 音高上下变化约 4% |
| Volume Variation Db | 0.6 dB | 每一步的轻微音量变化 |
| Jump Volume Db | -4 dB | 起跳衣料声相对于总音量的增益 |
| Landing Volume Db | +1.5 dB | 落地声相对于总音量的增益 |
| Landing Reference Speed | 5.6 米/秒 | 普通跳跃的落地力度基准；较高落差最多增加约 3 dB |
| Landing Pitch | 0.88 | 落地触地声的音高，略低于跑步 |
| Audio Bus | Master | 输出总线，可指定项目中其他音效总线 |
| Sounds | movement_sounds.tres | 各种材质和起跳素材列表，可展开替换或增加同类变体 |

地表声音对应也可逐项调整，默认城市底材为卵石、赛博底材为金属、古风底材为石板、自然底材为草地。道路覆盖层为卵石，泥土覆盖层为泥土，桥面为木板。未标记的普通碰撞面使用 Fallback Surface，默认石板。

独立碰撞地面与建筑统一在 `StaticBody3D` 或具体 `CollisionShape3D` 的元数据中设置字符串 `collision_surface`：`stone`、`cobble`、`grass`、`soil`、`wood`、`metal`。对应旧整数 `movement_surface` 的 `0`～`5`，旧标记继续兼容；同一节点优先新标记，命中形状优先于身体和父节点。房屋门廊标记木板，台阶标记石面。

脚步和本体反弹共用 `scripts/core/collision_surface.gd`，消费原有碰撞的形状索引，不根据建筑类型、节点名字或渲染纹理猜测。围栏石底／石柱与铁杆、长椅木板与金属脚、花车车身与把手、花坛石池与木座椅分别标记；路灯和设备为金属，建筑实体墙为石材。水域挡块、镜印和空气边界分别标记 `water`／`mirror`／`boundary`，麻袋为 `fabric`，当前暂共用既有第一条本体反弹声；它们不伪装成石材，也不进入六类脚步素材索引。

`CoreFeedbackAudio → 碰撞材质反馈` 的 `bounce_surface_cues` 配置材质到音库事件的映射，默认石／木／金属分别选择原三类事件；未知或尚无独立音源的材质走 `default_bounce_cue`。新增建筑只需标记部位，新增材质只需扩展映射与已确认音库；不用增加建筑类型分支，不改碰撞速度、伤害、声音预算或本机增益。生成器重建时重新写入标记，不缓存过期节点。建筑接入示例见[制作规范](../visuals/building-production-guide.md)。
