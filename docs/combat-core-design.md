# 战斗核心：怪物、攻击与增益

版本：0.1，2026年10月13日。对应 [总体设计](rpg-game-design.md)。

用户确定的方向：HD-2D 类《吸血鬼幸存者》、较舒缓的波次与安全休整、约 7～8 种普通怪物加精英首领、约 10 种攻击方式，以及丰富的局内增益。本轮集中完善核心设计，不估算工期，不纳入种植。

以下具体职责、名称、等级、槽位、概率和幅度均是讨论提案，尚未实现或完成平衡验证。名称为功能暂名，世界题材与正式外形仍开放；当前只有蓝色史莱姆外观已确定。本文不授权生成美术或直接改造正式地图。

## 1 核心关系

**攻击决定怎样清怪，增益决定怎样放大这个打法，怪物决定什么时候需要改变走位与目标优先级。**

清群、单体、覆盖、机动与生存应存在取舍。每种攻击要有擅长的站位、明确薄弱场景和可观察的成长；普通怪要分别改变空间、时间或处理顺序。增加内容时沿这三条关系扩展。

候选内容：8 种普通怪、2 种精英变体、1 个首领；10 种自动攻击；24 种增益，其中 16 种属性、6 种机制、2 种互斥体型。燃烧、缓速、易伤、导电是其中四种机制产生的敌人状态，不再重复计为四张额外卡。

一局先建议 4 个攻击槽、6 个增益槽。攻击 4 级，属性增益 3 级，机制增益 2 级，体型只选一次。升级已占槽内容不再占新槽；这组容量需要结合一局成长数量试玩，不由已有 HUD 槽位反推定稿。

## 2 八种普通怪

| 编号与暂名 | 行为与压力 | 玩家对策 | 边界与识别要求 |
| --- | --- | --- | --- |
| M01 普通史莱姆 | 缓慢持续追击，靠群聚形成包围；基础数量主要由它承担 | 聚成一团清理，寻找缺口穿出；范围和环绕收益明显 | 沿用现有蓝色史莱姆；不突然冲刺，不兼任远射；新刷出的怪有预告 |
| M02 疾行者 | 低生命、快速接近，短时间填补玩家刚离开的空隙；接近后有一次停顿 | 及时清掉、转向或用击退争取距离；检验只堆远程输出的薄弱处 | 敌人速度明显、接近动作可辨；不具备高速贴身后仍无停顿的无限连击 |
| M03 盾壳兽 | 高生命、慢速、较抗击退，作为敌群中的队形锚点，压缩可用路线 | 绕开并持续输出，利用穿透、持续区或暴击；不要耗尽所有走位空间 | 不反射伤害、不完全免伤；高耐受通过轮廓与受击反馈表达，不能只给普通怪暗加生命 |
| M04 冲撞者 | 短暂蓄力锁定玩家当时的位置，沿预告方向直线冲撞；撞空或撞墙后休息 | 横移而非一直沿冲撞方向后退；停顿时反击 | 锁定后不继续追着玩家转向；碰墙停，不跨断层，鼓舞不会缩短已有预警 |
| M05 投射者 | 有视线时停下来发射低密度直线弹，保持中距离；被接近后优先换位而非继续射击 | 绕开射线、借障碍、逼近压制；追踪与穿透帮助处理后排 | 有发射准备动作，弹丸可避、遇墙消失；不能隔墙发射或用不可见的即时伤害 |
| M06 裂殖者 | 较慢；死亡后在原处预告，再分出两只弱小幼体，造成一次局部数量突增 | 先聚群、再用范围或连锁同时处理；留意死后的空间 | 只分裂一代；幼体不再分裂，使用普通史莱姆行为，不另算第九种怪；幼体同样必须清理才算清波 |
| M07 布场者 | 在玩家经过的地面位置先预告，再留下短时危险区，改变路线；自身伤害与耐受较低 | 避免反复沿同一路线绕圈，提前处理布场者，利用场地缺口 | 地面区域数量有限、会消失，不追着脚底瞬间生成；区域不蔓延过墙或爬上不相接的台地 |
| M08 鼓舞者 | 在有限半径增强附近普通怪的移动能力，使清理顺序有意义；自身输出弱 | 通过穿透、追踪或绕侧优先击杀；移开敌群，使其离开增益半径 | 范围与受益对象可辨认；同类光环只取最强，不叠加；不增强自身、精英与首领，不回血 |

八种应有不同轮廓、运动节奏与准备动作，不把八种数值配置或换色当成已完成八种怪物设计。除 M01 外，具体生物身份、配色与素材另行讨论。

预警初始测试值可取：冲撞约 0.8 秒、投射约 0.6 秒、危险区约 1 秒。它们是试玩起点，需在当前开发镜头、景深、QE 和像素尺寸下确认能读懂，不能只在放大素材中成立。

### 精英与首领

精英候选 E01「连冲者」来自 M04：连续两次冲撞，每次独立锁定与预警，两次之间可重新走位；最后有更长休息。它检验躲过第一招后是否过早返回原处，不缩短成不可读的瞬间攻击。

精英候选 E02「鼓舞核心」来自 M08：增益半径更明显，在生命降到一半时召唤一次少量 M01，自身仍可直接击杀。它检验穿透、后排处理与清群能力，不做不可破的护盾或持续召怪。

首领暂称「聚群首领」，正式形象待定。建议三个动作：

| 动作 | 压力与破绽 |
| --- | --- |
| 锁定跳落 | 在可达地面标出落点，停顿后跳落并造成一次范围伤害；锁定后落点不再跟随，落地后有输出窗口，不跨断层 |
| 疏落扇形弹 | 朝一次锁定的方向发出留有明显间隙的弹丸；近身覆盖有限，鼓励横移或靠近侧面 |
| 有限召唤 | 在远离玩家的可达位置预告后生成普通史莱姆；有总次数与在场数量限制，给范围构筑发挥机会 |

生命过半后先建议增加动作轮换、减少少量招式间休息，保持预警长度与逃脱空间。首领同一时间只执行一个主招，召唤怪优先使用基础追击，不能同时叠加鼓舞精英、连续冲撞与大片布场。

控制效果对首领部分保留：缓速与击退减弱，主招不能被普通命中不断重置；不使用全面状态免疫让一条构筑失效。首领也应提供清群、单体和机动各自有价值的窗口。

## 3 十种攻击方式

全部默认自动触发。玩家通过位置、引怪路线、相对距离和闪身影响结果，先不加入持续瞄准或另一套魔力消耗。

| 编号与暂名 | 目标与命中过程 | 擅长／薄弱场景 | 2→3→4 级的行为成长方向 |
| --- | --- | --- | --- |
| A01 近身扇击 | 周期锁定最近可见敌人的方向，打出前方扇区；每段对单体命中一次 | 贴身聚群强；后方与远射压力大，需要走位调整扇区 | 扇长增加 → 扇角展开 → 两段错时斩击，各段有清晰动作 |
| A02 直线穿透 | 朝最近有效目标的锁定方向发射，之后保持直线；同一弹丸对同体一次 | 成列敌人、慢重怪强；侧后包围和转弯目标弱 | 可穿过更多目标 → 射程与速度增加 → 更宽的贯穿轨迹 |
| A03 扇形散射 | 向最近目标方向同时发出多枚分散弹丸；同次齐射对单体设合并伤害上限，避免贴脸伤害失控 | 中距离覆盖、截住疾行者强；远距离单体利用率低 | 弹数增加 → 扇面展开 → 两批错时散射，维持不同角度 |
| A04 追踪弹 | 优先选择视线内的投射者或鼓舞者，其他情况选近敌；有限转向，不能穿墙；失去目标后仅重新选一次 | 分散、移动和后排敌人强；高密度清群效率低 | 追踪更稳 → 更多弹丸分配不同目标 → 提升对单体的持续输出，不改成范围爆炸 |
| A05 回旋返程 | 向锁定方向飞出后返回玩家当前位置；同一目标去程、返程各最多一次 | 沿路径引怪、移动改变回程路线；紧贴或障碍较多时收益小 | 去程更远 → 返程轨迹更宽 → 两个错时回旋体；不无限来回命中 |
| A06 环绕护卫 | 少量攻击体围绕玩家，碰到敌人时按各自命中间隔结算；不能每个渲染帧都造成伤害 | 持续近身防守、裂殖群强；射手、布场与孤立远敌弱 | 护卫数量增加 → 环绕覆盖扩大 → 转速与接触节奏改善 |
| A07 跳跃连锁 | 从最近可见目标开始，逐段寻找距离内未命中过的目标；每条连接独立检查遮挡；越往后伤害递减 | 群聚、幼体与光环群强；目标间距大或孤立首领弱 | 跳数增加 → 跳距增加 → 后续跳跃的伤害递减减轻 |
| A08 延时爆破 | 选中一组有效敌人的中心并锁定，留下我方短预告后爆炸；爆炸前不追着目标移动 | 引怪聚团、处理慢重群强；疾行者与临时改道容易躲过 | 半径增加 → 预告略缩短但可读 → 两处错时爆破；不同时铺满场地 |
| A09 地面持续区 | 周期在玩家经过的有效地面留下短时区域，按固定间隔伤害；区域留在原处 | 引怪经过通道、慢怪与裂殖强；追逐远敌、频繁改变路线时弱 | 持续更久 → 范围扩大 → 更密集的伤害节奏；活动区域始终有上限 |
| A10 扩散震荡环 | 从玩家位置向外扩散，一次穿过敌人造成一次伤害和较强击退；伤害低于主输出攻击 | 打开近身缺口、应对冲撞与群聚强；远距输出和孤立首领效率低 | 最大半径增加 → 击退更稳 → 两圈错时波纹，每圈独立命中一次 |

每次等级提升都可适度提高该攻击的基础伤害，但表中的行为变化才是需要看见的成长。数字与发射数量仍需验证；例如“双段”不能通过一次音效和不可见的双倍扣血伪装。

### 共通判定与属性适用

- 目标选择在施放时锁定，避免每帧随机换目标。QE 只改变视角；自动攻击方向、场地位置、轨迹与判定都在世界中。
- 扇击以每段、投射物以每枚、连锁以每次施放、震荡环以每圈、持续区以每个伤害间隔去重。回旋明确分去程和返程；不能用提高帧率增加命中。
- 直线、追踪和回旋遇阻挡不能穿墙；攻击源到受击点须有对应的有效传播路径。连锁的每一跳、爆破中心到目标、持续区域内部均不能借平面距离穿过建筑。
- 地面范围只覆盖相同有效地表，受不相接台地和障碍裁切。玩家跳跃不默认获得无敌，攻击地表与观察角度不能把伤害切换成隔层命中。
- 「范围」按攻击的真实覆盖定义：扇长/扇角、环绕半径、连锁跳距、爆破和持续区半径、震荡最大半径。它不无条件增加所有投射物射程。
- 「数量」用于穿透弹、散射、追踪、回旋和环绕的额外攻击体；对连锁、爆破和持续区不直接增加一次施放数。
- 「穿透」只用于已有直线穿透语义的攻击：A02、A03、A05；「连锁数」只用于 A07。追踪弹不因穿透卡自动变成另一种攻击。
- 「持续」用于投射体的有效存续和持续地面区/燃烧时长；不延长爆破预告、不给永续环绕再增加无限时长。弹速只用于真实投射体，不自动加快雷电或震荡环。
- 攻击间隔用于周期攻击，环绕对应转动与接触节奏，持续区对应铺设频率；持续区每次跳伤间隔只随它自己的等级变化，不能同时被同一冷却卡重复加速。

## 4 二十四种增益

同名增益占一个槽，升级提高已有条目的等级。卡面显示具体当前值到选择后的数值、适用攻击与代价；只写“更强”“范围提升”不足以支持选择。

2026-10-13 首批已确认并接入 P01／P02／P03：本局全局伤害每级 +20%、基础攻击间隔每级减少 10%、覆盖半径每级 +15%，各三等级，同类按基础值相加。卡面读取真实武器数值，满级和无实际收益项过滤；参数与接口见 [本局战斗增益](combat-buffs.md)。槽位容量、其他增益和正式平衡继续讨论。

### 属性增益：16 种

| 编号 | 增益 | 决策价值与适用限制 |
| --- | --- | --- |
| P01 | 伤害提升 | 所有攻击的稳定强化；不增加范围、触发次数或同时重复提高已继承伤害的附加效果 |
| P02 | 攻击间隔缩短 | 增强持续压制与命中覆盖；按上节分别映射各攻击节奏，设置最小间隔 |
| P03 | 攻击范围扩大 | 改变贴身、连锁与布场的安全距离；没有相关覆盖属性的纯投射构筑不发此卡 |
| P04 | 弹丸速度提升 | 使投射命中移动目标更稳；只对 A02～A05 生效，不改变敌人预警 |
| P05 | 有效持续时间增加 | 加强持续布场、回旋和燃烧；不增加瞬发爆破等待时间，也不影响普通敌人的危险区 |
| P06 | 移动速度提升 | 强化拉扯和绕侧，仍需避开冲撞路径；与体型卡的移速收益进入同一计算组 |
| P07 | 最大生命提升 | 给近身路线更多容错；上限变化保留当前生命比例，不直接回满 |
| P08 | 伤害减免 | 提高承受单次失误的能力；有上限，不能堆成无伤 |
| P09 | 击退力度提升 | 打开缺口、争取投射距离；当前有基础击退能力才发此卡，相同目标受间隔约束，首领效果减弱 |
| P10 | 暴击概率提升 | 为暴击路线建立基础；当前有直击攻击才发此卡，持续伤害与触发伤害不独立暴击 |
| P11 | 暴击伤害提升 | 放大已建立的暴击打法；只有当前存在有效暴击机会时才进入可选池 |
| P12 | 额外攻击体 | 对对应攻击增加弹丸或环绕成员；有总数上限，不让每种攻击同时无条件复制 |
| P13 | 穿透数量提升 | 强化排队引怪和清理前排后的后排输出；只对 A02/A03/A05 生效 |
| P14 | 连锁次数提升 | 强化群聚覆盖，仍有单次去重和衰减；只有已持有 A07 时出现 |
| P15 | 闪身距离提升 | 便于跨过逼近的敌群或离开危险位置；仍受真实障碍与地图边界限制 |
| P16 | 闪身冷却缩短 | 更频繁调整路线；不因此增加无敌帧，不让按住闪身自动连发 |

### 机制增益：6 种

| 编号 | 增益 | 规则与等级方向 |
| --- | --- | --- |
| P17 | 燃烧附加 | 合格武器命中有机会施加有限时长的持续伤害；一级建立燃烧，二级提高伤害。燃烧本身不再施加燃烧或触发其他命中附加 |
| P18 | 缓速附加 | 命中有机会短暂降低敌人移动速度；二级增加持续，减速比例有上限；对精英和首领减弱而非无效 |
| P19 | 易伤附加 | 命中使目标短时承受更多伤害；二级增加幅度。多个来源刷新或取最强，不无限相乘 |
| P20 | 导电标记 | 命中可能标记目标；标记目标再被武器命中时向附近一个其他敌人放出一次弱电弧。二级提高电弧伤害；同体有触发冷却，电弧不能再次触发导电 |
| P21 | 击杀护盾 | 实际击杀给少量临时护盾；二级提高单次获得量。多只同帧死亡只按全局触发间隔获得，护盾有生命比例上限；不回血，不叠成无限容错 |
| P22 | 受击反震 | 真实承受生命损失时产生一次低伤害近身冲击，二级加强击退；有独立冷却，被护盾完全吸收不触发，反震不是伤害返还也不产生另一轮反震 |

### 体型增益：2 种，互斥

| 编号 | 方向 | 收益与代价的建议起点 |
| --- | --- | --- |
| P23 | 轻巧体型 | 体型与真实受击/碰撞半径约为原来的 0.85，移速略增，生命上限约降 10%；偏远距拉扯，耐受失误较低 |
| P24 | 强壮体型 | 体型与真实受击/碰撞半径约为原来的 1.15，生命上限约增 20%，近身覆盖与击退略增；更容易与敌群接触或被弹丸擦中，偏近身打法 |

两者只允许一个，领取前明确提示代价，不作为同一条无限增大的升级线。改变外观、受击半径、物理碰撞与脚底锚点，脚底始终贴地；不放大相机或世界。上限变化保持当前生命比例，选择卡不能直接让人物死亡。

体型自身不隐式乘算所有攻击范围。强壮的近身覆盖收益作为明确加成，与 P03 同组相加；远程投射和整个地面区不因人物变大再乘一次。轻巧也不自动缩小武器效果。

## 5 状态、叠加与伤害边界

这里的数值是为了把规则说清楚的参数起点，不是最终平衡表。每项后续应可独立调整，不能把文档数值当作已通过试玩。

| 状态 | 建议规则 |
| --- | --- |
| 燃烧 | 短时周期扣血，初测 3 秒、0.5 秒一次，最多 3 层；超层只刷新，不增加第四层。每层来源明确，持续伤害不暴击、不触发附加 |
| 缓速 | 同类取最强并刷新，不累加到冻结；普通怪初测最高约 40%，精英与首领减半。减速不缩短或改变已经锁定的预告 |
| 易伤 | 同类取最强并刷新；伤害结算只应用一次，初测上限约 30%；攻击之间共享目标上的状态，不能每次连锁继续乘前一跳的最终伤害 |
| 导电 | 标记有限时长，例如 4 秒；同一目标电弧触发冷却初测 1 秒。电弧只找一名未参与该次触发的近敌，独立检查遮挡，不自行产生下一轮电弧 |

同一进攻属性来源先在组内相加，再统一应用。范围不会额外提高伤害倍率；额外攻击体、穿透与连锁各有总数上限。建议测试起点为冷却减幅不超过 50%、移速总增幅不超过 35%、减伤不超过 50%、范围总增幅不超过 75%；这些上限是否合适必须结合成形后的实际清怪能力测试。

敌人鼓舞取最强，不多层相乘；缓速在鼓舞后的速度上按固定规则计算。冲撞者的预警不会因鼓舞变短，已经锁定的冲撞轨迹也不因减速中途追着玩家拐弯。玩家得到更高移速后仍能读懂威胁，不能靠敌人无限加速追平玩家。

武器的直接命中可以暴击，也可以尝试附加状态；同一目标的同种附加设最小尝试间隔，例如 0.5 秒，避免齐射一帧触发多轮。A09 每次周期伤害属于持续命中，附加也必须遵守这个间隔，其周期伤害不额外暴击。攻击说明与暴击类奖励应提示这种适用差异。

玩家沿用共享的短受击保护，同一时间来自接触、弹丸与危险区的伤害不能全部叠加；一次已经被保护间隔拒绝的命中不触发反震。敌人伤害仍需能表达种类差异，保护间隔的具体数值随后随战斗密度调整。

燃烧、电弧、反震等状态或触发伤害不再触发命中附加，不另行暴击，不用受害者已结算的最终伤害当作下一次伤害基础。与伤害提升的关系为：来源包含进攻加成一次，暴击与目标易伤/减伤分别结算；不能把已暴击、已易伤的数值再次当作基础叠乘。

击杀必须只结算一次。所有来自玩家的有效击杀均可尝试触发击杀护盾，但遵守玩家级冷却与护盾总上限；护盾取得不是伤害事件，不能让电弧、击杀和反震形成递归。休整时不因等待而增加护盾或恢复生命，既有护盾的战斗剩余时间可暂存，下一波继续。

普通怪受击退影响较明显；同一目标的重复击退有最小间隔，不能用环绕持续把怪锁在不可行动状态。精英与首领降低击退距离；主招不被普通小击退不断重置。控制路线仍能改变逼近速度与附近小怪的位置，首领不全面免疫状态。

## 6 成长链路与卡牌质量

2026-10-13 最新确认更新成长触发：怪物掉落经验宝石，人物靠近吸取，经验升级立即选择并临时冻结战斗；环境与声音继续运行。新挑战与重试重置本局等级。宝石、真实候选和首批三种本局属性增益已接入，其他增益与正式候选数量继续讨论，见 [本局经验与升级](run-growth.md) 和 [本局战斗增益](combat-buffs.md)。

建议首局即可从 10 种攻击中选择 1 种起始攻击，不通过训练、装备或种植解锁，避免核心体验被另一个系统挡住。引导可推荐扇击、穿透或环绕，其他攻击仍能选。

此前的“每波两次三选一、攻击与增益各一次”保留为历史节奏提案；当前由经验曲线决定升级机会，不按每波固定派发。奖励池是否分开、如何保证输出形态成长，继续讨论。

一局先以约 14～16 次成长机会讨论，不固定波长。例子是 9 波，前 8 波各两次选择：既能比较少数攻击高等级与多个攻击低等级，也不会把所有内容一局拿齐。

奖励规则：

1. 三张卡为不同条目，不重复展示同一个升级；达到槽位或等级上限的无效获得项移除。
2. 攻击槽未满时，攻击选择尽量保留一个已有攻击升级，另有新攻击候选；槽满后只提供已有攻击升级，不强行替换武器。
3. 增益卡按当前攻击标签过滤。没有投射攻击不发弹速，没有 A07 不发连锁次数，没有有效暴击不发暴击伤害；不能按“以后可能抽到”解释当前无效。
4. 六个增益槽满后只提供已有增益升级；选了体型后另一体型不出现。满级条目与实际无收益的封顶条目同样过滤。
5. 保证至少一项当前可用的选择；有效项不足三张时如实少显示，奖励池完全耗尽时给一次明确的有限恢复，不另加无限刷新经济。
6. 卡面展示真正改变的值与适用攻击。体型显示生命、碰撞和近身范围的收益与代价；等级提升显示新增段数、穿透、连锁或轨迹变化。

获得攻击自动入槽仍为后续提案，不再去 Tab 重复学习或装配。Tab 显示内容待实际获得链路接入；大型管理页继续限制在安全区域。成长选择采用新确认的升级立即冻结战斗规则。

每局开始使用一致的起始角色参数。结束与重试清空本局攻击、增益、状态和护盾；已有训练/装备存档不直接改变这套挑战平衡，永久解锁与装备成长留到后续。具体存档与覆盖方式尚未实现。

## 7 四种成形打法

| 方向 | 攻击与关键增益 | 主动玩法与优势 | 薄弱处与应对 |
| --- | --- | --- | --- |
| 近身环绕 | 扇击、环绕、震荡；范围、减伤、击退、强壮 | 围着聚群边缘转，靠近后清理史莱姆和幼体；用震荡制造进出窗口 | 射手与布场压迫停留，需绕侧处理，不能只站着承受；第四攻击可选追踪补后排 |
| 远距穿透 | 穿透、散射、回旋；数量、穿透、弹速、移速、轻巧 | 拉长敌人队列，改变回旋返程路线；有视线时连续处理前后排 | 疾行和连冲打断拉扯；保留闪身出口，可用环绕补贴身防守 |
| 持续消耗 | 持续区、延时爆破、回旋；持续、范围、燃烧、缓速 | 引敌人重复经过布置好的路径，以持续伤害处理慢重怪与裂殖群 | 快速冲撞与敌方布场迫使换路线；需要一项即时攻击处理漏网目标 |
| 连锁控制 | 连锁、追踪、震荡；连锁数、导电、缓速、易伤 | 借敌群相邻关系清理并压低逼近速度，对鼓舞群有较强覆盖 | 孤立首领和离得很开的射手削弱连锁；用追踪或穿透补单体，不依靠首领永久被控 |

同一攻击可以服务多个方向，组合不设置强制套装门槛。例如小体型配回旋与穿透强调路线，大体型配环绕与扇击强调靠近；体型要改变风险与走位感受，而不只是换一个人物尺寸。

## 8 怪物组合怎样检验构筑

按「基础群体 + 一种逼迫换位的威胁 + 少量优先目标」组织普通波次，先限制为最多三类主要行为。八种怪分阶段出现，再重组已有内容；不是同屏堆满八种。

| 组合 | 玩家要读懂的事情 |
| --- | --- |
| 史莱姆 + 鼓舞者 | 表面的群体数量与后方增益源；处理支援可显著降低包围压力 |
| 盾壳兽 + 投射者 | 慢重前排占路线，后排持续远射；穿透和绕侧分别有价值 |
| 冲撞者 + 布场者 | 直线闪避出口可能被短时布场改变；提前读路线，不能最后一瞬间才看地面 |
| 裂殖者 + 疾行者 | 爆发清理母体后需要接上范围覆盖，同时防止快怪从缺口逼近 |
| 普通群体 + 一名精英 | 把注意力从持续清群短暂转向独立预警；不同时首次引入两种精英 |

建议渐进次序：史莱姆 → 疾行 → 慢重 → 冲撞 → 远射 → 裂殖 → 布场 → 鼓舞组合 → 首领。这个次序可用于九波示例，不是最终关卡表。下一波的主要威胁应在休整时用短说明提示，使成长选择有可理解的目的。

基础追击群承担主要数量，远射、布场、鼓舞和精英保持少量。危险区不能盖住全部出口；主预警并发可先限制在两处，首领自身一次只施放一个主招。出生点要避开玩家当前位置，不能在闪身落点即时出怪；生成和召唤均给可见预告、使用可达地面。

清波判断包括分裂幼体、有限召唤和已生成敌人；处于预告阶段、尚未出现的分裂或召唤也计入待生成数量，必须「场上敌人 = 0 且待生成 = 0」才能清波。清理所有敌方弹丸与危险区、完成剩余经验引发的升级选择后，才进入休整；失败、撤退或结束挑战同时取消未完成的预告与生成。若残余敌人落在不可达位置，挑战不能永久卡住，需有明确的恢复处理规则。

## 9 HD-2D 表现与设计验证

危险预警主要依靠地面形状、准备动作与短声音，颜色为辅助；我方延时区与敌方危险区要有不同边缘形状。持续区域边缘清楚、中间保持透视，瞬时攻击用短命中反馈，避免十种攻击共同遮住人物、敌群和花草。

范围、体型和目标始终用世界尺度表示，预警跟随有效地表并受遮挡；旋转镜头不改变机制。人物与怪物沿用已有遮挡轮廓规则。实际验证应保持现有开发相机和景深，不用俯视截图代替正式观察。

设计进入灰盒后的关键检查：

- 单独用每种起始攻击能清理基础群体，薄弱场景需要应对但不是必败；每条构筑也能对首领造成有效伤害。
- 每种怪物可以通过移动、攻击、借遮挡或闪身应对，不能只有某一张随机卡才能破解。
- 扇击分段、散射伤害上限、回旋去返程、连锁去重、环绕间隔、爆破锁定与持续区周期都按约定生效。
- 同屏交叉预警、建筑、高差与 QE 不导致看不见的攻击或无法躲开的覆盖。
- 满攻击槽、满增益槽、等级上限、体型互斥、纯持续区构筑等情况下，不提供没有实际作用的卡。
- 燃烧、导电、反震与击杀护盾同时存在时，触发链仍有限，击杀不重复计算；首领不被永久锁死。
- 轻巧与强壮的脚底、受击半径、门口与坡道通行一致；强壮加范围不重复乘算，轻巧不造成无碰撞。
- 成长后能清楚感到覆盖、节奏或风险变化；如果只能从面板数字发现区别，需调整该条设计。

待讨论的关键不是是否继续缩减数量，而是十种攻击是否都值得选择、二十四种增益是否都有明确用途，以及八种怪物的组合能否让这些打法发挥并接受考验。伤害、冷却、生命和密度需在这一关系成立后继续调优。
