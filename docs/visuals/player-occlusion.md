# 玩家与怪物遮挡轮廓

更新：2026-10-15。

人物被建筑等写入深度的不透明表面遮挡时，显示被挡部分的暖黄色像素轮廓；露出的身体保持正常显示。轮廓使用当前动画帧的透明边缘，随贴图、左右镜像、世界位置和相机转向同步。玩家保持独立设置；正式地图波次怪物的统一开关当前关闭。

## 在 Godot 中调整

玩家：选中地图中的 `Player/Sprite`，在检查器的“遮挡轮廓”分组中调节。

波次全部怪物：在“参数总览 → 战斗与成长”搜索 **波次怪物遮挡轮廓（全部）**，跳到 `WavePrototype → 波次配置 → Enemy Occlusion Outline Enabled`。正式地图保存为关闭；运行时修改总开关会立即应用于当前怪物，后续生成和分裂／召唤也使用同一设置。此项不修改玩家轮廓。

每种怪物：打开 `scenes/enemies/` 下对应怪物场景，选择 `Sprite` 调节独立开关及颜色、宽度等参数。总开关仅控制是否允许显示，不覆盖 Sprite 自己关闭的选择。

参数总览原有 `Slime/Sprite` 对应地图中的展示怪物，修改它只影响那一个实例，不会传给波次中新建的怪物。要统一关闭战斗怪物，请使用上述 `WavePrototype` 总开关。已运行的旧游戏窗口需要重新启动场景，加载新脚本和正式地图设置。

| 参数 | 当前值 | 含义 |
| --- | --- | --- |
| Occlusion Outline Enabled | 开启 | 整体开关 |
| Occlusion Outline Color | RGB(1.0, 0.89, 0.55) | 暖黄色；可改为需要的提示色 |
| Occlusion Outline Width | 1.0 | 原人物纹理像素为单位，向轮廓内部描边；不是固定屏幕像素。0 关闭 |
| Occlusion Outline Opacity | 0.85 | 不透明度，范围 0～1；0 关闭 |
| Occlusion Depth Bias | 0.03 米 | 遮挡表面要比人物更靠近镜头的最小差距，避免接触面和深度误差触发轮廓 |

参数支持运行与编辑器预览。轮廓开关独立于人物受光开关，关闭人物受光后仍可保留遮挡提示。脚本重载导致内部节点引用重新初始化时，关闭逻辑也会寻找并隐藏已经存在的辅助轮廓节点，避免旧轮廓残留。

## 实现与适用范围

[character_lighting.gd](D:/Project/HD-2DMap/demoWithMeowa/1/scripts/rendering/character_lighting.gd) 为人物建立一个不保存到场景文件的辅助面片。[character_occlusion.gdshader](D:/Project/HD-2DMap/demoWithMeowa/1/shaders/character/character_occlusion.gdshader) 沿当前帧 alpha 边缘描线，重建场景深度并与人物逐像素比较，只在人物位于遮挡表面之后时输出颜色。深度重建遵循当前渲染器的 NDC 范围和 Godot 的逆深度约定。[Godot 深度纹理说明](https://docs.godotengine.org/en/stable/tutorials/shaders/advanced_postprocessing.html)

效果依据画面深度，无需给每栋建筑增加碰撞射线或配置单独触发器。遮挡表面是否参与取决于材质的深度写入；透明材质按其实际渲染方式处理。辅助轮廓不写入深度、不投影、不参与 GI，且从平面水面反射中排除，原人物的正常倒影保留。

史莱姆使用每行八帧的图集，每帧为 80×80 像素。轮廓按当前 `AtlasTexture.region` 映射到原图集，只读取这一帧的 alpha，并按帧内原始像素计算描线宽度；不会把整行八帧压缩到同一个轮廓中。普通独立 PNG 继续使用完整纹理范围。

## 技能与命中特效层级

雷光贯穿的雷刺、尾迹与命中电弧，棱晶弹射的晶体、折线尾迹与接触反馈，镜梭、镜印和碎片，以及奔雷涌潮的落雷、连线、电涌和命中帧，均通过 `scripts/rendering/combat_effect_layer.gd` 创建材质。A01 和基础剑术的现有斩击材质也接入相同规则；基础剑术仍保留当前关闭剑光的选择。

怪物 `Sprite` 沿用原来的受光、阴影、alpha 裁切和深度绘制，在透明覆盖通道用同一网格与当前纹理标记可见轮廓。技能正常绘制后，仅在被可见怪物挡住的像素上补画；已经可见的技能像素不会重复增亮，建筑完全遮挡时不补画。补画共享原特效的帧、色彩、淡出与实例参数，不移动真实弹道，也不禁用整张特效的深度测试。

同帧怪物共用遮罩材质，每种技能着色器共用补画着色器，现有节点池继续复用。地面预警、怪物残骸、人物残影和伤害数字保留各自原来的表现通路。实现使用项目当前 Godot 4.7 / Forward+ 的 stencil 功能；`tests/test_combat_effect_layer.gd` 在原生渲染下读取正式地图当前镜头，检查六种怪物、七种特效材质、切换镜头、透明轮廓、建筑遮挡和重复混色。

## 教程补充提示词

```text
为当前二维像素人物加入被建筑遮挡时的轮廓提示。使用当前动画帧的 alpha 边缘，与场景深度逐像素比较，仅显示被挡住部分的轮廓。正常露出的身体保持原有受光。

支持待机、跑动、跳跃和左右镜像，适配现有可旋转相机。默认暖黄色 RGB(1.0,0.89,0.55)，粗细 1 个原图像素，不透明度 0.85，深度容差 0.03 米。开关、颜色、粗细、透明度和容差在人物 Sprite 检查器中可编辑。

辅助轮廓不投影、不写深度、不进入水面倒影。使用同一相机分别验证无遮挡、完全遮挡和局部遮挡，并展示关闭/开启对比。
```
