## 当前地图逻辑

- `scenes/previews/four_realms.tscn` 是视觉测试地图。`four_realms.gd` 负责人物与相机边界、测试区域状态，以及光影测试按键。
- `scenes/world/world.tscn` 是独立正式地图入口，当前接入 `MapEffects`。它没有继承视觉测试地图的地形数据、建筑或摆放。
- `addons/map_switcher/plugin.gd` 在 Godot 编辑器中打开、运行地图并选择 F5 默认入口。它没有游戏中的分区切换逻辑，连续地图仍由玩家行走连接活动区域。
- 地形由 `TerrainData` 的格子数据生成顶面、崖壁、水、桥、坡道与碰撞。每格默认 1.6 米，每层默认 0.8 米；区域类型与覆盖层控制材质和地形结构。
- `Player` 已有相机方向下的移动、侧向/背向动画、跳跃、下落与落地。预览 NPC 当前是展示用贴图，尚未提供完整交互、任务、背包或战斗系统。

游戏方向见 [慢节奏波次生存草案](../rpg-game-design.md)。当前已接入 [基础波次灰盒](../gameplay/wave-graybox.md)，技能实际效果与成长继续讨论；具体出生点规划和地图布局仍可调整。

这些是本次接入的默认基准。以后修改视觉预览场景的独立参数，不会自动覆盖正式地图；修改通用场景的参数会成为其未覆盖实例的新默认值。

2026-10-13 正式地图更新：落雨地面反馈仍使用已有着色器和世界坐标，原半径 0.11 米、强度 0.32 在当前 28 米镜头下很细小，雨量及草地材质进一步降低亮度。正式地图独立覆盖为半径 **0.24 米**、密度 **1.6**、强度 **0.95**，保持原来的短暂扩散与消退；没有增加水洼或新的美术。原视觉预览和共享脚本默认值保留。

在 `MapEffects/Weather → 地表雨水` 调整 `Ground Rain Enabled`、`Ground Splash Size`、`Ground Splash Density`、`Ground Splash Strength`；参数总览可搜索“地面雨纹”。大小是最大半径（米），密度是满雨量时每平方米每秒的近似数量，强度控制短暂溅点／环纹的可见程度。当前默认雨量 0.48，所以实际落点数少于满雨量值；草地仍比道路更轻，景深仍会自然虚化远近地面。

`GroundDressing.ground_sheen` 控制大片湿润亮斑，与地面雨滴环纹独立。正式地图当前为 0；Style 切换已改为保留该手动值，也保留上述雨纹参数。无需开启积水或湿亮斑来显示雨滴落地。

当前镜头实机动画：[调整前](../media/ground-rain-preview/before.webp) · [调整后](../media/ground-rain-preview/after.webp)。36 帧来自原生 D3D12 / Forward+，1280×800，无损编码；对比使用相同世界位置、镜头、景深和雨纹计时，只调整地面落雨三项参数。草地、道路都有反馈，不新增三维粒子或逐滴节点。

验证：83 项 Style 检查覆盖湿亮斑 0／自定值和雨纹调参的保留，参数总览通过；正式场景原生运行核对材质绑定、雨纹计时、四种 Style 以及关闭／恢复地面雨水。验证时同步补齐攻击脚本 `next_time` 的浮点声明，解决新增配置的类型推断阻塞，既有 32 项扇击检查通过；最终日志无脚本错误。

## 在 Godot 中使用

打开正式地图，展开 `MapEffects`，选择对应子节点，在检查器中调节。正式地图已允许编辑该实例的子节点；新增地图实例化同一通用场景后，也可启用“可编辑子节点”。每张地图的环境、后处理、天空与材质资源已隔离，运行时调参互不影响。

`MapEffects` 自动寻找同一地图下的这些节点：

| 连接 | 默认寻找位置 | 用途 |
| --- | --- | --- |
| 地形 | `World/Ground`，其次 `Ground` | 地表雨水、湿润、水面反射和活动范围 |
| 人物 | `Player` | 相机跟随与移动相机 |
| 花草 | `World/GroundDressing`，其次 `GroundDressing` | 风摆与铺设重建通知 |
| 已有相机 | 地图根下的 `Camera3D`，需使用 `FollowCamera` 脚本 | 接入现有镜头，避免同时启用内置相机 |

节点名称或组织方式不同时，在 `MapEffects` 的“地图连接”中手动指定 `Terrain`、`Player`、`Dressing` 和 `Map Camera`。编辑器中新增或更换这些节点后，点击“连接地图节点”；运行地图时会自动连接。

当前正式地图的 `Homestead` 使用既有 `Terrain` 脚本，已在 `MapEffects/Terrain` 显式连接。旧版自定义小院地表也支持通过 `Surface Source` 提供地面材质、水面材质和水域节点；花草重建后会刷新天气连接，水域重建后会刷新倒影。

`Apply Camera Defaults` 默认开启：已有相机也采用预览的距离、俯角、旋转和景深参数。需要使用已有相机的自定义设置时关闭它。相机始终连接通用后处理，因此放在地图根节点也能驱动效果子场景里的椭圆虚化。

每张地图使用一个 `MapEffects`。它已经包含环境、主光、天气、后处理与音频。内置相机在没有外部相机时启用；引用 `Player` 后会自动跟随。

## MapEffects 的教程介绍

`MapEffects` 是本项目自定义的地图效果入口：一个可复用的 Godot 子场景，以及负责连接地图节点的脚本。它把环境、主光、空气光、相机、后处理、天气、音乐和水面反射组织在一起，用于给地图提供统一的效果默认值。

人物、地形、花草和灯具仍是地图中的独立节点。`MapEffects` 将它们与天气、光影和镜头连接起来；人物动画与受光、地形材质、花草铺设和灯具表现各自还有调节入口。教程可以把这套组合称为“HD-2D 环境效果系统”。

从零学习的完整路线见 [Godot HD 2D 视觉效果复刻教程](D:/Project/HD-2DMap/docs/technical/hd2d-visual-tutorial.md)，包含现有效果总览、18 个阶段的可复制开发提示词、Meowa 素材提示词、参数基准与逐阶段验收方法。

### 录制前的状态核对

- 深度景深当前默认开启；椭圆虚化是可切换的另一种模式。
- 日照与云影演示当前默认关闭，录制时手动开启。
- 细雨当前默认开启，雨声音效默认关闭，BGM 与风声默认开启。
- 镜头水滴和音频在运行地图时展示；花草铺设与多项光影参数支持编辑器预览。
- 积水功能已有，当前默认关闭。
- 萤火虫、灯光、水和瀑布需要对应物件或地形。花草铺设需要区域节点。通用效果入口提供配置与连接，其具体位置由地图布置决定。
- 视频介绍时，可按“Meowa 的素材生成或参考下载 → 素材筛选与整理 → Godot 布置、脚本与 Shader 实时表现 → 参数调节与地图复用”讲解。灯光、雨幕、折射、雾、景深等动态表现由 Godot 实时实现。

每个效果推荐保持相同镜头，按“关闭效果 → 开启效果 → 调一个关键参数 → 展示与其他效果配合”录制，便于观众看清变化。
