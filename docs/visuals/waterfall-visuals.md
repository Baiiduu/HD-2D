# 瀑布：张力与观赏性

2026-10-10，工作项目：`demoWithMeowa/1`。

后续泡沫与水滴已进一步统一，当前颜色、共同尺度与水滴参数见 [泡沫与水花](water-foam.md)。下方保留首版水帘的说明与验证记录。

这一版把原来的亮蓝平面与均匀白点改为弯曲水帘、粗细不同的流束、落水白沫和少量抛物线水花。水帘保留较暗的青灰水体，顶部和底部更亮，接受现有灯光与阴影；落水点的局部雾减轻，以便看清流束。没有调整河面 shader、人物反射算法、灯光或地图布局。

对照 benchmark 的 `threejs/src/water.js` 与 `particles.js`：采用了水帘弯曲、两种尺度的水纹、顶部/底部泡沫分区和局部飞溅的思路；保留 Godot 现有真实灯光与材质管线，没有照搬 three.js 的手动灯光计算。

## 调节

场景根节点 `ArtDirection` → **瀑布** 分组，支持检查器实时调节与逐项恢复默认值。

| 参数 | 默认 | 作用 |
| --- | ---: | --- |
| waterfall_speed | 2.2 | 向下流动速度，米/秒 |
| waterfall_curve | 0.18 | 向下游翻出的距离，米；0 为平面 |
| waterfall_opacity | 0.72 | 水体基础不透明度，亮流束和白沫更浓 |
| waterfall_stream_contrast | 0.9 | 明亮流束强度 |
| waterfall_foam_strength | 0.85 | 上沿、下沿及下游白沫强度 |
| waterfall_foam_length | 0.65 | 底部白沫向下游延伸的距离，米 |
| waterfall_splash_strength | 0.65 | 水花高度和可见度；0 关闭 |
| waterfall_mist_density | 0.18 | 仅瀑布附近的薄雾密度；0 关闭 |

水体、流束和泡沫颜色在 `World/Ground` 的 `waterfall_material` 中单独调节。提高张力时先调整流速、流束和白沫；保持观赏性时注意暗部间隙、白色面积和局部雾的遮挡。白沫长度有上限，避免覆盖下游人物倒影。

## 验证结果

- Godot 4.7.2 Forward+ / D3D12 实际加载、渲染与 48 帧动画采集完成，没有脚本或 shader 错误。
- 正式机位人物倒影对照：冻结材质和人物，只隐藏镜像代理，比较人物倒影所在区域 `Rect2i(575, 600, 140, 190)`。修改前后倒影对比度 595.886 / 595.929，比例 100.007%；有效像素 2714 / 2715。两张水位反射视图正常。使用局部区域排除瀑布局部体积雾的时间噪声。
- 河面真实灯光、高光、阴影和 R 键反射开关回归通过，864 个水面采样点；平均高光增量 0.12497、灯光增量 0.22199、阴影减光 0.01074。
- 相邻同水位落差的水格保持水帘与流束连续，只在整条瀑布的实际侧缘淡出。
- 相对本次修改前的文件检查：修改集中于瀑布 shader、瀑布网格生成、瀑布材质与总控参数；项目已有其它改动保留。差异空白检查通过。

这是一版适合当前短落差的风格化表现，使用局部程序水纹与水滴，没有流体模拟或新增美术图片。正式视角中，桥栏仍遮挡部分落水点；场景构图未调整。尚未测量低端设备性能，也未声称逐像素复现参考图。
