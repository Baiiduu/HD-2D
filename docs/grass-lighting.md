# 草地光影试作

Godot 场景：`demoWithMeowa/1/scenes/four_realms.tscn`。
选中 **World → GroundDressing → 草地光影**，参数在编辑器和运行时均可调整。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| Lighting Enabled | 开 | 总开关；关闭恢复原有草丛受光、草地湿润响应和根部表现，位置不变 |
| Stable Shadows | 开 | 阴影渲染使用每丛固定朝向的贴片轮廓，减少 QE 旋转带来的草影转动 |
| Normal Strength | 0.35 | 固定在世界中的受光起伏；0 是朝上的统一法线，仍与镜头解耦 |
| Root Occlusion | 0.3 | 草根与其脚下地面的柔和遮蔽，0 关闭 |
| Backlight Strength | 0.12 | 叶尖接收真实光源的背光程度，0 关闭；没有自发光描边 |
| Ground Relief | 0.008 | 现有草地纹理的细微凹凸受光，0 恢复平面法线 |
| Ground Wet Response | 0.2 | 草地对 ArtDirection 和天气湿润的响应，0 保持原有干燥表现 |

第一版复用现有月光和路灯，不增加光源。月光方向、颜色和强度仍在 ArtDirection 中调节。道路、石板、桥和水面不使用草地材质参数；公共路灯金色颗粒配置保留。

## 实现与局限

草丛的显示贴片仍绕竖直轴朝向相机。受光法线采用每丛固定的世界方向、轻微叶片变化和随风弯曲，再转换到观察空间。根部压暗和背光使用原有材质与真实光源；没有新增美术贴图。

地面接触遮蔽图由既有草与花的落点生成，固定在世界中。这是美术近似的根部遮蔽，不是动态物体阴影，也不代表逐叶片的真实三维遮挡。阴影通道中的固定贴片轮廓同样是近似，不能提供完整三维草叶结构。法线凹凸以现有纹理明暗为近似高度，强度保持很小。

## 性能与验证

- 继续使用原有 MultiMesh 分块；没有新增灯光、场景实例或额外阴影视图。
- 草丛不增加纹理采样；地表根部遮蔽增加一次纹理采样。
- 根部图为 512 × 512 的 R8 图像，原始数据约 256 KiB；只在重新铺设时生成。调节光影参数不重新撒布，也不每帧生成图像。
- 实际 RTX 3050 / D3D12 / Forward+，1280 × 800 同一视角交替使用原始和新版着色器测试。后台编辑器仍运行，GPU 帧耗时波动较大，本次数据不能支持可靠的性能增幅百分比。
- 实际渲染器检查 -45°、0°、45°：同一贴片的世界法线诊断颜色保持一致；固定世界地面采样中的投影保持接近。原生阴影边缘仍受阴影贴图分辨率和滤波影响。
- 已验证参数开关、0 值、重新铺设、Nil 热重载、保存重开；分布和水面参数保持原值。
