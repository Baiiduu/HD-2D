# 参数总览与游戏内 Style 切换

更新：2026-10-13。项目 `demoWithMeowa/1`，正式地图 `scenes/world/world.tscn`。

## 参数入口

Godot 右侧新增「参数总览」，初次默认放在检查器下方，选择参数后可继续浏览总览。可拖动停靠面板调整位置；已有布局可能保留此前的页签位置。打开地图或组件场景后自动索引，外部修改后可点「刷新」。已有编辑器若未显示，在「项目 → 项目设置 → 插件」启用「参数总览」。

- 默认「只看常用」，先显示镜头、风格、人物、扇击数值、怪物数值、波次、经验、HUD 和音量。
- 关闭常用筛选，按用途、组件路径和原分组浏览全部自定义导出参数、嵌套规则资源与高级着色器参数。
- 搜索中文用途、英文变量名、节点路径、分组或原代码说明。搜索覆盖全部参数，不受常用开关限制。
- 选择结果定位原检查器，继续使用 Godot 的撤销、场景保存和资源保存。总览不保存第二份数值。
- 悬停和选中时显示原代码说明。共享资源只登记一次；要独立调节先设为唯一。

| 分类 | 实际控制对象 | 常用调节 |
| --- | --- | --- |
| 视觉 | VisualSample、ArtDirection、Camera3D、Weather | Style、像素材质、色板、曝光、主光、雾、镜头、景深、雨量、风摆、闪身扰动 |
| 人物 | Player、Player/Sprite | 速度、跳跃、台阶、闪身与残影、生命魔力、受光、轮廓 |
| 战斗与成长 | WavePrototype、FanAutoAttack、RunGrowth、波次／怪物／经验资源 | 扇击伤害／范围／间隔、怪物数值、刷新、保护、经验与吸取 |
| 地图与地编 | Homestead、BattleArea、GroundDressing、区域、建筑及画笔 | 地形、战区、铺装、花草、建筑尺寸和材质 |
| UI | LoadoutUI、TrainingUI、属性条、技能栏、物品栏、成长卡片 | 缩放、字号、边距、槽尺寸、辉光、透明度、动效 |
| 声音 | BGM、Weather 音频组、动作音效、UIAudio 及声音资源 | 开关、音源、分贝、淡化、循环和增益 |
| 物品与规则 | 物品／装备／技能目录、训练规则 | 内容、基础属性、训练消耗及已有配置；不代表后续流派已定稿 |

生成的网格、碰撞、花草批次和 UI 控件不作为重复调节入口。布局仍在场景，地形仍在 TerrainData，机制数值仍在组件和规则资源中。

## R 切换

默认黄金时段。**R 单次按下：黄金时段 → 细雨 → 夜晚 → 原始光影 → 黄金时段**。结算重试改为 **T**；F 开始／继续，ESC 返回或撤退。

| Style | 当前光影与天气 |
| --- | --- |
| 原始光影 | 原有冷光、色调、细雨和表面受光基线，关闭 Lumina 额外调色与浅凹凸 |
| 黄金时段 | 暖主光、冷环境填光、晴天、轻窗光和较干地面 |
| 细雨 | 冷柔主光、细雨、较湿地面和更明显的暖窗 |
| 夜晚 | 深冷环境、晴天、低主光和较强暖窗 |

Style 仅切光影、表面受光与天气，保留当前镜头、Q/E 朝向、跟随、景深、人物位置、地图与建筑布局、尺寸、碰撞、花草密度及分布、种植、库存、战斗与存档。建筑窗光和 Lumina 受光只更新材质，不重建网格或碰撞。

像素材质、色阶、屋瓦对比、卵石暗点及草地深浅变化在四种 Style 中独立保留。「原始光影」用于同场景光照对比，不再还原历史镜头、旧布局与旧素材。声音音量／开关、闪身扰动参数也独立保留，天气声音继续采用原淡化。

`VisualSample → 画面风格 → 游戏内切换` 提供 `Runtime Switch Enabled` 和 `Style Key`。自动重复、组合键、文字输入、背包／训练面板与升级选择期间不接管 R；结果状态允许切换。F7/F8 不绑定视觉功能。

## 参数由谁控制

| 调节项 | 持久修改位置 | 切换 Style 时 |
| --- | --- | --- |
| 镜头、跟随、旋转与景深 | `MapEffects/Camera3D`，FOV 在内置属性中 | 保留；移除 VisualSample 重复的四项镜头控制 |
| 地图、建筑、花草分布 | 原场景节点、TerrainData、地编区域 | 保留 |
| 像素材质、尺度、屋瓦对比、色板与卵石暗点 | VisualSample 与色板资源 | 保留 |
| 草地深浅开关、强度与斑块大小 | `VisualSample → 草地深浅变化` | 所有 Style 保留，包括原始光影 |
| 明暗层次样板及原版对照 | `VisualSample → 明暗层次样板` 与 `spawn_value_sample.tres` | 保留开关和独立色板；三种 Lumina Style 应用各自半球补光，原始光影恢复均匀环境色 |
| 主光、填光、雾、受光和预设雨量 | `data/visual/spawn_*.tres` | 应用该预设；直接调控制节点用于临时试看，切换后会重设 |
| 声音、闪身、人物与战斗数值 | 原组件或规则资源 | 保留 |

总览列出四个「风格预设」资源：`node_values` 是节点视觉值，`shader_values` 是材质视觉值，`palette_values` 是地表受光。历史快照内的相机、位置、尺寸、花草分布、声音和闪身项保留参考，现切换逻辑明确忽略；画笔编号与图集规则不从 Style 写回。

当前光影立即切换，方便对比，天气音频继续淡化。后续可讨论将美术风格、时段和天气分开组合，或加入光色渐变；本轮没有新增风格或正式天气循环。

## 草地深浅变化

选择 `VisualSample → 草地深浅变化`，也可在「参数总览」搜索「草地深浅」或「斑块大小」。

可以直接在 **Godot 编辑器 3D 视窗**中预览，不必运行游戏或按 R。拖动强度／大小会立即更新地面材质；已打开场景在工具脚本更新后自动补齐预览初始化。若想手动重刷，同组提供「刷新草地斑块预览」按钮，只更新这三项，不套用 Style，也不重建地形或花草，因此保留当前自定义灯光。

| 参数 | 默认 | 意义 |
| --- | --- | --- |
| `Grass Variation Enabled` | 开 | 叠加固定的程序化色块，与 Style、Lumina 凹凸、草地受光及像素材质开关独立 |
| `Grass Variation Strength` | 0.16 | 越大深浅差异越明显；0 不叠加这层变化，贴图自身的明暗仍保留 |
| `Grass Variation Size` | 约 2.63 米 | 噪声格的世界尺度，越大斑块越大；不修改地形格、贴图密度或花草分布 |

算法在地面着色器中运行：世界 X/Z 位置除以斑块大小，取固定位置偏移下的平滑值噪声，再用 `smoothstep` 形成颜色倍率。在开启五色色阶时，先变化底色再选档。强度 0.16 沿用此前约 0.84～1.04 的倍率；算法不使用时间或相机位置，保持固定分布。只作用于实际草地层，道路和耕地保持原行为。

原来这层变化使用写死的频率／幅度，并附在 Lumina 开关上，所以原始光影没有斑块；现在三项参数独立，在原始光影中也生效。只调强度或大小更新材质，不重建地形、碰撞或花草。

首次进入必须直接得到正确草色。已修复启动阶段画笔延迟刷新将 Style 色调覆盖成白色的问题：画笔应用后重新保留当前草地／道路受光，不重复套用整个场景预设。草根遮蔽、草地凹凸等继续由 GroundDressing 统一控制，历史 Shader 快照不再覆盖这些数值。
