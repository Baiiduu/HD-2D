# 背包与物品快捷栏

正式地图的背包页和底部中央物品栏已接入。按用户最新要求，人物、背包、技能页统一使用原来的 `assets/meowa/ui/journal/foundation.png`，保持书本外框、尺寸、页签和关闭按钮位置一致。背包内部的空纸面取自这张已有底图；新提取的大书页保留归档，不在运行界面使用。左下角技能栏维持既有素材、尺寸与样式。

背包格子、分类按钮、搜索框、操作按钮、收藏标记、物品图标和物品栏槽位来自 Meowa 对已确认参考图的提取。透明原图与裁片位于 `assets/meowa/ui/inventory/`，文字、数量、选中状态和交互由 Godot 控件显示。

## 当前操作

| 操作 | 效果 |
| --- | --- |
| Tab／ESC | 打开或关闭手帐；打开期间世界、音乐及环境声继续运行 |
| 背包页的分类与搜索 | 筛选全部、装备、工具、材料、种植或消耗品 |
| 单击物品 | 查看说明、持有数量和详情图 |
| 拖到下方物品栏 | 绑定物品；已有绑定移动到占用位置时交换槽位 |
| 双击普通物品／加入快捷栏按钮 | 放入当前选中的物品栏槽位 |
| 双击装备／穿戴按钮 | 穿戴装备；人物页继续提供装备槽和属性比较 |
| 点击物品栏／关闭手帐后按 1–8 | 选中对应物品；打开界面时数字键留给搜索输入 |
| 右键物品栏 | 清除该快捷绑定，物品仍在背包中 |
| 星标／整理 | 收藏物品、整理同类物品顺序 |

物品栏引用背包库存，不复制数量。获得、消耗或移除物品后，两处数量自动同步；物品耗尽会清除失效绑定。当前为每页 6×5 格、8 个快捷槽的可调整制作基线，30 格表示分页大小。正式地图已接入锄地、播种、浇水和恢复草地；工具或种子详情可点“拿起使用”选择物品并返回地图，操作与参数见 [种植说明](farming.md)。制作、食用及其他工具用途继续按对应系统接入。

开合、切页、选择、拖放、装备、收藏和整理已配套接入 Meowa 音效；操作对应关系、音量和替换方式见 [UI 操作音效](ui-audio.md)。

## 配置与接入

在正式地图的 `LoadoutUI` 检查器调整 `ui_scale`、`font_size` 和 `world_dim_amount`，分别控制书本缩放、文字大小和背景压暗。物品栏参数位于 `scenes/ui/item_quickbar.tscn`：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `slot_size` | 68 | 单格尺寸，逻辑视口像素 |
| `slot_spacing` | 6 | 格子间距 |
| `bottom_margin` | 24 | 距离屏幕底部的边距 |
| `background_opacity` | 0.65 | 空槽暗底透明度 |
| `slot_texture`／`selected_slot_texture` | Meowa 提取的槽位 | 普通与选中外观 |

窄窗口时物品栏自动缩小，必要时上移避开左下技能栏。背包网格的行列数位于 `InventoryBookPage` 的 `columns`／`rows`；它在运行时创建，当前可在远程检查器查看，调整后刷新页面生效。

物品栏的悬浮提示只在对应格子上方显示一行名称，默认全透明背景、小字号和浅色描边，不显示纸面详情卡或操作说明，空槽不弹出提示。完整说明在背包页查看。`ItemQuickbar → 悬浮名称提示` 可实时调节：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `show_item_name` | 开 | 名称提示开关 |
| `name_font_size` | 16 | 提示字号，独立于手帐字号 |
| `name_max_width` | 160 | 名称最大逻辑宽度，过长时省略，保持一行 |
| `name_background_opacity` | 0 | 背景暗底透明度；0 完全透出游戏世界，最高 0.5 |

![透明名称提示](inventory-preview/hover-name-detail.png)

背包内的格子悬浮也只显示物品名称，完整说明继续放在右侧详情区。手帐共用的悬浮提示使用无描边的黑字、全透明背景，便于在浅色书页上阅读；收藏、拿起使用等按钮采用短提示。`LoadoutUI` 的 `tooltip_font_size`（默认 16）与 `tooltip_background_opacity`（默认 0，全透明）可独立调节，不随书页正文字号放大。

![背包悬浮名称的透明 UI](inventory-preview/hover-inventory-tip.png)

`data/loadout_catalog.tres` 的 `items` 列表使用 `ItemDefinition` 配置稳定 ID、名称、类别、图标、详情图、说明与是否堆叠；装备继续使用既有 `equipment` 列表。`LoadoutUI.starting_items` 和 `starting_quick_items` 决定演示库存与初始绑定，仅在新存档或旧版存档升级时初始化一次。已有有效存档优先，不会因重新运行补回已耗尽物品。

后续掉落、采集或制作系统可调用 `LoadoutUI.state.add_item(id, quantity)` 与 `remove_item(id, quantity)`，数量不足时扣除失败。通过 `get_quick_slots()` 和 `active_quick_slot` 获取当前物品；`ItemQuickbar.slot_selected` 提供选择通知。

物品数量、绑定、当前槽位、收藏、种植地块与已有装备／技能／训练状态统一保存到 `user://equipment_skills.json`。版本 1／2 的有效存档升级前分别保存为 `.v1.bak`／`.v2.bak`，再写入版本 3；损坏存档仍保留原文件并停止自动覆盖。
