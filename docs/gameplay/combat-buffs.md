# 本局共有成长

2026-10-16。正式增益池收敛为三条弹射成长与三条通用成长，技能学习／强化继续使用原有局内流程。旧重复增益和全部专精暂时退出正式池，资源与接口保留。数值为可调试玩值。

## 正式六条成长

普通单次收益指前十级、非突破等级。各条目独立累计等级，同类增幅相加，再作用于基础值；成长不覆盖人物或武器基础资源。

| ID | 条目 | 普通单次收益 | 实际用途 |
| --- | --- | --- | --- |
| R01 | 弹射速度 | 初速 +10% | 短蓄与满蓄初速同步提高，更快抵达目标并保留更多续弹余速 |
| R02 | 动能维持 | 统一动能效率 +25% | 同时减少飞行衰减、固定碰撞扣速和比例碰撞损失 |
| R05 | 蓄力节奏 | 蓄满效率与发射冷却效率各 +25% | 满蓄更快，提前取消飞行后也能更快准备下次发射 |
| P01 | 伤害提升 | 共享伤害 +20% | 基础剑术及支持共享伤害的技能 |
| P02 | 攻速精进 | 共享攻速效率 +12% | 缩短支持该属性的出手间隔，保留完整动作与各攻击的间隔下限 |
| P03 | 范围扩大 | 共享攻击范围 +15% | 扩大支持该属性的攻击范围 |

P03 不改变 A02 的射程、弹丸碰撞宽度或怪群轮廓，也不扩大奔雷总传播边界。游走收集暂不加入正式池：现有吸取已经较快，清波也会自动收取全场经验，本轮不额外提供移动／吸取成长。R01 不附带碰撞伤害或新的伤害倍率。

### 动能与速度公式

令本局累计动能效率为 E，所有损失共同除以 `(1 + E)`：

```text
飞行衰减 = 基础飞行衰减 / (1 + E)
固定碰撞扣速 = 基础固定扣速 / (1 + E)
实际保速 = 1 - (1 - 基础保速) / (1 + E)
碰撞后速度 = 当前速度 × 实际保速 - 固定碰撞扣速
```

墙体、镜面与怪群接触沿用各自基础保速，统一应用这份动能效率。基础保速为 100% 的接群不会凭空产生比例损失，仍扣固定耗速并持续衰减；自动环绕的续段不额外伪造碰撞。有限正成长不会直接将原有损失减成零或使反弹加速。旧分项效率仍可通过原型配置使用，先计算各分项，再统一应用动能倍率；正式六张卡不会重复授予它们。

正式基础初速 4～12 米／秒，最低续行速度 2 米／秒，飞行衰减 4 米／秒²，每次固定扣速 0.25 米／秒；墙／镜面保速 92%、怪群保速 100%。满蓄且无碰撞时约持续 2.5 秒、行进 17.5 米。只选三次动能维持后 E=0.75，参考续航约 4.38 秒。初速成长和碰撞会分别延长或缩短实际续航，不设固定飞行时长、反弹次数或环绕圈数。

### 蓄力节奏

蓄满时间、发射冷却各除以自己的 `(1 + 累计效率)`。一级将基础满蓄 0.5 秒降为 0.4 秒，将发射冷却 0.2 秒降为 0.16 秒。冷却从发射开始并行计时；当前飞行未结束时仍不能再次蓄力，移动主动结束飞行也会保留尚未结束的冷却。独立收势效率卡已退出正式池，基础收势保留 0.06 秒。

## 抽牌与方向跟进

开战前仍从有效技能池抽三张选一张，不混入共有成长。普通升级在有相应有效候选时保留一个技能学习／强化候选和一个弹射成长候选，第三张从剩余全池随机取得；三张展示位置打乱、不预选、不重复。某类没有有效候选时，其位置用于其它有效候选，总池不足三张就展示全部。

选中一条弹射成长后，记录为当前跟进方向。此后最多三次确认升级内，会再次展示该方向的下一等级；只保证获得选择机会，不自动授予。若方向在前两轮已经出现，即重新计算展示间隔；选择另一条弹射成长则改为跟进新方向。到期方向会优先占用弹射候选位，仍须满足真实收益、开关和等级条件，失效时用其它有效候选补位。

跟进计数只在确认升级时推进，反复重抽不推进、不重置。初始技能与后续升级共用每局三次重抽，重抽优先取得当前未展示候选；如果分组和跟进条件下已经没有可替换候选，就不能消耗次数仅改变排列。取消并重开初始选择保留原牌与已花预算；连续多级逐轮明确选择，空池沿用明确跳过流程。

## 持续成长与突破

六条均为 `Max Level = 0`，不设默认单卡等级上限。本局能升多少级仍受经验规则控制。前十级使用普通增幅，之后每次增幅乘 `sqrt(10 / 下一等级)`，持续增加并温和递减。每五级突破一次，本次增幅乘 1.5，组合卡的两项收益一起放大；不会把以前的全部成长重新乘算。

例如伤害前四级累计 +80%，第五级额外 +30%，合计基础伤害 ×2.10。卡面显示下一等级、突破及实际前后值；动能显示“耗速倍率”下降并说明飞行与碰撞同步降低，避免误读成初速降低。弹射成长标明“下次蓄力生效”。

攻速使用效率相除，不靠持续减法得到零或负间隔。基础剑术的起手、扫刃与收尾按同一倍率缩放，完整走完一次动作后才可开始下一刀；不截断动作或叠加同刀伤害。基础弹射挥剑 0.30 秒，一／二／五次攻速成长后约为 0.268／0.242／0.181 秒，避免第二次成长即被原 0.25 秒动作时长吞掉。`PlayerSwordRules.minimum_attack_interval` 默认 0.12 秒，同时约束动作倍率与出手频率；其它技能保留各自下限。候选至少有一项实际收益才可入池，触底不暗中转换成额外伤害或范围；仍保留组合卡代价必须实际支付的兼容校验。人物素材槽和人物动画保持现状。

## 快照与局内生命周期

卡片生成时复制配置与嵌套附加效果，图标继续共用原资源；编辑器随后调整参数不会改变已经展示的奖励。确认时统一授予主属性与附加效果，不重复结算。正在挥剑的攻击使用起手快照，本体弹射在开始蓄力时固定快照，后续升级不突变本次速度、耗速、方向、进度或技能去重。走路和经验吸取在确认成长、恢复战斗后读取最终值。

波间保留技能与六类成长；结束、撤退、失败和重试清空属性与方向跟进，新局恢复三次共享重抽。成长不写入装备、训练或永久存档。升级选择只冻结战斗对象与战斗计时，世界、天气与管理输入规则保持原有实现。

## 退出正式池的兼容资源

P04「游走收集」暂不加入；P05 独立吸取，以及 R03 固定扣速、R04 保速、R06 收势、R07 周转与 R08～R11 拨怪增益，均不再登记到正式 `RunBuffs.definitions`；S01～S08 全部专精也暂时移出。它们的资源、枚举编号、前置与代价接口继续保留，方便独立原型验证和以后重新设计。

R02 沿用原 ID、UID 与文件 `ricochet/flight_duration.tres`，但主属性改为新增的 `MOMENTUM_EFFICIENCY`；旧的飞行衰减枚举编号保持原义，不冒充统一动能。R05 保留原标识，通过附加效果同时授予蓄力与冷却收益；P04 的组合配置仅保留作兼容原型。后续未确认的特殊弹射能力没有加入卡池。

## Godot 配置

正式地图使用 `WavePrototype/RunBuffs → Definitions` 的六个资源，参数总览“战斗与成长”可搜索普通收益、递减、突破和附加效果。基础弹射值位于 `data/player/body_ricochet.tres`；调整后下一次蓄力生效。不要为同一张卡同时登记旧资源，否则会重新制造重复方向。

| 参数 | 含义 |
| --- | --- |
| Max Level | 0 持续可选，正数为显式等级上限 |
| Bonus Per Level / Bonus Cap | 主属性普通收益与累计上限；Cap=0 不额外封顶 |
| Diminishing After | 温和递减起始等级，0 关闭 |
| Breakthrough Every / Multiplier | 突破间隔与本次倍率，Every=0 关闭 |
| Extra Effects | R05 的冷却效率等附加效果 |
| Required Levels | 兼容原型的前置等级；正式六条均为空 |
| ID / Title / Icon / Enabled | 稳定标识、名称、现有图标与候选开关，出战中不改 ID |
| RunGrowth → Cards Per Draw / Rerolls Per Run / Draw Seed | 展示数量、共享重抽次数、独立抽牌随机种子 |

`WavePrototype/RunGrowth → Enabled` 控制普通经验成长。若 `WavePrototype.population_rules.simulation_mode` 为 true，则仍按怪潮模拟配置直接开战、预装技能，不走普通抽卡流程；试玩这套成长需关闭模拟模式。保留用户当前的模拟模式选择，不为成长整合自动切换。

## 实现与验证范围

`GrowthBuffDefinition` 和 `GrowthBuffEffect` 维护条目、统一枚举与附加效果；`RunCombatModifiers` 计算本局最终值；`RunBuffs` 过滤真实收益并生成配置快照。`GrowthDrawPool` 负责技能／弹射候选、跟进与重抽，`RunGrowth` 只在实际确认升级时记录方向。

`PlayerRicochet.get_stats(modifiers)`、`PlayerSword.get_stats(...)`、`Player.get_movement_speed(modifiers)` 与 `RunGrowth.get_attraction_radius(modifiers)` 继续作为真实最终值入口。不新增逐帧资源复制、寻群、碰撞查询或音效通路。

`tests/test_ricochet_growth.gd` 已补充三条合并收益、一百级正值耗速、正式六卡注册与游走收集排除、深快照和局内生命周期；`test_growth_draw.gd` 补充候选分组、三轮跟进、重抽计数和小池退化；旧专精专项通过显式加入旧资源保留兼容验证。当前仅完成脚本语法、资源引用与离线数值／抽牌逻辑检查，未启动 Godot；引擎类型检查、物理回归和实际手感仍待试玩。
