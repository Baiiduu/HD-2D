# 本局共有属性与专精

2026-10-15。共有属性沿用真实局内成长、三选一和每局共用三次重抽。基础剑术、A01—A04、本体弹射、走路与经验吸取读取同一局属性状态；每项只作用于支持它的系统。以下为可调试玩数值，游戏平衡需要结合实际怪潮继续检验。

## 长期成长与突破

基础条目的 `Max Level = 0`，取消默认三级封顶。每次升级继续取得实际收益；本局总等级上限仍由经验规则控制。正数上限仍可用于有限内容，当前专精各五级。

前十级使用常规单次收益；此后每次比例收益乘 `sqrt(10 / 下一等级)`，持续增加但温和递减。续弹效率同样使用比例收益，不再有整数次数预算。`Diminishing After = 0` 可关闭递减。

每五级有一次突破，当前等级的增幅乘 1.5；续弹效率条目使用 2 倍，增强本次耗速效率收益。突破同时放大组合词条的收益和代价。它只改变本次授予量，不乘算以前所有成长。例如伤害前四级合计 +80%，第五级额外 +30%，累计为基础伤害 ×2.10。卡面显示下一等级和“突破”，不再显示 `Lv.4/3` 或 `Lv.4/0`。

攻速使用效率：基础出手间隔 ÷ `(1 + 累计攻速效率)`，不会通过持续减法得到零或负间隔。旧 `COOLDOWN` 枚举与线性减幅配置保留兼容；当前 P02 使用新追加的 `ATTACK_SPEED`。旧十四个属性编号不改动。

## 基础条目

每级收益指前十级的普通成长，突破和后期递减另外计算。同类增幅相加，最终作用于基础值，不覆盖基础资源。

| ID | 条目 | 普通单次收益 |
| --- | --- | --- |
| P01 | 伤害提升 | 共享伤害 +20% |
| P02 | 攻速精进 | 共享攻速效率 +12% |
| P03 | 范围扩大 | 支持范围属性的攻击半径 +15% |
| P04 | 步履生风 | 普通走路速度 +12% |
| P05 | 拾光引力 | 经验开始吸取的半径 +20% |
| R01 | 弹射速度 | 起步与满蓄初速 +15% |
| R02 | 滑行续航 | 飞行耗速效率 +15%，衰减 = 基础衰减 ÷ (1 + 累计效率) |
| R03 | 续弹效率 | 固定碰撞耗速效率 +20%，耗速 = 基础耗速 ÷ (1 + 累计效率) |
| R04 | 反弹续势 | 墙／镜面与怪群保速各 +5 个百分点、共享伤害 +3% |
| R05 | 蓄力效率 | 满蓄效率 +20% |

| R09 | 拨怪推力 | 绕行参考速度 +15% |

P01、P02、P03 由基础剑术和支持对应属性的技能共享。P03 不改变 A02 的射程或弹丸碰撞宽度，也不扩大拨怪圈；R08 只扩大拨怪判定，不扩大剑光。P04 只改正常行走，不叠加到已发射速度或闪身距离。P05 不增加经验掉落、收集距离或宝石速度，只改变开始吸引的范围。

蓄力、收势、发射冷却、飞行耗速与固定碰撞耗速使用效率相除；例如基础满蓄 0.8 秒、效率 +20%，实际约 0.667 秒。保速最多 100%，不会逐次反弹加速失控；R04 满保速后仍有伤害收益；固定碰撞耗速和飞行衰减继续生效。R07 在发射冷却被飞行覆盖时仍有明确蓄力收益。卡面只展示本次实际变化的属性，不虚报已经饱和的收益。

## 专精与取舍

达到前置等级后，专精才进入同一个有效候选池，不自动授予、不消耗前置等级。各专精最多选择五次，第五次也有突破。多个专精可组合，补足弱点需要付出其它成长选择的机会；不额外引入专精装备栏或新的抽卡预算。

| S01 | 重锋镇岳 | P01 ≥4 | 伤害 +35%、推力 +15% | 攻速效率 −8% |

## 有效收益与时序

候选必须至少有一项真实收益。每项代价也要能实际生效：完整动作时长已经封住攻速，继续降低攻速仍不改变出手间隔时，不能获得免费重锋收益；其它属性下限完全吞掉代价时也不提供该组合。卡片明确显示“代价”和真实前后值。

攻速不加速或跳过完整动作帧；各攻击自身的最短间隔仍生效。两种基础剑术模式都参与资格检查，飞行挥剑封底时仍可强化普通攻击。当前速度、飞行衰减、碰撞耗速和真实碰撞继续约束路线：反弹后余速不足即收势，不按总时长或次数截断，水面、地图边界和断层仍结束飞行，每只怪每次发射最多拨一次。

收益、代价和突破在一次授予中统一应用。卡片生成时深复制配置，包含附加效果资源；编辑器随后调整嵌套参数，不改变已经展示的奖励。正在进行的挥剑使用起手快照，本体使用开始蓄力时的快照，升级不突变当前刀光、飞行方向、速度、衰减或推力。走路和经验吸取在成长确认、战斗恢复后读取新值。

波间休整保留等级与专精，结束、撤退、失败和重试清空。初始选择仍只学习技能，所有成长不写入装备、训练或永久存档。空池继续使用原有明确跳过流程，不堵住清波。

## Godot 配置

正式地图选择 `WavePrototype/RunBuffs → Definitions`；参数总览“战斗与成长”可搜索以下参数。组合词条的附加效果也会被索引。

| 参数 | 含义 |
| --- | --- |
| Max Level | 0 持续可选，正数为本条目的等级上限 |
| Bonus Per Level / Bonus Cap | 主属性普通收益与同类总增幅上限；Cap=0 不额外封顶 |
| Diminishing After | 温和递减起始等级，0 关闭 |
| Breakthrough Every / Multiplier | 突破间隔与本次增幅倍率，Every=0 关闭 |
| Required Levels | 专精前置 ID 与等级；同表各项需同时满足 |
| Extra Effects | 每项独立选择属性、正收益或负代价、可选总增幅上限 |
| ID / Title / Icon / Enabled | 稳定标识、名称、现有图标与候选开关；出战中不改 ID |

基础属性资源在 `demoWithMeowa/1/data/growth/` 与其 `ricochet/` 子目录；专精在 `specializations/`。基础弹射值仍在 `data/player/body_ricochet.tres`，基础剑术值仍在 `data/player/basic_sword.tres`，运行时不覆盖这些资源。`WavePrototype/RunGrowth → Enabled` 独立控制是否开启经验成长，保留当前场景的选择；需要试玩成长时打开。

图标和卡框复用已有 Meowa 素材。卡面遵守现有布局，等级和突破放在标题，正文保留真实收益和代价。

## 实现与验证

`GrowthBuffDefinition` 定义条目、成长曲线、突破与前置；`GrowthBuffEffect` 定义统一枚举和附加收益／代价。`RunCombatModifiers` 管理本局等级、叠加、组合授予和无副作用预览。`RunBuffs` 检查真实收益和代价、生成卡片并保存配置快照；`RunSkills` 继续合并技能和共有属性候选。

`PlayerRicochet.get_stats(modifiers)`、`PlayerSword.get_stats(...)`、`Player.get_movement_speed(modifiers)` 与 `RunGrowth.get_attraction_radius(modifiers)` 是实际使用的最终值入口。新增属性不额外产生逐帧资源复制、全场扫描或新的音效通路。

`tests/test_growth_specializations.gd` 验证单属性一百级、温和递减、突破预览、有限等级兼容、八种专精解锁／满级／代价、真实行走位移、扩大经验吸取、深配置快照、动作瓶颈过滤与生命周期；`test_ricochet_growth.gd` 覆盖全部弹射属性及有足够速度时超过十二次真实反弹。`test_combat_buffs.gd` 使用显式有限配置保留旧减冷却语义验证；基础剑术、弹射、抽卡和参数目录继续回归。实机呈现使用正式地图当前相机与原生 D3D12。

本轮人物弹射已切换为速度机制：沿用 `RICOCHET_DURATION`／`RICOCHET_BOUNCES` 的原编号，分别映射到飞行衰减与固定碰撞耗速，收益按效率相除；旧时长和次数不再参与人物运行。按用户要求，本轮仅完成静态语法及数学检查，更新后的引擎回归用例尚未运行。
