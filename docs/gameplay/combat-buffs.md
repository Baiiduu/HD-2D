# 本局共有成长

正式 World 使用四条普通成长与五条史诗机制，数值是首轮可调试玩值。卡面、专属图标、特效和人物动作素材留待逐卡制作，本轮复用现有界面与素材。City 和共享旧资源保留原规则。

World 关闭旧装备的属性及旧技能数值加成，保留装备、库存与训练存档。无训练加成时使用基础生命上限 100，不再叠加旧皮甲的测试生命；基础恢复与吸血上限按实际生命上限自动计算。地图入口为 `BattleConfiguration.configuration.equipment_bonuses_enabled=false`，它不写入角色存档，载入旧装备不会重新启用；City 和原型保持原装备行为。普攻、弹射与局内技能继续使用各自战斗配置和本局成长。

## 成长与抽牌

普通成长为伤害提升 P01（基础伤害 +20%）、攻速精进 P02（攻速效率 +20%）、弹射速度 R01（初速 +20%）与动能维持 R02（损失效率 +25%）。蓄力节奏 R05 和旧普通范围 P03 不再登记到正式 World 卡池，旧接口和资源保留。

人物等级 5、10、15……以一次史诗选择替代该级普通选择。先提供尚未获得的史诗机制；全部获得后提供仍有效的史诗续级，再无有效项则回退普通池。史诗取得后的下一等级立即进入普通池；普通阶段不展示未获得的史诗。候选不足三张时展示全部，真正空池跳过该次选择，不冻结在空界面。

World 全池随机，不再预留技能／弹射位或对弹射方向强制跟进，位置随机且不预选。初始选技仍独立从有效技能池三选一。初始与后续选择共用每局三次重抽，没有实际替换候选不扣次数；重抽不推进等级。大额经验按下一待选等级逐轮处理，不能因当前总等级已超过五级而漏掉史诗轮。

## 史诗机制

| ID | 机制 | 初次效果与续级 |
| --- | --- | --- |
| E01 | 空间扩张 | 适用攻击半径／射程及显示尺寸 +30%；普通续级继续扩张 |
| E02 | 动能超载 | 当前剩余弹射动能 4～16 米/秒对应最终伤害 +20%～100%，端点外夹紧；续级增加该曲线强度 |
| E03 | 千手 | 仅弹射挥剑增加真实刀数：初次低速两刀，余速越过 8／12 米/秒后为三／四刀；续级每次再加一刀，最多五级、单次最多八刀 |
| E04 | 一拳超人 | 伤害 ×3、攻击频率减半；续级增加伤害，减频只应用一次，不逐级翻倍间隔 |
| E05 | 全能吸血 | 按怪物实际损血的 3% 恢复，每秒另有最大生命 5% 上限；续级同时增加吸血与上限 |

千手速度切档有 0.4 米/秒余量，避免门槛附近反复抖动。一次根出手锁定刀数、伤害和追加刀倍率，在原完整动作预算内顺序完成各刀；每刀都有真实扫刃、去重和地形／挡墙检查，不将刀数直接乘到单次伤害上。追加刀初值为原刀三分之一，首张卡理论上提升约 33%～100% 剑术输出；这不是额外增加一至三刀全额伤害。根出手间隔保持，每刀复用现有剑光与独立余迹；动画时长与各刀表现仍需人工试玩确认。

速度增伤使用 `PlayerRicochet.flight_speed` 的剩余动能，不使用环绕减速后的位移速度；真实路段另外保存动能时间切片。每次剑术起手、弹丸出射和雷潮触发各读一次，后续命中不重读人物速度。奔雷在 World 按每次触发更新攻击属性，同一次传播的后续层保留本次快照。

范围扩大同步基础剑术、A01 及已支持的雷光／棱晶／镜梭射程、碰撞宽度与显示尺寸；World 奔雷的触发、单跳和总传播边界同步扩展，保留实际挡墙。持续环绕在增大后的剑术射程之前识别活怪群，预测与真实移动共用识别半径；实际外沿仍由怪物体型、人物胶囊和原有留白构成，不把轨道向外扩大。群体被清空后仍按原有切线离开规则处理。

## 开局续航

有效持续环绕期间，所有现有怪物伤害统一降低 30%，不区分普通／特殊招式，也不产生无敌；原有共享受伤间隔保持。

基础普攻与弹射挥剑真实造成伤害时，每次原始出手恢复最大生命的 1.5%，每个滑动战斗秒最多恢复 5%。同刀打多怪、千手重复刀共用一次基础恢复资格。全能吸血按每个真实伤害事件另外结算，使用独立上限；不按请求伤害或过量伤害回血，模拟命中不回血。满血部分不占用恢复预算。人物已经死亡时不靠延迟命中复活。

恢复预算只随未冻结战斗时间推进，不受 UI 实时时钟或逐刀短顿补算影响；休整保留属性，结束／重试清空。命中结算使用常数时间累计量，预算过期按物理步清理，不在每个怪物伤害回调内重扫恢复记录。

## 统一属性与边界

`RunCombatModifiers` 是本局最终属性入口，`CombatAttackSnapshot` 保存一次出手的动能与刀数，`RunSurvival` 管理基础续航和两个独立预算。所有现有武器复用真实 `CombatDamageEvent.amount` 触发全能吸血，新增攻击可继续走同一接口。

全局攻速影响出手间隔、剑术完整前摇／扫刃／收刀、A01 旋转速率和同体命中间隔；保留各攻击最短间隔和有效收益筛选。独立世界余迹使用自己的消散时间。攻速不改变走路、弹丸飞行速度或人物蓄力时长。重击的减频进入同一间隔结算，可以由攻速成长抵消。

动能维持 E 继续将飞行衰减与固定扣速除以 `1+E`，比例保速为 `1-(1-基础保速)/(1+E)`。速度与耗速仍在开始蓄力时固定本次快照；新速度增伤和千手在每次出手读取当下余速，不重新修改这份物理快照。具体基础速度／衰减以地图人物资源为准。

原普通属性继续同类相加，并保留温和递减与周期突破。千手采用整数等级，关闭条目突破和递减。20%～100% 为希望验证的有效战力增幅范围，单卡纸面增幅不等同所有局面的实战提升；平衡和手感尚待试玩。

## 调节与验收

正式资源位于 `data/combat/scenes/world/growth/`，地图入口为 `BattleConfiguration.configuration.growth_rules`，参数总览归入「战斗与成长」。五张史诗分别位于 `growth/epic/`；修改数据无需新建技能节点。

「设置 → 人物」只读展示生命、伤害、攻击频率、实际间隔、范围、满蓄初速、余速、耗速、动能增伤、千手刀数、基础续航与吸血，以及已有史诗等级。当前没有暴击机制，面板明确显示尚未启用。打开设置仍只占用人物输入，世界、音乐和环境声继续运行；旧背包／人物管理页与物品栏不因此重新开放。

若当前地图选择了怪潮免伤模拟，仍沿用直接开战和模拟技能配置；体验升级需在原有怪潮配置中关闭模拟，本轮不改玩家保存的模拟选择。

无界面回归覆盖史诗等级与普通续级、自由抽取与多级连升、重击与攻速、真实多刀及挡墙／冻结／取消、余速快照、独立回血预算、模拟／过量伤害、范围联动与提前接群。正式地图的视觉、卡面排版、千手观感和持续绕行生存平衡由人工验收；本轮不自动启动渲染窗口或制作新美术。
