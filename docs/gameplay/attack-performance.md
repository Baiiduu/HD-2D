# 攻击资源复用与性能

用户要求所有攻击在保持游戏效果的前提下尽量节约资源。当前覆盖 A01 全部等级、A02 实际投射物与视觉组件、史莱姆接触攻击；后续玩家、敌人、弹丸和范围攻击沿用下面的要求。

## 所有攻击的共同要求

- 固定网格、索引、图集和材质尽量复用；位置、旋转、缩放和播放帧通过实例更新，不逐帧重新创建资源。
- 重复出现的命中特效、弹丸等按实际需求复用对象。闲置时停止更新，取消或结束时完整重置；不预建大量尚未用到的对象，也不遗漏应显示的效果。
- 先检查阶段、冷却、已命中记录、范围、高差与角度，再做射线、地形采样和导航查询。
- 共享有明确有效期的查询结果，地形改变、战斗结束或相关参数变化后失效；动态挡墙实时检查。
- 不通过减少动画帧、改变伤害频率、删减并发特效、降低命中精度或关闭场景效果取得性能数字。声音沿用既有全局声音预算与合并规则。
- 新攻击接入时验证高等级、多效果和敌人密集情况，并回归墙体、台地、坡道、移动、闪身、升级冻结与清场。性能比较使用相同地图、镜头和参数，分别记录攻击 CPU 与整帧耗时。

这些要求规定复用和验证方式，不要求所有攻击使用同一种几何形状或一套庞大的通用武器框架。

## A01：保留完整斩光，减少重建

原双刃在每个物理帧重建两份网格，重复计算约两千次地面采样，且在排除不可能命中的敌人之前就做导航查询。

现在每刃使用 125 个独立顶点与 576 个索引，仍绘制原有 192 个三角形。空旷平地上两刃共享同一个网格，移动和旋转只更新实例变换；范围、角度或离地高度改变时重新生成。墙体继续实时裁切；坡道、水面、断层与台地边缘继续逐点贴地，仍使用相同三角形、纹理坐标和动画。

`scripts/combat/attack_surface_query.gd` 是战斗共用的地表查询服务，通过 `WavePrototype.get_attack_surface_query()` 获取。`flat_ground(origin, radius)` 判断完整范围及边缘缓冲是否为同高地面，`unclipped_flat(origin, radius)` 再检查挡墙，决定能否直接共享未裁切网格。有墙的平地只做实时墙面裁切，不重复逐点采样已经确认的地面高度。地形资格缓存限于当前物理帧，`TerrainData.changed` 或数据替换立即清空；动态障碍每次查询。其他贴地攻击可复用这个服务，不适用的攻击继续自行判断。

命中先过滤未出生／已死亡、已命中或尚在命中间隔中的敌人，以及不在扫过角度内的目标，再执行原有范围、地面高差、遮挡与导航判定。双刃仍共享同体命中间隔。闲置时不反复执行取消和隐藏操作，闪身、冻结与清场沿用既有行为。

本机原生 D3D12 / Forward+，16 只实际追击的史莱姆、A01 七级双刃，预热后采样四秒：

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| A01 每物理帧 CPU 平均 | 12.11 毫秒 | 0.64 毫秒 |
| A01 每物理帧 CPU P95 | 16.06 毫秒 | 1.06 毫秒 |
| 整体渲染帧间隔平均 | 39.45 毫秒 | 34.51 毫秒 |

攻击 CPU 平均减少约 95%。整帧仍包含地图、敌人、光影与其他系统的开销，这组结果不代表整体已达到 60 FPS，也未据此定位剩余瓶颈。

另以当前等级资源、16 个固定目标、120 次 1/60 秒步进隔离对照：

| 等级 | 优化前 CPU 平均 | 优化后 CPU 平均 | 网格更换次数（前→后） |
| --- | ---: | ---: | ---: |
| 6，单刃旋转 | 5.20 毫秒 | 0.29 毫秒 | 120→1 |
| 7，双刃旋转 | 12.05 毫秒 | 0.47 毫秒 | 120→1 |
| 8，高速双刃 | 12.23 毫秒 | 0.48 毫秒 | 120→1 |

每级前后的总伤害、三角形展开后的顶点及纹理坐标哈希完全一致。手动步进每次清空共享地形缓存，避免因整段测试处于同一引擎帧而低估开销。

## 正式战区：满级技能与 128 只怪物

2026-10-14 在当前建筑密集的正式地图中，原平地优化遇到任一墙体就回退到全部地形采样，并逐帧创建新的 GPU 网格，导致满级双刃开销再次放大。现已拆开平地资格与障碍查询：墙面射线仍逐物理帧精确计算，平整地面的高度不再重复采样；需要裁切时每刃复用独立网格，只更新完整顶点和 UV 缓冲，同时更新包围盒。索引、192 个三角形、动画帧、伤害间隔和穿墙限制保持。

最近目标查找先比较距离，再检查遮挡和导航；更远且不可能替换当前目标的怪物不做昂贵查询。怪物避让哈希格由 2 米改为 1 米，仍计算全部真实半径内同伴，没有邻居上限或更新降频。`TerrainPath` 的格子四角高度在同一物理帧复用，坡道插值与桥面抬升保持精确；换帧、数据替换、层高变化或 `TerrainData.changed` 立即使缓存失效，动态墙体查询不缓存。

本机 Godot 4.7.2、D3D12 / Forward+、RTX 3050、1280×800 原生窗口。在相同战斗位置、128 只实际移动的高生命测试怪、四技能与增益全满、预热后连续采样五秒的对照中：

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 物理帧 CPU 平均 | 22.00 毫秒 | 12.20 毫秒 |
| 渲染帧间隔平均 | 148.71 毫秒 | 22.05 毫秒 |
| 渲染帧间隔 P95 | 158.10 毫秒 | 28.63 毫秒 |
| 邻居候选检查／物理帧 | 2019.83 | 1363.47 |

这组压力样本用于持续放大靠墙双刃与密集避让，人物固定位置，仅运行实例的怪物生命提高以保持怪潮；没有改写玩法资源。它不包含持续击杀和补怪，不能作为整局稳定帧率的承诺。优化后的平均约 45 FPS，物理 CPU 平均减少约 45%，邻居候选减少约 32%。

另用 `tools/benchmark_enemy_population.gd -- --uncapped --combat --walk --counts=128 --warmup=12 --duration=10` 验证满级完整战斗：保留十倍高波次生命、真实死亡、经验掉落／吸取、补怪和人物碰撞。完整走位仍有帧时间尖峰；这一阶段另一个编辑器启动的正式地图游戏窗口同时运行，结果仅作运行回归与瓶颈排查，不作为单窗口帧率验收。当前地形保持原样，未来统一地面高度不会取消建筑碰撞、遮挡或反射检查。

此次原生验证沿用场景实际保存的相机：FOV 28°、距离 15 米、俯角 25.414°、焦点 0.9 米、景深关闭、16:10；这些是测试前已有配置。没有为采样降低光影、天气、动画、裁切精度或特效数量。对照脚本、日志和截图保存在 `D:\.codexfile\work\world-performance-20261014`。

## A02：固定拖尾与命中对象复用

`LightPierceAutoAttack` 空闲或未学习时停止物理更新。资格、距离和冷却筛选后才查询地形与动态墙体，球形连续扫掠与其它投射物共用 `ProjectileCollision`；没有只检测当前帧终点而跳过中途怪物。命中按真实碰撞体进入顺序结算，查询不依赖固定返回上限。

整套飞行组件按真实并发需要创建并在飞行、完整命中动画与收尾结束后归还，复用节点、材质、拖尾及命中星芒；不通过固定池上限丢失攻击。每发固定出手时的属性快照，升级冻结继承战斗节点的运行模式；波次代号变化与阶段结束立即清理旧弹丸。

`LightPierceEffect` 的拖尾保留 42 个顶点、40 个三角形和原纹理坐标，多个组件共享一份固定网格。飞行长度、宽度与镜头方向通过实例变换更新，取代逐帧创建网格；1000 次拖尾更新的网格更换次数从 1000 变为 0。

当前 A02 使用 Meowa 原生小尺寸像素雷刺与断续电光，启用 `Preserve Trail Pixel Scale`：短尾迹只改变采样区域，保持固定世界像素密度，不增加网格或节点。雷刺长轴沿真实弹道，Q/E 转到纵深方向时自然缩短，尖端锚定真实投射物位置；起手裁切尚未行进的部分。八帧命中动画和既有对象池保留。A03 的旧碰撞星芒通过独立场景连接，继续使用原资源。

命中星芒的节点、QuadMesh 和材质按实际并发需求创建，动画结束或取消后隐藏并归还本组件，再次命中重置位置、帧和计时。不同命中仍独立完整播放，空闲时不更新。重复 200 次命中／取消不增加节点数量；地图退出时随组件释放。

前后 24 组几何对照覆盖 0°／90°／180° 镜头、水平／倾斜方向、不同飞行长度及父节点旋转缩放。三角形索引与 UV 一致，世界位置最大差异约 0.000015 米，为变换运算的浮点误差。枪锋、八帧命中、拖尾渐宽与消退、短时映照及原 Shader 保留。

## 敌方攻击：提前检查受击资格

波次为 `WaveEnemy` 提供可选的 `can_damage_player(amount)` 回调，与 `damage_player(amount)` 共用阶段、战斗代次、冻结、受击保护、生命和合法伤害检查。史莱姆在接触范围与高差满足后先检查资格，才做实时遮挡射线；实际扣血时再次校验。未来敌方弹丸和范围攻击可使用同一接口。

人物已被命中并处于保护期间，额外 120 次接触不再产生遮挡射线，也不重复扣血。保护结束后仍实时查询，新挡墙继续阻止命中；开波保护、冻结、零伤害和过期战斗回调均保留原规则。
