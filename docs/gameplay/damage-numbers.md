# 伤害数字框架

正式波次场景已接入 `DamageNumbers`。人物普攻／飞行挥剑、A01、A02、棱光弹射、反射镜印、奔雷涌潮共用同一条反馈链路。

当前完成事件、运动、样式、相机投影与节点复用。伤害数字采用 CodeMan38 的 **Press Start 2P** 粗像素字体，原始文件、来源与 SIL OFL 1.1 许可证放在 `assets/fonts/press_start_2p/`。World 已启用真实暴击：人物普攻、弹射挥剑和技能的每次有效命中固定 10% 概率，造成最终攻击伤害的 2 倍，当前装备和成长均不提高暴击率。重击飘字仍只作为独立样式预留；「一拳超人」的伤害与减频按原成长规则结算。

## 结算与显示

`WaveEnemy.take_damage()` 完成原有资格检查和扣血后，通过 `damaged` 信号发出 `CombatDamageEvent`，每次有效扣血一次。数值采用实际扣除生命，溢出伤害保留在 `requested_amount`，不会把无效命中、出场保护或冻结期间的攻击显示成伤害。

暴击只在上述资格通过后、扣血前掷一次；以 `source` 标明人物来源的伤害进入地图暴击规则，无来源的直接清理／调试伤害保持原值。暴击在伤害、动能及重击等已有增益之后乘一次，不改变攻击频率、范围、同目标去重或攻击批次。怪物从真实生成路径取得地图概率、倍率与专用随机流，分裂和增援共用；随机流独立于刷怪、选卡和视觉，每局按本局种子初始化，冻结与无效命中不消耗随机数。City 默认概率为 0，保留原玩法。

巨量怪潮模拟仍经过相同资格与命中检查，但锁定怪物生命。事件标记 `simulated`，实际扣血 `amount` 保持 0，显示层通过 `display_amount()` 读取完整的 `requested_amount`，保留真实攻击、技能等级与成长数值，不按剩余生命截断；不会触发死亡、奖励或分裂。普通战斗继续显示实际扣血。

事件保存实际伤害、请求伤害、来源、表现标签、方向、目标 ID、世界锚点与致死标记；真实暴击另记 `critical` 与 `critical_multiplier`，统一选择 `critical` 数字样式，雷系非暴击仍保留原蓝色样式。不修改武器传入的上下文字典，连续命中不会沿用上次暴击标签。事件不保存怪物或武器节点，计分批次与基础回血快照继续共用原身份；吸血只读取实际损血，模拟和过量伤害不额外回血。数字停留在本次命中位置，怪物移动或释放后仍可完成动画。`get_damage_feedback_position()` 可供新怪物重写；现有史莱姆和具体怪物使用实际 Sprite 尺度和画布高度。

显示器监听当前会话的 `enemy_spawned`，自动连接新怪物，包括分裂幼体。新怪物继续继承 `WaveEnemy` 并通过波次登记即可，无需分别写飘字。

## 新攻击接入

保持原有伤害公式，只在真实命中处提供可选反馈信息：

```gdscript
enemy.take_damage(final_damage, {
	"source": &"new_weapon",
	"style": &"lightning",
	"direction": heading,
})
```

旧的单参数 `take_damage(final_damage)` 仍有效，使用普通样式。方向为世界向量，显示器在出字时换算为当前相机的左右方向。不要额外手动调用飘字，否则同一次伤害会重复显示。

独立预览或其它已结算的伤害来源可构造 `CombatDamageEvent` 并调用 `DamageNumbers.present(event)`；这个接口不扣血，也不参与攻击判定。

## 样式扩展与参数

共用资源位于 `demoWithMeowa/1/data/combat/damage_numbers/`，正式地图读取独立的 `data/combat/scenes/world/combat/damage_numbers/`。下表为 World 当前实际配置：

| 标签 | 字号／起跳放大 | 当前用途 |
| --- | --- | --- |
| `normal` | 24／1.3 倍 | 人物基础剑术、A01、棱光弹射、反射镜印的非暴击 |
| `lightning` | 28／1.3 倍 | A02 与奔雷涌潮的非暴击 |
| `heavy` | 32／1.45 倍 | 暖金重击表现预留，仅预览使用 |
| `critical` | 32／1.5 倍 | 真实暴击，金橙色、感叹号与较大弹出幅度 |

各地图保留已保存的独立字号，本轮不改字体或字号资源。关闭字体抗锯齿、MSDF、微调和子像素定位，数字节点使用最近邻采样。连续命中的横向间距按字宽与放大倍率留空，纵向间距读取地图配置。离屏判断计入实际字面尺寸和动画放大，避免多位大数字提前消失。其它 UI 字体保持各自配置。

新增 `DamageNumberStyle` 资源，填写唯一 `style_id` 并加入 `number_styles` 即可。未知标签、空样式槽会回退普通样式。`source` 负责识别攻击来源，`style` 负责选择外观，两者不绑定伤害公式。

Godot 正式场景入口：`WavePrototype → DamageNumbers`。统一参数面板位于“战斗与成长”，可以编辑各样式的字体、字号、颜色、描边、投影、后缀、小数位，以及压缩、上升、顶点停留、回落、侧移、倾斜、消散和碎光。资源编辑会影响引用同一资源的场景；需要独立风格时先复制资源。字体和文本尺寸在新数字出现时确定。

同一目标按中、右、左交替分槽，不延迟首次反馈、不合并伤害。横向间距同时考虑字宽、描边和放大倍率；相机旋转时重新投影世界锚点，背后及屏幕外的数字隐藏，生命周期继续推进。当前不做建筑遮挡射线查询。

## 生命周期与性能

- `DamageNumber` 不单独逐帧处理，不使用每击 Tween 或 Timer；显示器集中推进活跃节点，没有数字时停止处理。
- 默认预热 24 个节点，闲置池保留最多 128 个。上限只限制闲置节点，密集命中仍按真实次数创建，超出部分完成后释放；目标分槽状态随最后一个数字回收。
- 数字不接收鼠标输入，独立于场景灯光和景深，不跟着怪物闪白或变暗。
- 加入会话的战斗冻结机制，升级选择冻结动画；管理界面沿用原有世界运行规则。清波休整保留尾段，新局、结束、撤退时清空。
- 普攻与击杀短顿期间，数字用单调时钟的真实经过时间继续播放，不用当前 `Engine.time_scale` 反推本帧时长，避免切入时将新数字直接推进至过期。普通战斗仍沿用战斗时间；闲置唤醒、冻结／恢复和清理都会重新同步时钟，不补算冻结或闲置时间。
- 当前碎光为可调的简单方形占位反馈；后续定稿字体或更丰富素材可替换显示层，不改技能和伤害计算。

## 预览与验证

从“地图切换 → 伤害数字预览”运行 `scenes/previews/damage_numbers_preview.tscn`，使用当前正式地图、已保存的实际相机和光影，循环演示四种标签及连续命中。预览脚本仍显式指定标签，不影响真实暴击概率；World 正式攻击按实际暴击事件显示。Q/E 沿用现有相机控制。

`tests/test_damage_numbers.gd` 覆盖真实扣血、致死后节点释放、无效伤害、连续错位、相机旋转与背面、冻结恢复、扩展标签、池复用、密集命中回收和参数入口。既有部分攻击测试仍含旧的 A01 开关与线性冷却预期，验证时须按当前独立开关及攻速公式隔离夹具，不修改正式场景配合旧断言。

`tests/test_critical_damage.gd` 验证固定种子下的 10% 独立随机流、2 倍结算、技能与剑术共用入口、保护与冻结不掷骰、上下文复用、过量伤害、模拟飘字，以及正式场景真实刷怪和挥剑后的暴击事件；同时检查现有成长不增加概率、人物页读数和暴击数字样式。

`tests/test_damage_numbers_hitstop.gd` 覆盖短顿切入帧、同目标连续命中、近战与奔雷致死、冻结恢复和闲置复用的计时；`tests/test_walking_sword_hitstop.gd` 使用真实行走与剑术，检查每刀实扣 10 点后对应的数字仍处于有效显示状态。均为无界面逻辑／数据验证，实际数字辨识度与动画观感仍需正式地图人工试玩。
