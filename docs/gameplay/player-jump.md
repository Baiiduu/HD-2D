# 人物跳跃与下落

World 当前暂时关闭 `Player.jump_enabled` 和自动迈步；空格不会起跳，栅栏底座、花坛和建筑台阶按障碍阻挡。以下跳跃与动画参数仅供保留原型或后续重新启用时参考，当前开关以[正式地图说明](../../demoWithMeowa/1/scenes/world/README.md)为准。

保留的黄衣青年原型包含侧向与背向的起跳、下落、落地动作。侧向沿用三分之四朝向，左右镜像；背向沿用原站姿，没有新增正面视图。

运行游戏后按 **空格** 跳跃，可配合原有 WASD / 方向键移动。空中不能再次起跳；按住空格不会落地后自动连跳。门口低台阶可以直接走上、走下，保持走路动作；走下较高台地时仍进入下落，接地后短暂屈膝，再恢复待机或跑步。水平移动在落地缓冲期间仍可操作。

## 可调参数

在 **Player → 台阶通行** 中调整 `Auto Step Enabled`（默认开启）和 `Max Step Height`（默认 0.25 米）。后者是单级台阶的最大通行高度，房屋门口每级约 0.14 米。迈步前检查头顶、前方与台阶顶面；高于上限的障碍仍会挡住人物。自动迈步不触发跳跃、下落或落地动作与音效。

在主场景 **Player → 跳跃与下落** 中调整：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| Jump Enabled | 开 | 控制主动跳跃；关闭后仍有正常重力和下落动作 |
| Jump Height | 0.8 米 | 相对起跳地面的最高离地高度 |
| Gravity | 20 米/秒² | 同时影响上升与下落；同样高度下，数值越大，跳跃越快 |
| Landing Time | 0.12 秒 | 落地屈膝恢复时间；0 可关闭缓冲姿态，不限制水平移动 |

按键位于项目设置 → 输入映射 → `jump`，默认物理空格键。运行中的 Remote 修改只影响当前运行；本地 Inspector 修改后保存场景可保留设置。

## 动画与资源

`assets/meowa/player/animations.tres` 新增 `jump`、`fall`、`land` 及对应的 `_back` 动作，全部为一次播放；上升与下落播到最后一帧后保持，由物理状态决定何时切换。原待机与跑步素材保留。

起跳离地、最高点、下落和接地都由 CharacterBody3D 的真实物理位移与碰撞控制。动画不再附加整块人物的飞行轨迹，避免贴图跳跃与物理跳跃叠加。

新增素材来自 Meowa 的像素姿势编辑与像素关键帧动画。逐帧筛选后使用 80×80 PNG，没有缩放或重新像素化。原始动画的透明上、下边距被裁去；背向两帧上升姿势额外作 4 像素整数平移，去掉生成的整块上移。具体选择顺序与偏移见 `assets/meowa/player/sources.json`。

侧向重新以原待机首帧为参考，通过 Meowa 像素动画进阶模式生成 8 帧。用户最新确认允许轻微面部变化，先筛帧使用。最终选择原始第 0、2、3、7 帧（从 0 计数）；剔除头部转向或面部、身体比例变化更明显的第 1、4、5、6 帧。保留生成的原始面部像素，只裁透明边距并做整数位置对齐。

运行使用 `hop_00.png`、`hop_02.png`、`hop_03.png`、`hop_07.png`。起跳播放第 0→2→3 帧，12 FPS；下落播放第 3→2 帧，12 FPS；落地播放第 7 帧→原待机首帧，16 FPS。整块人物在生成动画中的上移已被对齐，实际飞行继续由物理控制。侧向起跳、下落、落地分别为 3、2、2 帧。

背向保留当前收腿、放腿与屈膝姿势。旧侧向 PNG、旧原始生成与局部眼部修正版均保留归档。新 Meowa 原始 WebP、GIF 和图集保存在 `assets/meowa/player/jump-source/side-new.*`；该目录不导入 Godot，运行只加载筛选后的 PNG。

## 验证

已检查左右镜像、背向起落、按住空格不连跳、修改跳高、关闭主动跳跃、高处直接下落，以及空中动作末帧保持。默认 0.8 米设置在物理测试中实测约 0.800 米，1.3 米设置实测约 1.301 米。当前地图的原生 Godot 检查中，三个方向均完成上升、下落、落地与恢复待机。

[当前地图预览](../media/player-jump-preview/jump.gif) 展示右向、左向和背向的完整起落；预览裁取游戏画面，未修改地图或相机配置。

台阶通行测试见 `demoWithMeowa/1/tests/test_player_steps.gd`：正式地图住宅台阶上下与训练地坪、斜向迈步、最大高度、低顶阻挡、开关、高台地阻挡和下落、原有跳跃共 15 项物理检查通过。此检查只确认人物通行行为，不作为其他地表材质或音频采样逻辑的验收。
