# Meowa 调用记录

阅读入口：[HD 2D Meowa 调用记录](https://chatgpt.com/space/page_a1d8b19baf7c8191913c59c3b647e390)。

自 2026-10-10 起，每次 Meowa 调用的请求和实际返回数据保存于此目录，并同步到上述页面。本次第一块环境制作记录 CALL001～CALL007，涵盖认证、参数说明、三次图片生成与一次本地组件裁切；所有记录保留实际输入与返回。

此目录独立放在项目根目录 `meowa-call-logs/`，与游戏源码和一般文档分开。

新任务按全局连续序号与中文任务名建目录，例如 `1-制作广场石板地表`。同一任务内保留每次真实调用的独立文件，例如 `CALL001-生成-request.json`、`CALL001-生成-result.json` 和对应输出与阅读记录。请求文件在调用前创建；调用后补齐响应与状态。旧的日期目录保留历史原始记录，不覆盖、不改写历史调用。

请求记录包括实际工具名称、调用目的、北京时间、原始参数、完整提示词及参考资源。结果记录包括实际返回内容、任务标识、状态、错误及产物路径。保留失败、重试和查询记录，并关联原任务。

提示词保持原文和换行，不以摘要替代。仅对密钥、令牌、认证头和签名链接中的敏感凭据脱敏，明确标注位置。
