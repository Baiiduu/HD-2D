# 石板广场与美术来源

当前阶段验证参考图中的基础石板铺装、用户指定的地表变化、光影与已确认的“宗门灯火与山谷层次”远景。场景为 16×17.6 米的平整广场、六个人物、三盏简单占位灯与三层 Meowa 山谷背景。近处建筑、台阶、摊位、桥梁、河流、外围可行走地形和粒子仍不接入。

## 宗门山谷远景

- 一张 Meowa 原生 1024×768 RGBA 图集包含三条横向背景：深色山壁、带少量暖灯宗门的青蓝山峰、低对比远山。通过 UV 分别取用，不裁切、重绘或改动图片字节；原图与运行副本的 SHA-256 相同。
- 三层分别位于距广场中心 60、110、200 米的环绕曲面上，以不同距离产生轻微移动视差，并覆盖横向旋转后的背景。每层按原画宽高比例重复 2、3、3 次，避免把宗门建筑横向拉长；各层透明山峰轮廓遮挡后层。背景是 2.5D 美术，不是可探索的山体或三维宗门模型。
- 远山底色、雾化沿用已有调节；低处逐渐融入当前雾色。图中的瀑布、树木和云雾为静态美术。远处暖灯参数调节原画暖色区域，不新增实际点光源。
- “天空与远景”新增高度、距离比例、亮度、远处宗门灯火四项，均支持单独恢复、保存与 JSON 导入导出。“远景构图”仅切换镜头到 FOV 34°、俯角 18°、横向 22°、距离 22 米；不自动保存，不改变地表或光影调节。
- 当前广场边缘仍是试验平台，尚未制作与山谷连接的崖壁、栏杆或外围地形。背景用于确认层次、颜色与灯火构图，这部分过渡另行讨论。
- 本轮 Meowa CLI 调用一次，成功，实际费用 7 credits；模型与种子未返回。完整输入、结果与 CLI 内部轮询输出保存在 `meowa-call-logs/3-制作宗门远景/`。实际预览见根目录 `docs/media/opening-environment-preview/plaza-vista.jpg`。

## 地表与显示

- 石板来自 Meowa CALL002 修正铺装，原图 64×64，不透明。原图覆盖 3.2×3.2 米，单块约 0.8×0.4 米，保持源像素，不缩放、不重绘文件。
- 基础材质为非金属，粗糙度 0.76。水迹是平面薄贴花，当前没有动态湿地反射或立体积水。
- 光影采用冷色全局方向光、上下半球环境光、三盏暖色点光源；人物与细杆投射真实阴影，人物保留接触阴影。全局阴影图为 2048，点光阴影图各 512；全局阴影范围覆盖广场，避免相机跟随时移动灯光方向。
- 默认启用轻距离雾、解析高度雾与基于场景深度的灯光体积散射，后者是近似单次散射，不是完整光线追踪体积模拟。少量泛光与冷暖染色辅助灯光；景深与暗角仍默认关闭。
- 占位灯只有 0.18×0.22×0.18 米小方块与细杆，放在广场的三处位置；没有灯具贴图或正式模型，未生成新美术。
- 面板新增全局光水平方向/俯角/阴影，以及占位灯颜色/强度/范围/阴影。占位灯强度同时影响实际光源、间接填充、灯体发光与空气散射；强度 0 可完全关闭光效。环境光、全局光和雾仍可逐项调优、恢复与导入导出。
- 新光影保存位置为 `lantern-festival.plaza-lighting.v1`。第一次进入时沿用旧纯广场配置中已保存的镜头与地表参数，使用新的光影默认值；旧配置不覆盖或删除。保存新配置后优先使用新配置。
- 保留人物移动、朝向镜头、NPC 碰撞、广场边界、视觉参数单项恢复、横向旋转、FPS 与平均帧间隔。
- 每块石板有固定的轻微明暗变化，默认线性颜色倍率 ±8%，与原图错缝结构对齐；相机移动或刷新不会重新随机。
- 裂纹、磨损、花瓣、水迹、青苔与污渍来自同一张 Meowa 透明贴花图集，原尺寸 1024×768。通过 UV 选择六格，不裁切、重绘或修改源文件像素。贴花平贴地面，青苔偏向广场边缘与接缝，不添加碰撞或三维物体。
- 默认覆盖数量分别为裂纹 41、磨损 45、花瓣 20、水迹 10、青苔 24、污渍 13 个小贴花簇；不是单片花瓣数。六类使用实例化绘制，每种使用一个网格。调整数量只显隐预先固定的实例，不重新随机位置。
- 调节面板的“石板与覆盖细节”可逐项调整明暗幅度及六类数量，数量 0 关闭对应类型、1 显示该类预设上限；支持单独恢复、保存与 JSON 导入导出。接缝与轻微倒角目前来自颜色纹理，尚无独立法线或高度贴图。
