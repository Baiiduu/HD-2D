# 树池建筑样板

整棵树由 Meowa 单物体像素生成并去背景，`tree.png` 为原生 128×128 RGBA，未重采样或再次像素化。花草、盆内 `../materials/compost.png` 和坐面 `../ricochet/wood.png` 沿用现有素材，不复用路面或地板。

花坛现用已确认的无灯城市造型：`city_panels.png` 为原生 512×512 Meowa 图集，正面、侧面与带检修盖的背面各有独立 UV；金属包角与坐面支架复用图集中金属区域。`city_cap.png` 为母图原生裁出的 64×64 浅灰压顶。颜色无损导入、最近邻采样，不重采样或再次像素化。参考图、输入布局和原始母图保存在忽略导入的 `source/`；`tools/build_tree_planter_maps.py` 可从母图重新裁切、排图并补齐 UV 外边距。

Godot「地图切换」选择「树池建筑预览」即可在当前正式世界的相机、光影和天气下查看；Q/E 旋转，R 切光影和天气。预览不写人物存档、不运行波次挑战。

将 `res://scenes/buildings/tree_planter.tscn` 从文件系统拖入 `world.tscn`，选择 **TreePlanter 根节点**整体移动、绕 Y 旋转或复制。原点是地面底部，+Z 是长椅正面；放在平整地面后可点击 Inspector「贴合地面」。移动根节点不重建地形或全图花草。参数修改只重建当前树池。

Inspector 可调花坛宽／深／高、树图及根部锚点、像素尺寸、树冠风摆、受光起伏、花草比例、长椅／路灯／碰撞开关和材质。默认树图每像素 0.025 米，64px 材质每块 1.6 米，约 40 像素／米。替换树图时按新图片的根部位置修改 `tree_anchor`。

`city_panel_texture` 选择城市槽体及其完整面板 UV，`cap_texture` 控制浅灰压顶，`wood_texture` 控制长椅。清空 `city_panel_texture` 可返回原石砌构造，原 `stone_texture` 保留；修改这些参数只重建当前实例，不改地图布局。城市槽体的碰撞按金属身体、石压顶和木坐面分区，身体与压顶合计仍覆盖原有完整阻挡体积；原有遮挡淡化与静态合批继续可用。

树冠、树干共用一张直立贴图，只随相机水平朝向转动；它不具有真实三维侧面。材质接收现有方向光、独立路灯和阴影，树冠轻微风摆跟随 Weather 的开关与强度。花坛场景默认关闭附灯，因此不生成附灯模型、光源、光晕或粒子；旧附灯开关保留兼容。正式地图的最终观感由 F5 人工验收。
