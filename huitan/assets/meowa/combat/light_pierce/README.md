# A02 雷光贯穿美术

当前 A02 使用 `pixel/` 中的原生小尺寸像素素材，由 Meowa 按已确认的雷刺参考重新制作：青白亮芯、蓝紫分叉、三段有留白的电光尾迹，以及紧凑的八帧命中电弧。静态素材使用自定义尺寸像素生成与像素去背景，动画使用 Pixel 帧动画；保留原生像素及透明度，没有重采样或再次像素化。

| 当前文件 | 原生尺寸 | 用途 |
| --- | --- | --- |
| `pixel/head.png` | 48×16 | 水平向右的细雷刺 |
| `pixel/trail.png` | 128×16 | 三段断续折线残影 |
| `pixel/impact.png` | 64×48 | 命中动画起始素材 |
| `pixel/impact_atlas.png` | 192×144 | Meowa 原图集，3×3 格，使用前八格 |
| `pixel/impact_frames.tres` | 每帧 64×48 | 非循环 `impact` 动画，保留八帧及最后透明帧 |

`pixel/source/` 保留原动画 WebP 和透明 GIF，使用 `.gdignore`。运行时直接采样原图集中的 AtlasTexture 区域，最近邻过滤，完整动画重定时为 0.28 秒。一级雷刺宽 0.8 米、尾迹长 2.1 米，长轴约 60 像素／米；三段尾迹从雷刺后缘开始，起手只裁切已走过的部分。雷刺长轴沿真实弹道，转镜头时自然透视缩短。技能图标也使用当前雷刺。

## 保留的早期素材

以下旧青金晶体素材仍由 A03 的短光丝与碰撞星芒使用。A03 的反馈场景为 `scenes/combat/prism_contact_effect.tscn`，与 A02 的像素资源分开。

| 文件 | 原生尺寸 | 用途 |
| --- | --- | --- |
| `head.png` | 512×304 | 水平向右的枪锋 |
| `trail.png` | 1024×256 | 细长光丝拖尾 |
| `impact.png` | 512×384 | 命中动画的起始素材 |
| `impact_atlas.png` | 2560×1008 | 八帧命中动画，4×2 排列 |
| `impact_frames.tres` | 每帧 640×504 | Godot 非循环 `impact` 动画 |

全部 PNG 保留真实 alpha。三个静态素材从 Meowa 的 1024×1024 素材页按原像素裁切；动画由原始 WebP 帧按原尺寸打包，没有重采样或本地去背景。它们是适配 HD-2D 场景的特效美术，通用生成不保证统一的小像素网格。

`source/` 保留 Meowa 原素材页、原动画 WebP/GIF 和原始动画图集；原动画为八帧、0.8 秒。A03 碰撞反馈按 `Impact Duration` 重定时为 0.32 秒。该目录使用 `.gdignore`，运行时读取 PNG 和 SpriteFrames。

实战已接入初始选择、经验学习与四级成长；本次更换外观，保留攻击数值和成长规则。查看方法、可调参数与战斗边界见 [雷光贯穿](../../../../docs/gameplay/light-pierce.md)。
