# 人物基础剑术厚月牙

当前已停用：正式基础剑术的 `frames` 留空，此处仅保留旧素材，不代表游戏中仍显示该剑光。

Meowa 制作暖白厚刃、绯红内层的像素月牙，动画经逐帧编辑移除实体剑并补齐碎屑消散。原生透明动画为 8 帧 224×224，源图及最终 WebP 保存在 `source/`，由 `.gdignore` 排除引擎导入。

`slash.png` 仅把原生帧原样打包为 896×448 RGBA 图集；`frames.tres` 全部保留，非循环、40 FPS。`blade_angles` 元数据将每帧美术厚刃对齐攻击方向，横扫时钟负责左右揭示，收尾淡出，不重采样或重新像素化。

基础 1.52 米半径与 95 原生像素对应 0.016 米／像素。刀光使用独立腰部斜面，地面投影、遮挡与伤害共用攻击范围。参数和机制见[人物基础剑术](../../../../docs/gameplay/player-sword.md)。
