# Godot HD 2D 视觉效果复刻教程

更新：2026-10-12。实现参照：`D:\Project\HD-2DMap\huitan`。

这套画面的基础是三维地形、二维像素人物和可旋转的透视相机。光照、材质、雾、水、天气与后处理共同形成最终表现。教程按这些效果的依赖关系拆成 18 个阶段，每阶段都给出可以交给 AI 开发助手的提示词、当前项目参数和画面对照方法。素材部分另附 Meowa 提示词。

下面的提示词用于在一个独立教学场景中从零实现效果。它们不要求复制原项目的地图布局，也不代表正式地图接下来必须加入水域、花草或灯具。观众使用不同素材时可以复刻同类效果；要获得与原项目接近的画面，还需要匹配素材、物体尺度、布局和有效参数。

## 先讲清五种容易混淆的光

| 名称 | 小白可以观察到什么 | 主要调节什么 |
| --- | --- | --- |
| 真实灯光 | 地面和人物被照亮，遮挡物形成阴影 | 颜色、能量、范围、方向、阴影 |
| 材质自发光 Emission | 灯芯或霓虹自身很亮 | 自发光颜色、能量；本项目用独立灯照亮周围 |
| 泛光 Glow | 已经很亮的像素向外扩散成柔光 | 环境 Glow 强度、层级、Bloom 等 |
| 光晕 Halo | 灯周围专门画出的柔和圆形亮雾 | 光晕尺寸、透明度、亮度、边缘渐隐 |
| 雾中散射与光束 | 光穿过空气，在空间中显出亮度和层次 | 雾密度、灯的散射能量、纹理、光束强调 |

本项目 `ArtDirection` 中名为 `bloom` 的参数写入的是 **`Environment.glow_intensity`**，当前值 **0.18**；Environment 自己的 **`glow_bloom` 是 0.04**。录教程或抄参数时，应把这两个名字说明白。不能把“bloom 0.18”直接填到环境资源的 Bloom 字段中就认为完成匹配。

SSAO 是屏幕空间遮蔽，用来加强凹处和接触处的暗部；SSIL 是屏幕空间间接光；SSR 是屏幕空间反射。它们依赖可见画面信息。水面另有一套平面镜像渲染，因此人物倒影不能只靠打开 SSR 来保证。[Godot 环境与后处理说明](https://docs.godotengine.org/en/stable/tutorials/3d/environment_and_post_processing.html)

## 从零复刻的使用方法

观众先创建 Godot 4 的 **3D / Forward+** 工程，再把下面的“总提示词”发给开发助手。原项目使用 Godot 4.7.2、Windows D3D12、Forward+；其他可用图形后端也可以学习同类效果，具体画面以实机为准。完整路线使用 Forward+，因为体积雾要求这个渲染器。[Godot 体积雾说明](https://docs.godotengine.org/en/stable/tutorials/3d/volumetric_fog.html)

一次发送一个阶段，运行看到结果后再继续。每阶段的参数是本项目的参考基准，部分数字作用在自定义脚本或 Shader 中；助手如果采用不同算法，需要保留同等可调范围并说明映射，不能声称相同数字必然得到相同画面。

“节点”是场景里的对象；“检查器”是选中节点后右侧的参数面板；“Shader”是控制材质或屏幕像素如何显示的小程序。“导出参数”表示参数出现在检查器里，观众可以拖动调整。

### 总提示词

```text
我要用 Godot 从零制作一套 HD-2D 环境效果，用于教学。基础是三维地形、二维像素人物、冷色环境与少量暖色局部光。请先按我随后发送的阶段逐项实现。

请使用独立的教学场景，每个阶段只完成该阶段的内容。优先采用 Godot 自带节点与效果，确有需要再写脚本和 Shader。关键视觉参数都要在检查器中可编辑，按功能分组，用中文注释解释意义、单位和调大后的变化，并提供各组恢复本节基准值的方式。

每节完成后说明：新增了哪些文件和节点，我应点击哪里调节，运行应看到什么，以及怎样用同一镜头做关闭/开启对照。检查场景加载和实际渲染结果。观察或截图前核对运行中的有效相机设置，不要只读取场景里保存的 Transform。

共用相机基准：透视，FOV 30°，距离焦点 11 米，俯角 10°，初始水平朝向 0°，焦点高于人物原点 0.75 米，跟随平滑度 6，死区 0.1 米。Q/E 可持续旋转任意圈数，最高速度 90°/秒，加速度 90°/秒²，松手收尾基准 0.75 秒，15°吸附，每圈可回到初始朝向。逻辑视口 1440×900，窗口 1280×800，保持 16:10。

景深基准：启用深度景深，强度 0.02，焦点前后清晰余量各 2.5 米，近处过渡 1.5 米，远处过渡 4 米。只有讲解景深的对照时才专门改变景深。比较其他效果时，人物位置、镜头、分辨率、景深和无关参数保持一致。

需要美术或音频时使用 Meowa；先阅读当前 game-assets skill，确定资源尺寸、透明背景、数量和基准参考。模板能力先展示适用模板；已有确定选择时继续使用。检查输出尺寸、透明边缘、接缝和游戏尺度表现。素材生成与 Godot 实时效果分开讲，不用生成图片代替运行中的灯光、雾、雨、折射或景深。
```

## 阶段 1 基础场景与统一相机

本节结果：可以在三维地面走动的占位角色，镜头尺度和操作固定。先用灰色地面、一个高低台阶和简单遮挡块判断体积。它们是教学验证对象，正式地图布局独立处理。

```text
先完成基础教学场景：Node3D 根节点、简单三维地面与碰撞、一个可走坡道连接的高低台地、CharacterBody3D 占位人物、Camera3D、一套真实环境和方向光。

按总提示词配置相机和窗口。WASD 根据相机的水平朝向移动；Q/E 加速绕焦点连续旋转，松手平滑停到吸附角度；人物在小死区内移动时相机保持稳定。相机按地面边界约束焦点，并提供回正按钮。相机开始运行时立刻定位到人物，避免第一帧从保存位置跳过去。

采用米为尺度，后续地形每格 1.6 米，每层高度 0.8 米。检查器暴露距离、俯角、FOV、焦点高度、平滑、死区、边界和旋转参数。添加 CameraAttributesPractical，按总提示词配置深度景深。用实际场景里的环境和灯验证编辑器与运行效果。
```

验收与拍摄：走动、上下坡、按住 Q/E 转过一整圈再松手；人物大小稳定，移动方向跟随镜头。做静态对照前回到初始水平朝向。编辑器默认预览灯不能代替场景里的真实灯。

## 阶段 2 像素人物与环境受光

本节结果：像素人物站在三维地表，进入灯下会受到同一场景照明。先用一张稳定站姿完成显示与受光，再加动画。

```text
把占位人物替换成已确认的透明像素站姿。用 Sprite3D 作为视觉子节点，人物碰撞与贴图分别管理。采用最近邻采样和适合像素轮廓的 alpha scissor，让人物水平朝向相机且保持竖直，脚底锚点稳定。

保留原素材像素网格，用世界尺寸调显示大小；如果采用本项目的 80×80 画布，可从 pixel_size 0.0234375 米/像素开始，按实际非透明范围核对人物身高。不要把透明画布高度当作真实身高。

实现可开关的人物受光材质，接收场景光与阴影，柔和侧光 0.3、顶部受光 0.4、背光亮边 0.12 作为起点。同步贴图、颜色和左右镜像，关闭受光时能展示原始图像。转镜头时检查轮廓、脚底、阴影和背光，保持脸部可读。

增加建筑遮挡轮廓：按当前动画帧的 alpha 边缘描线，用场景深度逐像素判断遮挡，只显示被挡部分，露出的身体保持正常。默认暖黄色、1 个原图像素粗细、不透明度 0.85、深度容差 0.03 米；参数可编辑。辅助轮廓不投影、不写深度、不进入水面倒影，分别验证无遮挡、完全与局部遮挡。

以上轮廓为保留的教学原型。当前正式 World 关闭人物与波次怪物穿墙轮廓，使用 `BuildingOcclusion` 只检测玩家与相机之间的房屋分段盒，并渐变实例透明度；怪物不触发淡化。菜单与入场演出期间建筑完整显示，Q/E 后按新机位重新判断，离开后延迟恢复。

站姿通过后接入侧向与背向 idle/run，左向复用侧向镜像；随后按已确认素材接入 jump/fall/land。先看参考视图的脸型、头身比、肩宽、腿长，再看每帧在游戏尺度下的连续性。允许轻微动作差异，筛掉明显变脸、眼白突变、肢体错位和异常轮廓帧。物理跳跃驱动整个人物的高度，动画只提供局部姿势，避免双重位移。展示筛选后的实际帧数。
```

验收与拍摄：同一盏灯下开关人物受光，走进与走出灯光；原图用最近邻整数倍查看，再在基准镜头下看人物。透视投影、非整数屏幕占比、灯光、色彩和景深都会改变屏幕观感，不能把每种差异都归因于原图被改坏。

## 阶段 3 全局光 阴影与接触层次

本节结果：暗部仍有可读细节，物体有落地感；先弄清真实照明，再做发亮效果。

```text
建立全局光影调节节点 ArtDirection，连接唯一的 WorldEnvironment 与 DirectionalLight3D。导出环境光颜色/能量、主光颜色/能量/方位/仰角、阴影开关和柔化参数。

参考基准：环境光颜色 RGB(0.50,0.52,0.60)，能量 0.6；主光颜色 RGB(0.82,0.87,1.0)，能量 0.7，方位 -32°，仰角 48°，角度柔化 1.5°。在脚本中说明方位与朝向的约定，用实际阴影判断方向。

逐项接入 SSAO 和 SSIL，并提供独立开关。参考 SSAO 强度 2.2、power 1.6、detail 0.7、light affect 0.15；SSIL 强度 1.6。用台阶接缝、墙脚与人物落地位置做对照，避免把遮蔽加到全画面发黑。开启合适的三维抗锯齿与阴影质量；最近邻采样仍由像素材质控制。
```

验收与拍摄：依次关闭/开启主光、真实阴影、SSAO、SSIL。说明 SSAO 的接触暗部与 Light3D 的投影阴影分别来自哪里。

## 阶段 4 色彩 自发光 泛光与暗角

本节结果：冷色暗部、暖色亮部与柔和发光点形成统一画面。

```text
在已有真实光照上建立色彩与发光调节，不改变相机。环境采用 ACES 色调映射，曝光 0.86、White 6.0，亮度 1.06、对比度 1.2、饱和度 1.45，全部可单项恢复。

增加少量自发光测试片，分别演示灯芯、暖窗和冷色霓虹；旁边保留由真实灯照亮的地面。接入 Environment Glow：glow_intensity 0.18，glow_strength 1.05，glow_bloom 0.04，层级 2/3/5 的权重分别 0.6/0.8/0.6。自定义面板把 Glow 强度与 Bloom 明确分开，避免同名参数填错。

建立一个可复用的屏幕后处理材质，用轻微分离色调和暗角统一画面。暗部 tint RGB(0.86,0.94,1.12)，亮部 tint RGB(1.08,1.0,0.90)，分离色调强度 0.25；暗角强度 0.3、半径 0.85。ColorRect 铺满窗口并忽略鼠标输入，后续 HUD 放在它上方。

发光源、真实灯和 Glow 各有开关。亮处保留颜色与轮廓，地面、人物脸部和屏幕中心保持可读。为后续水滴预留屏幕采样接口。
```

验收与拍摄：关闭 Glow 时灯芯仍亮、真实灯仍照地；只关闭真实灯时发光片仍亮。再开关分离色调与暗角。当前资源的 `tonemap_mode=3` 对应 ACES。[Godot Environment 枚举](https://docs.godotengine.org/en/stable/classes/class_environment.html)

## 阶段 5 像素天空 远山与雾层

本节结果：背景有远近层次，近处仍清楚，地表与天空的雾色衔接。

```text
为 WorldEnvironment 创建程序化像素风 Sky Shader。包含天顶到地平线渐变、稀疏星点、与主光方向一致的月晕、少量暖色地平线辉光、一层远山和四排高低错落的松林剪影。远层小、亮、接近雾色；近层大、暗，树脚逐渐融进雾里。按视线角度量化图案，像素角步长 0.004 弧度。静态天空不依赖 TIME，避免持续重算天空反射。

参考颜色：天顶(0.05,0.05,0.11)，地平线/雾(0.38,0.35,0.40)，剪影(0.10,0.09,0.13)，暖辉光(0.75,0.42,0.24)、强度 0.5，月晕(0.55,0.62,0.85)，星密度 0.01。

分别暴露距离雾、低处雾和体积雾，说明它们的不同作用。参考距离起止 21.5/99 米、强度默认 0，低处雾 0.06；体积雾密度 0.006、albedo(0.75,0.85,0.92)、基础计算长度 40 米、环境光注入 0.2。不要因距离雾当前为 0 而删掉它的可调入口。
```

验收与拍摄：雾分别开关，比较远处剪影和近处人物；不要让雾把所有物体盖成相同颜色。本项目的山与松林是天空图案，不能当作可走地形。

## 阶段 6 空气散射与局部灯光

本节结果：灯的地面照明、灯芯、光晕、雾中散射和颗粒能单独解释，也能组合展示。

```text
先制作一盏可复用的教学灯，灯体用小方块与细杆。建立真实聚光、少量全向补光、可投影阴影、发光灯芯、边缘渐隐的圆形光晕、局部 FogVolume 与少量柔和微尘。光晕与微尘不能露出矩形面片边缘。光束强调使用独立调节，并检查人物和遮挡块经过灯下时的阴影。

路灯参考：暖色(1.0,0.84,0.60)，聚光能量 3.6、角度 40°、边缘衰减 0.9、倾斜 -10°，补光能量 0.45、范围 4.4 米，specular 0.85，阴影 opacity 1、light size 0.12。灯芯 emission 1.6；光晕强度 0.9、直径 1.6 米；微尘 28 个、尺寸 0.028 米、能量 0.65。逐项调节，不把整套灯效果绑到一个总亮度上。

再增加独立 AtmosphericLight：暖色(1.0,0.83,0.55)，散射 12、局部薄雾密度 0.014、上层空气增益 1.8、背景散射 1、光晕 0.3；远景距离 28 米、高度 22 米、宽度 7 米、光束定义 0.07，体积雾计算长度可扩展到 80 米。地表补光方位 -24°、仰角 38°、能量 2.2，纹理打散强度 0.7。图层和光照遮罩要避免光束被重复照亮或错误进入水面倒影。

所有参数分为“真实照明”“灯芯光晕”“局部雾”“微尘”“远景空气光”，可分别关闭和恢复。环境灯的不同预设允许有独立参数。
```

验收与拍摄：无雾→有雾，阴影开关，人物经过灯下，微尘开关，空气光开关。光束、辉光与地面亮斑的相对位置应一致。路灯数字是现有一种基准，桥边环境灯等预设不必强行用相同值。

## 阶段 7 地表纹理 衔接与湿润材质

本节结果：纹理随世界位置稳定，地形接缝合理，石材与草地湿润后的反应不同。

```text
为教学地形接入已确认的像素基础纹理。使用世界对齐 UV，64×64 纹理对应 1.6 米地形格，保持最近邻采样；顶面、崖壁、道路和坡道侧面按同一尺度衔接。

需要自动道路/泥土边缘时，使用经过接缝检查的 4×4 dual-grid 过渡图集，通过相邻四角计算对应瓦片，并叠到区域底材。处理透明覆盖层、草地崖边过渡、苔色与接缝暗部，提供独立强度和开关。不要把普通素材拼图当作可用过渡图集。

加入可调石材受光起伏与不规则亮面：stone relief 0.006、gloss variation 0.55。它是材质上的微小受光变化，不改变碰撞体。加入基础 wetness 0.6、wet darkening 0.65、wet roughness 0.16。草地使用较弱湿润响应 0.2，并保留大部分哑光。

提供默认关闭的稀疏不规则积水，数量参数 0.4、颜色变暗系数 0.45、粗糙度 0.02，明确数量如何映射到噪声阈值。支持无纹理灰盒材质的受光、湿润与后续雨水响应，方便尚未选定地表素材时调试。
```

验收与拍摄：干燥→湿润，同一灯位观察光泽；近看道路边缘与坡道顶侧面。积水独立开关。微起伏不等于增加了真实石板高度，程序化积水也不等于流体模拟。

## 阶段 8 地编区域 随机铺设与编辑器预览

本节结果：选资源、画范围、调密度即可批量布置花草，位置可复现，分布没有明显行列。

```text
用已确认的透明草、花、小石子资源制作 GroundDressing。每类支持多变种勾选，密度按每平方米实例数量计算，范围至少 0～10；小石子默认不铺，保留可选入口。

添加可移动、缩放、复制的矩形 GroundDressingRegion。每个区域有启用开关、可铺类别、密度乘数 0～5，并能按地形类别过滤。采样点落到实际地表高度，排除不适合的位置。

采用有最小间距的随机撒点，叠加轻微尺寸、朝向和资源变种差异；不要按网格等距离摆放。最小间距从 0.28 米开始，固定种子 10102026。用分块 MultiMesh 批量绘制，并让区域边界与分布在 Godot 编辑器未运行时可见。参数更改后更新预览，有手动刷新按钮与空资源处理。

暴露密度、种子、间距、变种列表与区域乘数。固定种子和同样配置得到同样结果，编辑器预览与运行一致。说明高密度受最小间距和区域面积限制。
```

验收与拍摄：移动区域、取消一个花变种、把密度从 0.3 调到 1.5，再换种子。观众应看到范围和稀密改变，草根落地，水和道路等过滤区不被误铺。

## 阶段 9 花草受光 稳定草影与风摆

本节结果：花草融入地面，光影与根部稳定，风使上端轻微摆动。

```text
为已铺花草制作可受光的细分面片材质。保持像素透明轮廓和根部锚点，上端可变形；不同实例风摆相位不同，避免所有花草同一时间向同一侧倒。

增加柔和法线受光、根部遮蔽、背光叶尖：normal strength 0.35、root occlusion 0.3、backlight 0.12。将根部遮蔽信息写入与地形对齐的轻量遮蔽贴图，让地面也有相应接触暗部。显示面片跟随镜头时，投影使用稳定朝向，避免 Q/E 旋转导致草影不断转动。

增加统一风参数接口，供后续 Weather 控制。参考风向 XZ(1,0.25)、强度 1.65、速度 1.6、阵风 0.3、草摆幅 0.055、花摆幅 0.035；说明自定义摆幅单位和物体尺度。根部固定，草花上端摆动。

铺设重建后刷新风材质与根部遮蔽连接，关闭风时恢复静止。检查器暴露受光、稳定草影、根遮蔽、风向、风强、速度和各类摆幅。
```

验收与拍摄：风关→开，转镜头检查影子，开关根部遮蔽。微风不应把花草吹成摆钟，也不应让整片草地像镜面水。

## 阶段 10 水面流动 高光与泡沫

本节结果：一块有岸边的平面水域呈现流动、颜色变化、受光和泡沫。先做好水材质，再加倒影。

```text
在教学场景增加一小块平面水域与岸边，水面先不做镜像倒影。水材质包含相位混合的流动纹理、浅深水颜色、微小波纹法线、真实灯光高光、细碎反光和岸边/接触泡沫。

参考浅水 RGB(0.26,0.46,0.50)、深水(0.10,0.25,0.30)、opacity 0.86、流速 XZ(0,0.12)、波纹强度 0.08、highlight roughness 0.22、glint 0.8。高光粗糙度控制自定义水面高光的宽窄，原项目材质 ROUGHNESS 则由清水 0.12 向泡沫 0.75 混合，分别保留含义。泡沫颜色(0.78,0.85,0.85)、密度 0.55、漂移 0.08、岸边宽 0.14 米、强度 0.8。

灯光在平均水面方向形成较宽光斑，在细小波纹上形成窄亮点；响应灯的距离、方向、阴影和颜色。采用真实光照计算，不用固定发光色冒充所有高光。泡沫沿岸边和接触区域变化，不出现整齐的白色边框。

检查器分组暴露颜色、透明度、流速、波纹、宽高光、细碎亮点与泡沫。为雨纹和镜像纹理预留接口。
```

验收与拍摄：关闭波纹与高光后逐个开启，移动或关闭灯光观察水面亮斑；检查水与岸边的深度、透明排序及接触泡沫。

## 阶段 11 屏幕空间反射与平面倒影

本节结果：水中出现正确的场景与人物倒影，镜头旋转时位置稳定。

```text
先为湿地面接入可独立开关的 Environment SSR：max steps 96、fade in 0.1、fade out 2.5、depth tolerance 0.4。说明 SSR 依赖主镜头可见的深度和颜色，不能保证所有透明像素物体都有倒影。

为水面另实现 WaterReflection：按水位分组，使用 SubViewport 与关于水平水面镜像的相机，得到投影匹配的反射纹理；水面法线扰动倒影。先支持一个水位，确认后再支持最多两个水位。参考反射强度 0.85、分辨率比例 0.5、波纹扰动 0.08；0.5 指宽和高各减半。

人物倒影同步动画纹理、翻转、颜色、实际世界变换和受光参数。裁剪低于水面的静态几何，排除水面自身、镜像代理和光束特效，避免递归与重复渲染。镜像内部保持合适的 HDR 线性数据，避免曝光、调色和泛光重复处理。

只更新当前镜头能看到的水位，窗口尺寸改变后更新反射纹理。提供重新构建入口，并说明静态几何与动态对象各支持什么。保留反射开关与参数，在同一镜头下分别展示 SSR 与平面反射。
```

验收与拍摄：人物在水边移动、跳跃、左右镜像，水里同步；Q/E 转镜头后倒影不漂移。当前项目支持最多两个水位，主要反射静态网格和动态 Sprite3D；MultiMesh 花草、粒子与光束未统一纳入。静态反射几何启动时构建，复杂运行时地形改动需要相应重建。教学版若实现了更广支持，应单独展示验证。

## 阶段 12 瀑布 水花与局部薄雾

本节结果：高低水面之间出现水帘和落水层次，参数之间的作用能看清。

```text
在教学水域做一个小高低差瀑布。使用有弯曲的水帘网格和透明材质，包含向下移动的流束、流束疏密、底部泡沫、零散水花与局部 FogVolume。

参考流速 2.2、弯曲 0.18、opacity 0.72、stream contrast 0.9、foam strength 0.85、foam length 0.65、splash strength 0.65、mist density 0.18。水花尺寸 0.055、密度 0.6；沿用水面泡沫配色，按实现说明各参数单位。

流束、泡沫、水花与雾可分别关闭。落水区与水面位置一致，表现可以程序化，不要求每一滴具有真实流体碰撞。镜像中排除容易重复叠加的雾和强调光束。
```

验收与拍摄：静态水帘→流动→泡沫→水花→薄雾，调流速观察变化。雾应集中在落水附近。

## 阶段 13 细雨雨幕与统一天气

本节结果：连绵细雨覆盖镜头附近，可切晴雨，雨的透明度和方向适合游戏画面。

```text
创建 Weather 节点，模式先只包含晴天和细雨。在镜头附近生成 GPUParticles3D 雨幕，雨丝使用窄长、透明、边缘渐隐的材质，受统一风向影响，降雨区域随镜头覆盖当前可见场地。

采用本项目参考：雨强 0.7、粒子预算 4800、速度 8 米/秒、雨丝尺寸(0.008,0.26)米、颜色 RGBA(0.65,0.76,0.84,0.24)、覆盖区域 24×20 米、高度 9 米、种子 10102026。雨强影响有效降雨量，不只是总开关。核对实际算法下预算与可见疏密的关系。

风参数接管前一节的花草材质，雨天风增强参考 0.25，切晴天后回到基础风。铺设花草或更换相机后刷新引用。雨粒子不投影阴影，不产生整片发白的遮罩。

天气、风和雨幕提供编辑器预览开关、实时参数与恢复按钮。镜头水滴和音频留到后续阶段接入。
```

验收与拍摄：晴→雨，调透明度、雨量、风向各一次；人物移动和旋转镜头后雨幕仍覆盖视野，没有显眼的降雨盒边界。4800 是当前粒子预算，画面并非同时看到 4800 条实心雨线。

## 阶段 14 地表溅水 水面雨纹与湿润变化

本节结果：雨落在地表和水上有不同响应；雨停后表面慢慢恢复。

```text
把 Weather 的雨强、时间和湿润状态送到地面、水和花草材质。地表出现稀疏短暂溅水，水面出现由点扩散、逐渐消失的雨纹；用世界坐标随机事件避免图案贴着镜头或形成规则循环。

参考地表密度 0.9、半径 0.11、强度 0.32；水面雨纹密度 1.8、半径 0.28、强度 0.35、生命周期 0.8 秒。地面和水面分别有开关。参数中的密度、强度按自定义 Shader 说明。

基础 wetness 保留材质原值，天气额外 wetness 参考 0.12，按雨强渐进累积，湿润时间 8 秒、干燥时间 25 秒。停雨逐渐消退，不能立即把原有湿地面重置成完全干燥。草地仍保持较弱湿润反光。

如果当前教学场景没有水或花草，对应连接可以为空，地面与天气照常工作。暴露状态与调节入口，展示是否真正绑定到当前材质。
```

验收与拍摄：同时拍石材、草和水，切晴雨并等待湿润变化；看雨停后是否渐退。本项目用材质事件表现雨纹与溅水，未实现每粒雨与所有物体的三维碰撞。

## 阶段 15 镜头水滴 不规则折射与轻微模糊

本节结果：少量水滴出现、滑落和消失，透过水滴看到局部图像弯曲，主体操作区域保持清楚。

```text
在现有全屏后处理加入镜头水滴。脚本管理随机出现、生命周期、淡入淡出和缓慢下滑；Shader 使用屏幕纹理制作局部折射、轻微模糊、边缘高光与背景亮度响应。水滴有不同尺寸、纵横比、旋转和边缘扰动，不能全是规整圆形或相同椭圆。

参考参数：生成率 1 个/秒并乘雨强，数量上限 8，半径 18～34 像素，生命周期 3.8 秒，渐隐 1 秒，下滑速度参数 6；blur 1、refraction 9、irregularity 0.7、light response 0.55、rim 0.18、中心保护半径 0.14。水滴半径、折射和下滑按本项目以 900 像素高画面为基准的约定换算，中心保护按画面高度比例；区分半径、直径、基准像素和归一化 UV，并说明窗口缩放后的对应关系。

从背景细节和灯光中取样，让亮处穿过水滴时出现局部高光与位置弯曲；这属于屏幕图像的视觉响应，不改变场景灯本身。减少人物与交互区域的遮挡，HUD 放在后处理上方。切回晴天后停止生成，让存量水滴自然退场；关闭总开关可立即清除。长时间运行不无限累积。

水滴在运行时验证。录制包含细纹理与暖灯的背景，分别开关折射、模糊、边缘响应，让观众看清每层作用。
```

验收与拍摄：录至少一轮出现→滑落→消失；用灯或地表边线观察折射。当前效果是屏幕空间模拟，不能介绍成真实光学光线追踪，也不直接改变真实阴影。

## 阶段 16 景深替代模式 萤火虫与日照演示

这节有三个相互独立的补充效果，可以拆成三个短视频。基础相机的深度景深保持原基准，只在本节专门做模式对照。

```text
先补齐景深演示：深度景深按人物焦点前后距离虚化，使用基准强度 0.02、清晰余量各 2.5 米、近过渡 1.5 米、远过渡 4 米。另做互斥的椭圆虚化模式，清晰区中心跟随人物屏幕位置，半径按画面宽高各 0.25、过渡 0.9、偏移 0；屏幕边缘逐渐虚化。解释椭圆模式按屏幕位置分配模糊，无法等同真实深度景深。恢复按钮回到深度模式。

接着制作可放置的柔和萤火虫粒子：小亮核加径向渐隐光晕，颜色(0.75,1.0,0.45)，面片尺寸 0.045 米、大小变化 0.3、energy 2.6、softness 0.7、pulse strength 0.55、pulse speed 0.35 Hz。随机相位和缓慢运动，不能露出矩形边缘。它的光晕不自动等于照亮附近地面。

最后添加默认关闭的 DaylightPreview，暴露进度滑条和播放开关。参考一段运行时间 20 秒、方位 -65°～65°、低仰角 20°、最高仰角 38°，暖日光到较中性光色渐变、能量 1.5。可选移动云影覆盖 0.45、尺度 9 米、速度 XZ(0.12,0.05)。云影影响真实场景照明，关闭演示后恢复原来主光、环境和天空参数。

可增加“原始、月夜逆光、黄昏逆光”光照情绪预设，成组保存主光、环境、雾与天空参数。当前日照模块作为视觉演示，不扩展成完整游戏时间或季节系统。
```

验收与拍摄：深度→椭圆→恢复；萤火虫柔化开关；日照拖进度看影长，再关闭看基准恢复。不要为展示这些效果另换更高俯角或不同 FOV。

## 阶段 17 Meowa 氛围音频与混合

本节是声音补充，独立于视觉系统。先试听和选择，再接入游戏。

```text
使用已确认的 Meowa BGM、轻柔雨声与轻风声接入环境。BGM 听感为空灵探索，柔和钢琴、轻电子、少量东方音色；雨声绵延轻柔、细碎但不密集、不压过主体；风声轻微，没有强阵风或尖锐呼啸。

BGM 参考 -18 dB、淡入 3 秒、循环交叉淡化 6 秒，用两个 AudioStreamPlayer 平滑交接。雨声参考 -10 dB、淡入淡出 3 秒，并随雨强变化；风声参考 -5 dB、淡入淡出 3 秒，并随风强变化。根据实际音源响度试听微调，不能只凭 dB 数字判断哪种声音更大。

为每项提供音源、总开关、音量、音频总线和过渡时间。先分别播放，再混合；检查循环衔接和天气切换。匹配当前项目默认状态时：BGM 开、风声开、雨声关；教学可单独开启雨声演示。
```

验收与拍摄：BGM 单独→加风→加雨；切晴雨听渐变。生成时提出可循环意图，下载后仍要反复试听首尾；交叉淡化用于降低接缝感，不能替代素材审核。

## 阶段 18 打包 MapEffects 与教学录制

本节结果：观众能给第二张独立地图接入相同效果，理解默认值和逐地图覆盖。

```text
把已经验证的通用效果组织为一个自定义 MapEffects 子场景：ArtDirection、WorldEnvironment、主光、AtmosphericLight、DaylightPreview、相机、PostProcess、Weather、BGM、WaterReflection。它是项目自己的可复用场景，不是 Godot 内置插件。

地图独立保留地形、人物、花草、灯具和布局。MapEffects 用显式引用连接 Terrain/SurfaceSource、Player、GroundDressing 和 Camera3D；提供手动连接与刷新入口。地图已有相机时复用它并关闭内置备用相机，且仍连接通用后处理；“采用教程相机基准”默认开，可显式关闭。地形或水域重建、花草重铺后刷新对应连接。

每张活动地图只保留一套主环境、一台主视角相机、一套天气和 BGM；水面镜像相机是反射系统内部的辅助视角。把环境、天空、后处理与需要独立调节的材质设为场景本地资源，验证改一张地图不会串改另一张。

给另一张独立灰盒地图实例化 MapEffects，保留其独立地形数据和布局。解释共享场景默认值与地图局部覆盖：修改一个预览场景的单独参数不会自动改其他地图；修改共享默认值会影响未覆盖的实例。

整理教程参数清单和各模块的启用状态。每个效果录“关闭→开启→调一个参数→恢复”，采用基准相机与同一人物位置，报告实际渲染验证与明显性能开销。默认关闭日照演示、积水和雨声，开启基准深度景深、细雨、BGM、风声与已有环境效果。
```

验收与拍摄：两张独立地图使用同一默认效果，调整其中一张，再检查另一张。没有水域时反射不启动，没有花草时风摆连接为空，环境、雨幕、后处理和声音仍能运行。新的共享场景不应自动带入旧地图的建筑和地形布局。

## 给 Meowa 的素材提示词

这些文字只描述素材。尺寸、数量、透明度、模板和输出形式还应在所选 Meowa 功能中设置，并检查实际结果。专用像素工作流的输出不再做二次像素化。通用生成得到的像素风图片需要额外检查网格和尺寸，不能凭提示词承诺精确规格。

### 人物参考与动画

已有角色时以确认过的原站姿和背向视图作为输入，先核对视图，不要仅为了凑多方向而采用明显不同的脸型和比例。本项目曾遇到不同方向头脸比例变化、动画眼白和面部偏移；筛帧改善了一部分连续性，但不表示模型已经完全解决一致性。

空工程还没有人物时，先制作并选定一张静态站姿，再进入动作章节。下面是接近当前角色元素的起点；新生成的角色不会自动成为与原人物完全相同的资产。小尺寸动画人物优先采用实际支持的 128×128 以内画布，本项目接入尺寸为 80×80；需要动作留白时在提交前核对画布与内容范围。

```text
一位黑色短发、戴深色耳机的像素少年，穿黄色连帽衫、深色长裤和红白运动鞋，全身自然站立，略侧向，适合三维地形上的二维像素游戏角色。轮廓清楚，透明背景，脚底位置稳定。
```

```text
以这张已确认的像素站姿为人物基准，制作同一角色的侧向跑步。保持头脸轮廓、发型、衣服和头身比可辨认一致，动作自然，适合循环。透明背景，脚底锚点稳定。
```

```text
以这张已确认的侧向站姿为基准，制作短促的起跳、空中收腿和落地姿势。面部表情保持平稳，动作变化主要在身体和四肢，适合游戏中的物理跳跃。
```

如果当前任务优先使用帧动画 V2，开发助手应明确选择该公开功能，并先读取其当前输入契约。转身、多方向图、帧动画和关键帧动画各有用途，不能用“高级档”笼统代替功能名。参考图直接生成动画可以先做小样；如果需要先准备关键姿势，静态姿势必须先做游戏尺度审核，再送入动画。不要因为头发颜色和衣服一样就认定人物一致，也不用逐像素相同作为自然动作唯一标准。

### 地表基础材质

教学素材合同建议：不透明、可重复平铺的 64×64 像素纹理；先选正式参考库或专用纹理功能。需要过渡时再制作匹配的 dual-grid 图集；当前平面 dual-grid 输出契约是 256×256、4×4、每格 64 像素。

```text
冷灰色石板地表，石板大小有轻微差异，接缝清楚，少量磨损，适合我们的像素人物与三维地形。以材质本身为主，保持四边连续平铺。
```

```text
低矮自然草地地表，柔和的冷绿色块面，明暗不过强，与冷灰石板搭配。保持四边连续平铺。
```

验收：把最终基础纹理至少重复成 3×3 检查边界；过渡图集用绘制/擦除测试检查直边、内外角和孤立块。地表纹理不预烘焙强灯光和长投影，以便实时照明发挥作用。

### 草 花与小石子

教学素材合同建议：独立透明 PNG、统一像素密度与根部锚点，每类六个可选变种；现有花草使用 48×48 单元。先选匹配的模板或实际支持的尺寸合同，批量输出的数量以功能契约为准。整张素材表需要先检查、再拆分，不能声称已经分成独立文件。

```text
适合这张参考画面的低矮像素草丛，做六个不同形态：疏草、密草、细长叶、羽叶、阔叶和少量枯草。高度接近，颜色克制，根部落在相同位置，透明背景。
```

```text
适合这张参考画面的低矮像素野花，做六个不同变种：白色、粉色、淡紫、黄色、蓝色和少量红色。花朵小，茎叶轻巧，与草丛像素密度一致，根部位置统一，透明背景。
```

```text
适合这张参考画面的微小灰色碎石，做六个不同组合，包含扁石、圆石、棱角石和两三颗的组合。体积很小，保持地面细节尺度，透明背景。
```

这些都是候选教学资源；小石子在当前铺设要求下暂不放入地图。花草与人物需要透明底，重复地表需要完整不透明底，两者不能使用同一背景处理方式。

### BGM 雨声与风声

```text
空灵而温柔的游戏探索音乐，柔和钢琴、轻电子氛围，点缀少量东方音色。旋律留白，节奏舒缓，适合长时间在夜色和细雨中探索，便于循环。
```

```text
轻柔绵延的细雨环境声，细小雨点疏密自然，平稳柔和，放在游戏声音的背景。近处水滴不突出，首尾便于循环。
```

```text
非常轻微的户外风声，空气缓慢流过，柔和稳定，适合与探索音乐和细雨声一起作为背景循环。
```

环境声可以从当前音效能力支持的短循环时长开始，例如 10 秒。需要完整音乐时直接选择正式音乐输出；独立生成的短预览不能被承诺延长成同一条完整曲目。提示词提出循环要求后仍需试听真实文件。

## 每节通用的完成检查

1. 使用实际场景相机运行，而非随手移动的编辑器观察镜头；标准对照先回正。
2. 确认资源已加载、参数确实控制当前对象，运行无新增脚本或 Shader 错误。
3. 关闭本节效果拍一张，开启拍一张，其他条件一致；再录一个关键参数的变化并恢复。
4. 检查人物脸部、地形边缘、透明像素轮廓、亮处颜色和操作区域是否清楚。
5. 需要编辑器预览的项目，关闭运行后再改参数观察；镜头水滴与音频在运行中验收。
6. 用同一分辨率观察帧耗时变化。粒子数量、阴影灯、体积雾和反射视口有实际开销；记录真实结果，不承诺所有电脑相同帧率。

推荐把每阶段的视频按“目标画面→最小实现→参数调节→关闭/开启对照→与前几节组合”组织。第一轮把整条效果路线走通，第二轮再使用确认的素材和场景构图调到接近原项目的画面。
