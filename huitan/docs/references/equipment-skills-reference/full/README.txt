人物与背包界面视觉重建素材

这份素材以原参考图为目标，补齐首次组件包缺少的插画、人物、物品、符号和装饰。assembled-native.png 是在 Godot 中使用下面的实际素材和原生文字拼装的预览；没有把原参考图作为最终整屏图片直接展示。

主要文件

foundation.png：2048×1152 的固定美术底层。保留书本比例、纸面、左页风景、详情区风景、花纹、格子、固定框线、灯笼、怀表及桌面前景。移除了人物、物品、文字和数值。固定构图和场景光影仍绘在这张底层中。
portrait.png：独立透明人物立绘。
items/：16 个独立透明物品图标，包括参考中的六件装备及十个展示物品。
symbols/：7 个独立符号，供页签、数量和属性栏使用。
ornaments/：7 个可独立摆放的装饰，包括便笺、灯笼、花簇、信封、怀表、叶枝和分隔线。底图已包含固定装饰，复原预览不再重复叠加这些装饰。
controls/：首次提取的空白控件，可用于按钮、槽位和页签状态。复原预览的主底图采用 foundation.png，不采用其中重新排布过的 journal.png。
items-sheet.png、ornaments-sheet.png：对应的透明图集。
layout.json：设计尺寸、主要摆放区域和素材用途。
preview.gd：可重新渲染预览的 Godot 脚本。

重新渲染

用当前 HD-2DMap Godot 项目运行：
godot --path <demoWithMeowa/1 的路径> --script <本目录的 preview.gd 路径>

脚本读取当前正式地图并保持开发相机，隐藏旧界面，以本目录图片构建临时预览；不会修改正式场景或保存角色状态。输出 assembled.png（项目当前窗口截图）和 assembled-native.png（2048×1152 的 UI 单独渲染）。中文使用系统 KaiTi，英文使用 Segoe Print，缺失时采用脚本中的后备字体。文字和演示数值由原生 Label 渲染，未烘焙到新素材中。

还原范围

这份素材可重建参考的主要构图、纸面材质、插画层次和物品陈列。Meowa 的本次提取及编辑会重绘内容，人物、部分图标、字形和细节与原参考仍有差异，不能视为原图源图层的无损恢复。

当前预览用于检查美术是否足以拼装，尚未绑定装备、学习、装配或存档逻辑。参考中的额外物品和五项属性仅用于视觉演示，不代表新增游戏规则。技能页完整美术及未展示的按钮按下、禁用等状态仍需按实际界面继续制作。
