## 接入参考

参考预览中每条外框宽 320 屏幕像素，保持原始比例，高约 45～46 像素。接入后的默认宽度为 360 逻辑像素，在当前 1280×800 窗口中约为 320 屏幕像素。相对外框的填充区域为 `(22, 13, 276, 22)`，按 320 像素参考宽度填写，随外框缩放。

先绘制空槽，再在内侧绘制彩色填充。填充始终保持满长度的纹理尺寸，通过裁切控制可见宽度，避免随着数值变化挤压纹理或改变边框。预览使用 75% 生命、62% 魔力，仅作视觉示例。原始 PNG 含细高光与渐变，缩小显示使用线性过滤。

## 在 Godot 中调整

打开 `scenes/ui/attribute_hud.tscn`，选择根节点 `AttributeHUD`。正式地图通过 `LoadoutUI` 自动接入这个组件并绑定人物；可在地图中启用实例的可编辑子节点设置局部参数。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| bar_width | 360 | 每条外框的逻辑像素宽度，包含辉光留白 |
| screen_margin | (24, 32) | 左侧、顶部的逻辑像素边距 |
| bar_gap | -10 | 上下外框之间的间隔；负值只让辉光留白重叠 |
| fill_rect | (22, 13, 276, 22) | 320 像素参考宽度下，填充相对外框的位置与大小 |
| glow_strength | 1 | 光边和辉光强度；0 隐藏亮边，1 保留素材原有效果 |
| background_opacity | 1 | 暗槽透明度倍率；0 完全透出场景 |
| fill_brightness | 1 | 红蓝填充的亮度倍率 |
| show_values | true | 显示当前值 / 上限；关闭时仍正常显示条内进度 |
| value_font_size | 16 | 数字字号，逻辑像素 |
| value_color | 暖白 | 数字颜色 |

四个素材字段可分别替换。布局与视觉参数支持编辑器预览及运行时调整；窄窗口自动缩小整组属性条，避免移出屏幕。

基础生命、魔力上限位于 `data/rpg/training_rules.tres` 的 `base_health`、`base_mana`，当前均为 100。生命上限叠加现有装备和生命训练；魔力也经过同一装备加成 API，当前不新增魔力训练项目。`Player` 的 `starting_health_ratio`、`starting_mana_ratio` 控制出生时的比例，默认均为 1。出生比例在装备及存档初始化完成后应用。

## 人物数值与调用接口

读取 `Player.current_health`、`current_mana`、`max_health`、`max_mana`。直接设置当前值会自动限制到 0～上限，并通过 `vitals_changed` 通知 HUD；上限读取既有基础、装备与训练属性。

```gdscript
player.take_damage(20.0)   # 扣除已结算的伤害，返回实际扣血量
player.heal(10.0)          # 回血，返回实际恢复量
if player.spend_mana(15.0):
    pass                  # 魔力足够时扣除；不足则返回 false 且不扣除
player.restore_mana(10.0)  # 回蓝，返回实际恢复量
```

上限改变时保留已损失的数量，再限制到新上限，例如 95/135 训练后变为 105/145。整理物品、切换收藏等无关操作不会回满血蓝。打开角色面板时属性条隐藏，关闭后恢复；隐藏期间继续接收数值更新。训练界面沿用整个 `LoadoutUI` 的显示管理，游戏世界继续运行。

当前血量与蓝量保存在人物运行状态中，每次出生重新应用比例；现有装备、技能和训练存档格式保持不变。此接入提供数值接口，技能施放、敌人伤害和死亡规则仍按后续玩法任务实现。
