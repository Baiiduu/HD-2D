# 无尽波次

正式 World 使用 `data/combat/scenes/world/` 内的独立战斗资源，数量、生命、经验和弹射参数在新挑战／重试后生效。City 和共享模板保持各自配置；怪物接入见[怪物框架](enemy-framework.md)。

当前平衡方向是前期三至六次基础剑伤清怪，成长中获得清群能力，后期由混合招式与递增生命形成压力。每波完整清空后安全休整，按 F 主动继续。实际清怪时间、存活压力与手感仍需人工试玩。

## 成长与割草基线

基础剑伤为 10，World 奔雷基础伤害为 20（四级技能为 32，均未计共享成长与暴击）。下表击杀门槛只计无成长、非暴击的基础剑术，不包含技能补伤、分裂幼体或多刀。人物伤害保护间隔、环绕减伤、剑术恢复和全能吸血保持原规则，见[共有成长](combat-buffs.md)。怪物攻击伤害、移速与招式保持本轮调整前的地图配置。

| 史莱姆 | 40 | 4 | 3 | 6 | 仅受总容量限制 |
| 卷叶冲锋虫 | 50 | 5 | 6 | 3 | 100 |

| 蓝胶幼体 | 8 | 1 | 1 | 0，仅分裂 | 仅受总容量限制 |

四种主怪按 6∶3∶3∶1 混编。保留原有类型覆盖和跨批使用量，小批次有整数误差；标准十三只混编为 6 史莱姆、3 冲锋虫、3 花兽、1 壶兽。苔蛙不进入强制类型覆盖，避免低权重仍每批刷一只；第二波起单独少量穿插，长期约占主体 2.5%，同场最多四只。壶兽幼体不计入主怪配比。

World 升级需求为 20、30、40、50……，每级增加 10，上限保持 100 级。经验奖励、吸取和清波全场收取保持。按真实编排并完整击败壶兽与幼体，前三波分别提供 73／125／180 经验，完整清波后为 3／5／8 级，包含 2／4／7 次升级选择，不包含免费初始技能。第一张史诗在第二波获得；实际入账时间取决于击杀和收取。该模型不是实机耗时或命中率测量。

满蓄初速 10 米／秒，短蓄初速 4 米／秒，最低续弹速度 2 米／秒，自然衰减 1.6 米／秒²；未计碰撞时满蓄理论滑行 5 秒、短蓄 1.25 秒。碰撞仍保留 92% 余速并扣 0.25 米／秒，环绕保留现有位移比例及过渡。动能维持、速度成长可以继续延长续航；两者各四级时，满蓄初速 18、衰减 0.8，空地理论续航约 20 秒，作为成型目标而非硬性上限。两者继续成长仍有收益；真实碰撞、主动退出和清波可能提前结束。

## 后续波次

- 前三波主体 18／28／40：第一波 5 只史莱姆试探，6 秒时一批十三只混编；第二波 1 只史莱姆、十三只混编小股、9 秒一批十三只混编，14 秒穿插一只苔蛙；第三波十三只混编小股、9 秒和 18 秒两批各十三只混编，15 秒穿插一只苔蛙。第三波主怪实际为 18／9／9／3，另有一只苔蛙。
- 第一波保持模板入口；第二波起采用全战区合法外围、按人物方位选择双向至四向进场。逐个检查安全距离、禁刷区、实体碰撞、地形和导航；无安全点就保留任务等待，容量预留和分帧创建不变。原地分裂和明确指定区域的外部任务保留原约束，详见[怪物刷新](wave-spawning.md)。
- 第四波起沿用第三波的小股／怪潮／辅助穿插结构，每波主体增加 20：60、80、100、120……；第 27 波达到每波 512 只上限。幼体另计但仍受 1024 次单波登记预算约束，不丢弃已登记任务。
- 前三波同场容量 24；第四波起每波增加 12，第八波起封顶 80，包含出场预告。分类上限为普通／特殊／精英／首领 128／64／4／1，均受同场总量约束；特殊容量允许所确认的冲锋与远程比例实际进入场内，不增加当前不存在的精英或首领。满员时后续任务等待名额，不减少每波总数。
- 怪潮每批从十三只起随波次增长，受同场、同种、分类和成本限制，后期最多使用约一半同场名额；其余成员形成后续潮次。组内间隔每波减少原值的 4%，最大减幅 75%，最短 0.08 秒；批间隔保留原排期规则。
- 前三波生命保持基础值，第四波起每波增加基础值的 50%；第五波起，在该线性基底上每波额外乘 1.2，使压力从已反馈偏弱的第五、六波开始跟上。前段生命倍率为 `B=min(100, (1 + max(波数-3, 0)×0.5) × 1.2^max(波数-4, 0))`。第 18～21 波暂留百倍生命平台，允许成型构筑收获清群收益；第 22 波起，最终倍率为 `min(1000, B×(1+max(波数-21, 0)×0.12))`，后段每波增加平台基础值的 12%，不逐波复利。伤害、移速和经验不随波号递增，受伤与恢复保持原规则。

生命复合成长默认关闭，仅由 World 独立启用；City、共享模板及未配置地图仍沿原线性曲线和十倍上限。前段复合计算在 100 倍封顶，开启的后段持续成长具有独立的 1000 倍安全上限，极大波号仍有限且有界。分裂体按原机制读取出场波倍率，固定生命怪仍可独立豁免；有限模式不应用无尽成长。

本局只保留三个开场模板，后续按需生成；资源、数量和生命规则在开局建立快照，编辑参数后新挑战／重试生效，已出生实例最大生命不回写。

## 成长与休整

正式 World 在真实最后一击后先播放短暂收尾特写：相机推近人物与死亡快照，世界短暂慢放，以原生像素剪影和暖色亮边强调命中，再平滑恢复原跟随。待生成增援或分裂幼体未清空时不触发。击杀、掉落与得分照常即时结算；镜头完成后收取剩余经验、完成连续升级选择，再进入休整。升级界面继续只冻结战斗，天气和声音运行。人物等级、武器等级与全局增益在波次间保留，挑战结束或重试按原规则清空。当前奖励池耗尽后仍可继续升级与清波，不新增占位奖励。

`World/WavePresentation → settings`（`data/visual/wave_presentation.tres`）独立配置首波／续波／清波提示与最后一击镜头。默认特写 3 秒：快速推近后保持慢放与剪影，最后约 0.72 秒平滑归位；慢放比例 0.16、最近距离比例 0.56，后两项相对进入特写前的时间与当前镜头。镜头偏移叠在正常跟随和 Q/E 之后，不改写 FOV、距离、俯角或 Style；远处击杀放宽构图，保留人物。战斗 HUD 短暂退亮并完整恢复，UI 动画、音乐和环境声保持正常速度。打开管理界面、冻结、结束或返回菜单会释放镜头和慢放。首波与后续开战保持当前取景，仅显示辅助标题；清波后仍按 F 主动续波。有限挑战、模拟和 City 不启用这套地图演出。

World 的首波／续波采用 B 版「开战动态大字」：按真实波次显示「第 01 波」等标题，左右汉字与中央波次数分段快速切入，数字单次轻回弹后稳定，下方暖金短线扫出，少量两侧碎光随后消散；停留后整组向右上短移淡出。开场不再叠旧装饰横幅、地面圆环或画面边缘压暗，相机、出怪、输入与战斗时间保持原规则。首波 1.4 秒、续波 0.9 秒；默认数字字号 88、纵向比例 0.16、切入 0.22 秒、退场 0.18 秒、切入距离 56 像素。在「参数总览 → 视觉」搜索“开战”调整，字号和布局在下次提示生效；只由 World 独立启用。`WaveOpeningTitle` 复用三个标签与一个绘制节点，没有独立计时器或 Tween，统一由原演出时间轴推进，冻结／管理界面隐藏并保持进度，完成后不再处理。结束保留已认可的三秒慢镜头、运镜和剪影，文字布局、切入观感与节奏由正式地图人工验收。

清波提示采用已确认的简洁收尾：最后一击镜头归位、连续升级选卡完成后，`WavePresentation` 在真实 REST 阶段显示「第 01 波完成」，复用开场组件的奶油白像素字、独立像素数字与暖金短线。数字字号默认 56，整组轻抬淡入 0.24 秒、稳定停留约一秒、淡出 0.22 秒，总时长 1.4 秒，没有回弹、碎光或第二轮地面特效；旧花纹横幅、英文、地面圆环和边缘压暗退出 World 清波表现。对应 `compact_clear_enabled`、字号和淡入淡出时长可在「参数总览 → 视觉」搜索“清波”调整。

`WaveHUD` 在底部单独保留「休整中　[F] 开始第 02 波」，读取当前实际继续键和下一波数，与开战提示共用米白像素键帽；键帽 28 像素、字母 14 像素，正文默认字号 18，统一距底部 112 像素。底部距离和正文参数在同一波次演出资源中。标题消失后底部提示仍保留，顶部旧完成文案不重复显示；`ScoreHUD` 继续即时入账与显示加分数字，只在这套无尽样式下隐藏重复的波次完成说明。菜单和冻结期间隐藏，关闭后恢复；提前继续直接撤下旧提示、衔接真实续波标题，不增加等待。地图只绑定一份样式资源，移除演出时归还 HUD 样式；City、有限挑战与模拟沿用各自原提示。

休整没有倒计时，不自动生成下一波；按 F 继续，ESC 可撤退。战斗中顶部显示“第 N 波 · 无尽”，休整时使用上述底部继续提示，不显示有限总波数。`test_wave_clear_presentation.gd` 覆盖真实清波、选卡／管理界面隐藏与恢复、标题结束后的提示保留、可替换按键、得分去重、快速续波与样式退出；布局、遮挡和舒适度仍由正式地图人工验收。

## Godot 参数

选中 `scenes/world/world.tscn` 的 `WavePrototype → 波次配置`，展开 `Population Rules` 与 `Health Growth Rules`，也可在“参数总览 → 战斗与成长”搜索“怪潮”“生命成长”或具体参数。

| 参数 | 正式地图基线 | 含义 |
| --- | ---: | --- |
| Endless Mode | true | 启用无尽；关闭后恢复有限编排和最终胜利，用于开发对照 |
| Population Rules | horde_128.tres | 已连接的正式数量档位，优先于控制器旧数量参数 |
| Surround Start Wave / Surround Max Fronts | 2 / 4 | 无尽多向进场的起始波与每批方向上限；起始波为 0 沿用模板入口 |
| First Active Limit / Max Active | 24 / 80 | 同场容量起点与终值，包含预告中的怪物 |
| Growth Start Wave / Active Growth Per Wave | 4 / 12 | 同场容量递增的起始波和增量 |
| Enemies Per Wave Increment / Max Wave Enemies | 20 / 512 | 开场模板后的单波主体总数增量和上限 |
| Interval Reduction Per Wave / Max Interval Reduction | 0.04 / 0.75 | 每波减少基础组内间隔的比例和累计上限 |
| Min Spawn Interval | 0.08 秒 | 无尽生成的组内间隔下限 |
| Max Queued Per Wave | 1024 | 单波登记总预算，包含延迟分裂／召唤 |
| Health Growth Rules | endless_health_growth.tres | 已连接的无尽生命规则 |
| Start Wave / Bonus Per Wave | 4 / 0.5 | 生命递增起始波与每波基础生命增幅 |
| Late Start Wave / Late Bonus Per Wave | 5 / 0.2 | 复合增幅从第五波起每波乘 1.2，设为 0 可关闭 |
| Minimum Multiplier / Maximum Multiplier | 1 / 100 | World 前段生命倍率上下限，默认共享上限仍为 10 |
| Sustained Start Wave / Sustained Bonus Per Wave | 22 / 0.12 | 成型窗口后按前段基底逐波线性增幅，起始波 0 关闭 |
| Sustained Maximum Multiplier | 1000 | 开启后段成长时的独立最终上限 |
| Waves | 原三份资源 | 开场编排；最后一份也是续波模板，支持混合怪物 |

数量规则为空时才使用控制器旧参数：每波 +8、总数 160、间隔减幅 3%／最多 50%、最短 0.18 秒；这些旧字段在正式地图已被数量资源覆盖。`waves` 留空时，无尽模式以 `first_wave_enemies` 和 `spawn_interval` 生成一个开场模板，再使用所选曲线。有限模式继续沿用 `total_waves`、`enemies_per_wave`。共享控制器默认保留有限模式兼容，正式地图显式启用无尽。

`get_run_state()` 的 `endless` 标识区分无尽模式，`wave_count = 0` 表示没有有限总数，`active_limit` 与 `enemy_health_multiplier` 暴露本波容量和生命倍率；`wave_label(number)` 提供显示文本。`wave_cleared` 逐波通知，无尽不会自动发出胜利或 `run_ended`。

## 验证

`tests/test_endgame_balance.gd` 用实际成长与攻击结算验证首张质变、后续递减、可继续成长、卡面有效读数、成型清群窗口和后段压力，以及未开启地图的兼容；`tests/test_world_difficulty_balance.gd` 用实际 World 资源和混编规划验证三至六刀门槛、五秒理论滑行、成长续航收益、既有恢复参数、前后期生命、极大波号、主怪配比、少量辅助、前三波完整清波经验与史诗时机，以及后期批次容量。

无界面回归另外覆盖复合成长开关、旧线性曲线、配置快照、实际怪物扣血、混合批次预留与完整清波、剑术及升级规则。自动检查不代替正式地图试玩；后期实际击杀时间、死亡原因分布、选卡频率和同屏性能由人工验收。
