# 草地光影试作

2026-10-14 正式地图更新：树冠、花坛植物和草木地编改为固定世界空间的柔和簇影。显示贴片继续朝向镜头并保留风摆；投影通道采用朝向光源的圆润簇体，Q/E 不改变其世界轮廓。正式地图 `GroundDressing.stable_shadows` 默认开启，在参数总览显示为“固定柔和簇影”；Style 和刷新植被保留此选择。关闭可对照原来的显示贴片投影。

花草与人物的局部光阴影另修正了缓存更新：转镜后复用阴影与新建同位置灯光得到的轮廓在修复前分别相差 1155／784 个像素，修复后原生测试通过。两种着色器在顶点阶段读取 `TIME * 0.0`，让渲染器更新相机／自定义时钟驱动的投影；顶点位置、动画与风时钟不变。局部阴影更新有实际渲染开销，继续使用现有灯光数量上限。相关引擎缓存行为可参考 [Godot 官方问题记录](https://github.com/godotengine/godot/issues/70641)，本项目 4.7.2 的行为另由原生像素回归验证。

簇影边缘采用固定在投影卡片内的覆盖率过渡，再由原生阴影滤波形成柔边。相邻簇体在同一光源的阴影图中合并，重叠区域不通过透明黑片反复叠暗；阴影仍作用于原生受光表面，保持台地、道路、花坛和人物的接收关系。原有世界空间根部遮蔽继续提供近根接触，未改地表色斑、植被落位、光源强度或镜头。

投影视角使用 `INV_VIEW_MATRIX` 的光源视图，显示视角继续使用 `MAIN_CAM_INV_VIEW_MATRIX`，参见 [Godot 空间着色器说明](https://docs.godotengine.org/en/latest/tutorials/shaders/shader_reference/spatial_shader.html)。公共实现位于 `shaders/includes/foliage_shadow.gdshaderinc`，树与草木使用各自的冠部／可见尺寸，不修改原生 PNG。

Godot 场景：`huitan/scenes/previews/four_realms.tscn`。
选中 **World → GroundDressing → 草地光影**，参数在编辑器和运行时均可调整。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| Lighting Enabled | 开 | 总开关；关闭恢复原有草丛受光、草地湿润响应和根部表现，位置不变 |
| Stable Shadows | 开 | 阴影通道使用固定柔和簇影，邻近植物投影连成整体；关闭为显示贴片轮廓 |
| Normal Strength | 0.35 | 固定在世界中的受光起伏；0 是朝上的统一法线，仍与镜头解耦 |
| Root Occlusion | 0.3 | 草根与其脚下地面的柔和遮蔽，0 关闭 |
| Backlight Strength | 0.12 | 叶尖接收真实光源的背光程度，0 关闭；没有自发光描边 |
| Ground Relief | 0.008 | 现有草地纹理的细微凹凸受光，0 恢复平面法线 |
| Ground Wet Response | 0.2 | 草地对 ArtDirection 和天气湿润的响应，0 保持原有干燥表现 |

第一版复用现有月光和路灯，不增加光源。月光方向、颜色和强度仍在 ArtDirection 中调节。道路、石板、桥和水面不使用草地材质参数；公共路灯金色颗粒配置保留。

## 实现与局限

草丛的显示贴片仍绕竖直轴朝向相机。受光法线采用每丛固定的世界方向、轻微叶片变化和随风弯曲，再转换到观察空间。根部压暗和背光使用原有材质与真实光源；没有新增美术贴图。

地面接触遮蔽图由既有草与花的落点生成，固定在世界中。这是美术近似的根部遮蔽，不代表逐叶片的真实三维遮挡。投影通道的圆润树冠、草簇与花簇也是体积近似，随光源方向产生落影，不复刻逐叶片轮廓，也不随显示风摆改变形状。法线凹凸以现有纹理明暗为近似高度，强度保持很小。

- 继续使用原有 MultiMesh 分块；没有新增灯光、场景实例或额外阴影视图。
- 显示贴图不增加纹理采样；簇影复用原投影网格、材质和阴影通道，边缘过渡使用少量解析计算。地表根部遮蔽仍为一次纹理采样。
